# 書籍導讀共用規格

適用：導讀一本書（或書中一章）的文章，包括閱讀地圖類系列（群體非理性閱讀地圖這種一本書一篇＋總覽的系列）。課程導讀走 `course-guide-contract.md`，不套這份。

## 為什麼有這份規格

本站踩過（2026-11-20）：群體非理性系列的 Mackay 篇，開頭直接丟 Semper Augustus、200 perits、5500 florins，沒交代鬱金香狂熱是哪一年、在哪裡、買賣什麼、怎麼崩的，就跳去講「別人怎麼講這件事」、史料怎麼轉抄。結尾是「L1 層」「解釋鏈上的位置」「系列的發動機」與一節「台灣回扣」。使用者說「相當沒有價值，沒頭沒尾看不懂」。

原因有三，這份規格逐一擋：

1. **規劃表決定跳過背景**（「直接從原文句進入」），以為總覽講過，總覽其實沒講。→ 每篇自己交代事件或論點本身。
2. **規格只列查證義務**（史料清算、譯本狀態、利益申報），沒列讀者要先知道什麼。→ 下方「正文先後」。
3. **審稿的人讀過研究筆記**，腦中有背景，看不出缺口。→ 下方「冷讀」。

## 正文先後（教學功能，不是固定 H2）

1. **開頭三段內**：這本書是誰、何時、為什麼寫的；這篇讀它哪一部分、為什麼挑這部分；讀者讀完能做什麼。
1a. **書的核心主張**：作者自己怎麼說這本書要證明什麼，引原文一兩句（序言、結論）。只讀一章時，這一章要當成檢驗這個主張的案例，而不是單獨的故事。
2. **事件或論點本身**：書講的是歷史事件，就先用目前最可靠的版本把事件講完（時間、地點、誰、交易或行動怎麼運作、結果）；書講的是論點，就先把論點和它的例子講完。單位、幣值、專有名詞第一次出現時換算或解釋。
3. **書怎麼說**：作者的寫法與原文句，和上一段逐點對照，讓讀者自己看見差距。
4. **後來的研究修正了什麼**：誰、用什麼證據、主張到哪裡為止（例如 Garber 沒說「完全理性」）。學者之間的分歧講清楚，不只列名字。術語（observational equivalence 這類）要嘛用白話講完，要嘛不放。
5. **為什麼這個版本流傳下來／這本書今天還值不值得讀**：這是讀者最想要的「所以呢」，不能省。
6. **回答系列的問題**：系列文要明講這篇讓讀者對系列的核心問題（例如「群體為什麼會集體失去理性」）多懂了什麼。只做史料批判、把系列前提拆掉卻不交代剩下什麼，等於沒寫完。
7. **讀者帶走的判斷方法與一個今晚就能做的動作**。判斷方法優先給後面幾篇也用得上的工具（例如分辨「個人非理性／制度讓人冒險／道德恐慌」三種解釋），不只檢查來源。

本站踩過（2026-11-20）：Mackay 篇第一次重寫補了事件背景，冷讀也通過，使用者再問「能收穫什麼？跟系列關聯？缺了什麼？」——它只是一篇鬱金香迷思破解文，沒講 Mackay 的命題（序言「think in herds… go mad in herds」），也沒回答系列問題。冷讀只驗「看得懂」，驗不到「值不值得讀」，所以第 1a、6 步要寫進範圍卡，在動筆前定好。

檢法：遮掉第 3 節以後，讀者能不能說出這件事（或這個論點）是什麼？說不出來就是第 2 步沒做。史料清算與查證段落合計不超過正文一半。

## 不進正文的東西

- **規劃用語**：L1–L5、order N、解釋鏈、弧線、回扣、發動機、模板四件套這類寫規劃表時的標籤。description 與 tldr 也一樣，不寫「閱讀地圖 order 1」。系列位置由系列導覽元件交代；要提到前後篇，寫篇名與它講什麼。
- **抽象標籤代替內容**：「這個模板」「敘事模板」這類詞，讀者不知道指什麼。寫出那套講法本身（天價數字、全民瘋狂、法院不管、道德教訓），之後回指用「這套說法」。
- **固定標籤當小節標題**：不用「台灣回扣」「限制」「這本書在解釋鏈上的位置」這種每篇都一樣的 H2。小節標題寫這段的內容，例如「台灣的投資新聞也在用這套說法」。台灣讀者相關的內容有就寫進對應段落；只是數譯本版本，併進書籍資訊一兩句。
- **查證過程**：哪份摘錄沒讀到、哪個連結 404、標 🟡 未核，留在 `.work/`。正文只寫會改變讀者做法的限制（例如「中譯本未逐本核對，引原文以 Gutenberg 為準」）。
- **沒講清楚的旁支**：一句帶過的其他論文、其他章節，要嘛講到讀者懂，要嘛刪。

## 冷讀（交稿前必做）

開一個子代理，**只給渲染後的正文**（不給研究筆記、規劃表、審稿紀錄），請它回答：

1. 這篇講的事件或論點是什麼？（時間、地點、主角、結果）
2. 這本書的作者怎麼說，和後來的研究差在哪？
3. 讀完我能做什麼？這篇對系列的問題多說了什麼？
4. 哪些詞或句子看不懂？哪些詞像中國用語或翻譯腔？

答不出 1–3，或第 4 題列出規劃用語，就回去改正文，不是改審稿紀錄。冷讀結果記進 `.work/reviews/<slug>.md` 的「冷讀」一節。
