# 課程導讀共用規格

適用：課程總覽、原課單堂／跨堂導讀、作業與週次教學。不因文章屬於 ai/learning 就套用；先確認 course series 身分或使用者明確指定課程。只改標題或影片來源時，只驗該範圍，另外回報已有教學缺口，不自行擴成重寫。

## 標題與課程位置

- 中文：`主題：一個核心問題｜CMU 11-768 第 12 堂`；核心問題可省略，不強制問句。台灣中文授課序號用「堂」，不用「講」或 L12。
- 英文：`RL Systems: Connecting Inference and Training | CMU 11-768 Lecture 12`。
- 跨堂：`第 12–13 堂`／`Lectures 12–13`；作業：`作業 2`／`Assignment 2`；按週：`第 4 週`／`Week 4`；自行重組：`單元 2`／`Module 2`；總覽：`課程總覽`／`Course Overview`；跨校地圖：`課程地圖`／`Course Map`。
- 主題在前，課程身分與範圍在後。同系列採一致課名，保留可辨識的技術名稱，不堆多個結論或重複「導讀」。系列目錄若有獨立短標題可用 `第 12 堂｜強化學習系統`，不要反過來改完整文章標題。
- 實驗 `實驗 0`／`Lab 0`、助教課 `助教課 1`／`Tutorial 1`、明確原有分篇 `第 2 部分`／`Part 2`；跨活動用 `／`（英文 ` / `）連接。官方 Lecture 0 保留「第 0 堂」；原課有第 7.5 堂、作業 0 或第 0 週時同樣保留。講義逐章用「第 N 章」／`Chapter N`。無原課序號且按主題重組的文章標「主題單元」／`Topic Guide`，不能杜撰堂次或單元編號。
- 原課堂次不是 `series.order`，不能從 order 推堂次。總覽、作業、週次不能硬套成 Lecture。英文副標自然翻譯，兩語課程與範圍要一致。不改已發佈 slug、檔名與 date。
- **一堂一篇，不拆 A/B。** 同一堂含多個主題或多份投影片（例：CMU 10-423 第 26 堂的世界模型與對齊兩份 deck），在同一篇用 H2 分前後兩半，H3 放各半的小節；導言交代兩半的關係。篇幅不夠就在篇內加深，不拆成兩篇共用同一個「第 N 堂」。作業放在它依賴的整堂之後。理由：全站其他課程系列都是一堂一篇，拆篇會在列表上出現兩篇同名堂次，讀者看成重複（2026-10-12 CMU 10-423 已併回）。

- **同一課名底下，堂次不能重複或重疊。** 一個系列若由兩門各自從第 1 堂編號的課組成，標題的課名要分開寫，系列名稱可以維持合併。本站踩過：林軒田系列把課名寫成合併的「台大林軒田 機器學習基石與技法」，列表上「第 5–6 堂」「第 7–8 堂」各出現兩次，技法「第 1–2 堂」排在基石「第 15–16 堂」後面，使用者問「標題沒有按照格式」（2026-10-13）。改成「…｜台大林軒田 機器學習基石 第 5 堂」「…｜台大林軒田 機器學習技法 第 5 堂」；只有總覽與跨兩門課的作業用合併課名。
- **「主題單元」只給真的沒有原課序號的文章。** 正文或 description 寫明對應 Lecture N 的，標第 N 堂；作業導讀標「作業 N」或「作業 N–M」。本站踩過：同一系列的前兩篇正文寫「對應 Lecture 1–3」「Lecture 4」，兩篇作業文講 HW0–HW5、HW6–HW7，四篇標題卻都是「主題單元」。
- **主題那一半不重複系列標籤。** 不寫「林軒田機器學習基石導讀：⋯⋯｜台大林軒田 機器學習基石 第 N 堂」這種課名出現兩次、又帶「導讀」的標題；英文不以 `Reading <course>:` 開頭。副標只留一個核心問題，不用「——」再串第二、第三個結論。
- **總覽標題的主題那一半，寫這門課教什麼。** 用課名或學科名開頭，副標放課程的主線或這篇給讀者的東西（閱讀路線、自學計畫）。查課時發現的怪事（課號、先修欄位怎麼寫、停開幾年、計分比例、網站停在哪一季）不當標題，也不佔 tldr：tldr 同樣先講這門課教什麼、讀者拿得到什麼；怪事只有在會改變讀者決定時（例如停開、材料鎖住）才在正文對應段落交代。學期與年份放 description，標題不寫，除非文章本身就是在比較兩個版本。檢法：遮掉「｜」後面，讀者說得出這是哪個領域的課嗎？本站踩過：Stanford CS 主線 19 篇總覽在系列頁排成一列，CS124 的標題是「課號掛 100，先修寫死四門，而且下一學年整年不開」，使用者說「標題莫名其妙」；改寫草案又帶了 Spring 2026、Fall 2025，被問「為何要強調時間」；規則初稿寫「怪事放 tldr」，又被問「為何要浪費空間佔用 tldr」（2026-10-13）。檢查器只驗「｜」後面的格式，這一條要自己看。
- **舊系列是併堂寫的，也要拆回一堂一篇。** 一堂一篇的規則 2026-10-12 才定，之前寫的系列不會自己符合。動到舊課程系列時先對原課堂數與篇數：林軒田系列 32 堂只寫了 16 篇，是使用者自己在系列頁發現的。

## 寫作前範圍卡（存 .work/，不是正文）

記錄課程／版本、文章角色、原課範圍與 series.order、讀者先備、主問題、讀完能解釋／計算／實作的能力、完整例子、檢驗該能力的問題與答案／判準、來源底本。

## 依角色教學

- 概念導讀：從具體問題到直覺與機制，走完一個例子／推導／反例，指出常見誤解，附可自行判斷的解釋題或變式題。不是每篇都要操作環境或程式碼。
- 實作教學：必要環境、可執行步驟、預期結果、錯誤診斷、變式練習與成功判準。
- 課程總覽／地圖：讀者定位、先備、各模組學什麼、依賴與閱讀路線、具體起點。不能要求總覽塞進每堂例子與作業。
- 作業／週次：按原任務與閱讀範圍教，交代先備、解題思路與檢查方式，不冒充官方解答。

這些是教學功能，不是固定 H2 模板。完整例子必須有條件／輸入、推理或計算、結果、結果的意思；模型名清單或只有外部連結不算。自擬例子明示是本文教學例子，不冒充講者口述；數值另算一遍。自我檢查需答案或判準，不只寫「想一想」。未在系列教過的先備給可到達的橋接連結。

## 查證資訊的位置

正文只留讀者需要的來源底本、原音／字幕取得方式、必要限制與歸因。登入測試、逐頁核對、字幕修正歷程放 .work/ 或研究筆記；刪掉正文前先保存。影片狀態與既有 course-videos 檢查照常，重複聲明合併，不為縮字把「公開頁未列」變成「沒有錄影」。

**影片沒有字幕軌，不等於拿不到課堂口述。** 先確認真的沒有（yt-dlp `--list-subs`、觀看頁的 captionTracks 都查過），再自己轉錄：`node .agents/skills/post/scripts/transcribe-course-videos.mjs <lectures.json> <工作目錄>` 會下載音訊、用專案的 Cloudflare AI 綁定跑 Whisper，每堂產生一份帶時間戳的逐字稿（一堂約兩三分鐘）。不要在本機跑 Whisper，多個 session 同時跑會互搶 GPU。本站踩過：林軒田系列 130 支影片沒有字幕軌，第一次只查三支就回報「拿不到口述內容、只能依講義寫」，使用者反問「你沒辦法取得？？」（2026-10-13）；改成自行轉錄後，每堂都補進了講義沒有的口頭解釋與例子。逐字稿是機器轉錄：公式、數字、人名以講義為準；課堂說法用轉述、不加引號當原話；聽不清的專名寧可不寫。影片狀態行寫明底本是「講義與機器轉錄逐字稿」，不要寫「內容核對：已依字幕核對」。

來源衝突若會改變概念、數字或結論，在相關段落保留；自擬推導、作者解讀與原課說法分清楚。未取得的口述、逐字稿不能編造。

## 完成證據與防復發

1. 執行 `node .agents/skills/post/scripts/check-course-titles.mjs <文章路徑...>`：新／修改標題按格式阻擋；指定路徑時另外阻擋同課名堂次重疊、主題重複「導讀」、該標堂次或作業卻標「主題單元」三種情況，所以整個系列的檔案要一起傳進去，只傳一篇看不出撞號。這三條在全站 gate 目前只計數不阻擋（2026-10-13 盤點其他系列還有 138 個既有問題，登錄在 `docs/governance/escalation-queue.md`），遷移完再改成阻擋。`--audit` 盤點既有標題，不等於全站已修正。全批遷移後預設 gate 對全站嚴格檢查，歷史 baseline 不再提供豁免，不准為變綠加例外。
2. 執行 `node .agents/skills/post/scripts/check-course-guide-layout.mjs`：獨立來源區不能放在教學主體之前；開頭影片狀態、版本限制與重要來源衝突仍保留。這只驗區塊順序，不能判定教學品質。
3. 每篇新增／教學重寫交由未參與本篇撰寫的獨立審稿者做語意審稿，報告存 `.work/` 並記錄文章路徑與版本／內容 hash；未取得報告或文章再次改動而未複審時，狀態只能是待驗收，不能由作者自行宣稱通過：列學習目標、正文機制、完整例子、練習與答案的具體段落位置，逐項說明如何對齊。缺例子、例子沒有推理、練習無判準、查核歷程取代概念解說，均退回重寫。只檢查 heading／字數／關鍵字不能證明教學完整。
4. 身分／標題、事實、教學品質三項分別回報；verify 綠或來源全部 Confirmed 不能替代教學驗收。只更新來源時明示「完成來源更新，未做完整教學重寫」。
5. 改本規格／入口／檢查器後，重跑代表任務：單堂、多堂、作業、週次、總覽、中英、無影片、標題-only、來源-only、只有範例 heading 沒內容。保留好壞樣本對照，由獨立審稿者指出正文證據；不能宣稱 lint 能自動判斷學會與否。
