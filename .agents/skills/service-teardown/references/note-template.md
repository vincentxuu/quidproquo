# 筆記模板

檔名：`.research/YYYY-MM-DD-<service>-<scope>-walkthrough.md`（逐輪型）或 `<service>-<mechanism>.md`（一機制一檔型）。

```markdown
# <服務> <範圍> 實測（YYYY-MM-DD）

來源：<工具> 登入 <自己的帳號／方案>，從 <入口 URL> 走完「<步驟 → 步驟 → 步驟>」。
指令為唯讀（<例>），測試素材 <低風險 repo／專案>。session `<id 遮罩>`，跑完後已 Archive。
相關：<其他筆記路徑>；專文 <post 路徑>（若有）。
原始擷取：`.playwright-mcp/<檔名>`（未追蹤）。

## 定題
- Q1 …
- Q2 …
- 本輪對照：<有／無>

## 1. UI 層
| 控制項 | 預設 | 點開看到 |
|---|---|---|

→ 一句話觀察。

## 2. 流程層
T+0s …

## 3. 網路層（第 N 輪）
### 3.1 傳輸方式
### 3.2 API 時序
| 順序 | 端點 | 用途／body 重點 |
|---|---|---|
### 3.3 請求標頭（身分與內部代號）
### 3.4 其他（遙測、靜態資源、目錄）

## 4. 事件／資料層
## 5. 邊界層
### 5.1 中斷 ### 5.2 工具失敗 ### 5.3 權限 ### 5.4 失敗注入
| 步驟 | 可否人工觸發失敗 | 方法 |
|---|---|---|
### 5.5 憑證能做／不能做

## 6. 對照
| | A | B |
|---|---|---|
### 一句話結論
### 改善路線（Phase 0 止血 → Phase 1 最高 CP → …）
### 不要照抄

## 自動化備註
- selector／banner／抓不到的元件

## 已完成項目總覽
| 章節 | 項目 | 方法 |
|---|---|---|

## 待深入項目（需要條件）
| 項目 | 需要條件 | 說明 |
|---|---|---|

## 沒拿到的
- <對方拒絕的項目＋拒絕原文摘錄＋可行但未採用的替代路徑與不採用理由>

## 殘留清單
- <刪不掉的遠端分支等，需人工處理>
```

寫作紀律：
- 每個結論句尾能對到一筆原始擷取（request、event、DOM）；對不到的寫「推測」。
- 表格優先於敘述；敘述只用在「→ 這代表什麼」。
- 對方的原文（按鈕文字、警語、錯誤訊息、拒絕理由）照抄，不翻譯。
- 數字帶單位與快照時間（cost、token、秒數、版本號）。
