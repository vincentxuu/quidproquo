# 語句用詞 Ledger

這份檔案記錄 quidproquo 已知會讓 zh-TW 文章讀起來太 AI、太翻譯腔或不像台灣中文的語句。它不是禁詞表；命中後要看上下文，再決定是否改。

## 2026-08-29 Keenable 改稿

| 原句或句型 | 類型 | 問題 | 建議替代 | 情境 |
|---|---|---|---|---|
| `不是 A，而是 B` / `不只是 A，而是 B` | 模板化轉折 | 同篇反覆出現會像模型在套 reasoning skeleton | 直接寫 B 的具體卡點、證據或後果；必要時拆成兩句 | Keenable 改稿中掃出 5 處 |
| `可以 A，但不能 B` | 模板化轉折 | 句型太整齊，容易變成 AI 式二分 | 改成「A 的用途是...；B 仍要自己做／另外驗證」 | 使用者指出「可以 但不能」很常出現 |
| `有意思，但還不到 X` | 模板化轉折 | 像評論模板，判斷沒有從材料自然長出來 | 先寫具體訊號，再寫限制與下一步 | Keenable 採用訊號段落 |
| `值得看，是因為 X` | 解釋腔 | 「值得」先下評價，再補理由，讀起來像摘要器 | 直接寫產品邊界或事件：「Keenable 把 Search、Fetch、CLI、MCP 放在同一個邊界」 | Keenable 開頭 |
| `還不到直接替換既有供應商的程度` | 評語腔 | 抽象判斷，缺行動 | 改成「既有供應商先留著，測試可以這樣排」 | Keenable 測試段 |
| `台灣語境裡的公司、法規、文件、公告和在地媒體` | 翻譯腔／抽象詞 | 台灣文章較少這樣講；「語境裡的公司」尤其不自然 | `台灣公司、政府公告、法規文件和台灣媒體` | 使用者指出「台灣語境？會這樣用嗎」 |
| `本地*`（如本地任務、本地讀者、本地市場、本地新聞、本地公司動態） | 翻譯腔／高風險用詞 | 台灣文章多半直接寫台灣，或寫具體資料／制度／工作流；`本地` 很容易像 local 的直譯 | `台灣資料查詢`、`台灣讀者`、`台灣市場`、`台灣新聞`、`台灣公司動態`、`台灣這邊的工作流` | 使用者指出「台灣不使用本地吧」 |
| `在地媒體` | 視情境 | 在文化／地方議題可用；科技選型文裡容易變成泛稱 | 需要精準時寫 `台灣媒體`、`台灣科技媒體`、`iThome / INSIDE / 數位時代` | Keenable 搜尋召回段 |

## 2026-08-30 免費 Search／Scraping 工具文章改稿

| 原句或句型 | 類型 | 問題 | 建議替代 | 情境 |
|---|---|---|---|---|
| 中文正文連續使用 `production traffic`、`hard stop`、`spending cap`、`router`、`unknown`、`rollover` 等一般英文術語 | 中英混用／工程 memo 腔 | 單一術語不一定有問題；同段堆疊時，讀者必須在中英文之間來回切換，開頭與建議段尤其難讀 | 品牌、API 欄位、官方 UI 與計價單位保留英文；一般敘述改成「正式流量」「額度用完即停止」「支出上限」「未公開」「結轉」等自然中文 | `free-search-scraping-tools` 結構重排後，機械檢查全綠但人工回讀仍發現語氣卡頓 |
| `持續限速、沒有免費 API，別混進額度表` | 分類標籤腔／標題翻譯腔 | 「持續限速」可當表格標籤，但整句把兩種不同情況壓在一起；「沒有免費 API」也可能被讀成產品根本沒有 API，「別混進額度表」則過於突兀 | 拆成 `免費使用，但只有速率限制` 與 `網頁版免費，不代表 API 也免費` | 使用者直接詢問這是否是自然中文 |

判斷重點不是英文詞數量本身，而是讀者是否需要英文才能回查程式或官方文件。`router` 若是具名元件可以保留；「自己的 router 仍要設預算上限」則應直接寫呼叫端要做什麼。

表格欄位可以採用壓縮分類，文章標題則應說出讀者看得見的差別。若一個標題要靠逗號串起兩個分類，再補一句命令，通常應拆成兩節。

## 改寫方向

### 模板化轉折

不要只換同義詞。把句型換成以下結構：

- 場景：`台灣團隊做 agent 產品時，會先遇到...`
- 事件：`Keenable 把 Search、Fetch、CLI、MCP 放在同一個產品邊界裡。`
- 證據：`文件列出...，價格頁寫...，rate limit 是...`
- 決策：`先放進 provider matrix；測贏再提高流量。`

### 台灣用詞

優先具體寫出「台灣」：

- `本地市場` → `台灣市場`
- `本地讀者` → `台灣讀者`
- `本地任務` → `台灣資料查詢` 或具體任務
- `本地新聞` → `台灣新聞`
- `本地公司動態` → `台灣公司動態`
- `本地媒體` / 科技文裡的 `在地媒體` → `台灣媒體` 或具名來源

例外：`本機`、`本地開發`、`local runtime` 這類工程語境可以保留。
