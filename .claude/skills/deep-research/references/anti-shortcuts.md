# 反合理化清單（deep-research）

研究完成、交接前逐條對照。每條「本站踩過」都是實際發生過的錯誤。

## 研究流程

| 想偷懶 | 為什麼不行 |
|---|---|
| 跳過拆子問題，直接搜題目 | 廣搜回來都是 SEO 內容，沒結構，最後寫不出導讀 |
| 搜尋摘要看起來夠清楚，不用再開原文 | 摘要是為關鍵字匹配切的，數字常被切掉對照條件。**這條是本 skill 歷史上最大的錯誤來源** |
| 抽取主要來源時帶 `query` 省 context | 回傳的是重排後的片段，你會以為讀了全文其實沒有。省下的 context 之後要用三倍去補 |
| 直接 `firecrawl_crawl` 整站 | 多數題目 search + 單頁 scrape 就夠，整站爬慢、貴、易被 rate limit |
| Groundlane 沒連線時回退到 legacy fetch tools | `stealth_fetch` 與 `fetch_page` 已退役；使用實際可用的專用 MCP 或平台原生工具並記錄原因 |

## 來源與查證

| 想偷懶 | 為什麼不行 |
|---|---|
| 把單一來源外推成效果、比較或爭議結論 | 權威一手只足以支持其直接陳述的窄事實；跨來源結論至少需要兩個獨立證據 |
| 湊到兩個來源就當查證過 | 兩份二手引用同一個誤讀還是錯的。要升的是層級，不是數量 |
| 只記數字不記對照條件 | 「0.51」和「0.93」可以出自同一篇。沒有對照條件的效果量不能用 |
| 為了論點強度，只引作者但書的前半句 | 作者寫「但考量到 X，這些量值難以直接比較」時，砍掉 X 就是竄改。懷疑論加碼也是錯 |
| 二手來源彼此一致就當查證完成 | 二手站會集體抄同一個錯誤。結構性事實（產品線、方案名稱）與價格一律回官方頁 |
| 看到付費牆就標「無法取得」 | 先跑完繞路清單。本站踩過：ScienceDirect 的 section snippets 是免費的、被引用的論文是開放取用的，兩條都能拿到方法細節 |
| 一直標「只有二次引用」卻沒查過完整書目 | 先搜一次完整標題。本站踩過：某篇連續三輪標「未讀原文」，查了發現有開放 PDF |
| 同一份材料前面幾個數字查出錯 → 剩下的不用查也知道不可信 | **錯誤不是均勻分布的。** 本站踩過：據此判定不值得查，被要求查完後六項裡四項完全正確 |
| 從一兩篇的品質推斷整個來源站的品質 | 站內差距可以極大。本站踩過：由客座文引用鬆散推得「該站引用品質差」，同站另一篇有 13 筆全部可追的一手參考 |

## 交叉驗證

| 想偷懶 | 為什麼不行 |
|---|---|
| 省略事實交叉表 | 沒這步就會把 LLM 幻覺當事實寫進文章 |
| 把跨來源比較的推論寫進事實交叉表 | 交叉表混入推論後，下一輪你會拿它當證據往上疊。本站踩過：用兩份 meta 的差額反推機制，後來讀全文才發現前提不成立 |
| 多維度表格只驗「兩站數字打架」的格子 | 「沒衝突」不等於「查過」，兩站可能同時抄到同一個錯。本站踩過：九個會議 × 五個年份的統計表，只查了數字對不上的 8 格，其餘 27 格從未查證——其中一格後來查到連官方 Fact Sheet PDF 自己都寫錯 |
| 寫 tldr / FAQ / glossary 時直接從自己正文濃縮 | 改寫是重新宣稱。要回原始來源對，不是回自己的正文對——不然只是把錯誤複製到更容易被引用的地方 |
| 這句改過好幾輪都沒被動到，應該沒問題 | 存活 ≠ 查證。沒被檢查的句子只是沒被檢查 |
| 補完一輪就直接往下走，沒回頭同步既有段落 | 新事實會讓舊段落變成錯的。本站踩過：主 note 的「建議閱讀順序」是第二輪寫的，直到第十輪才發現它漏掉了 note 自己稱為全站最好的四篇 |

## 產出與交接

| 想偷懶 | 為什麼不行 |
|---|---|
| Research note 跟發文一起做 | 兩件事混在一起，材料還沒齊就在套句子，最後事實對不上 |
| 搜尋摘要裡有數字就直接寫進結論 | 片段看不到樣本數、納入條件、但書。本站踩過：一份 meta-analysis 的效果量寫對了，但漏掉「控制工作記憶後主效果不顯著」 |
| 引用來源時只有名稱沒有確切 URL，自己拼路徑 | 那是虛構連結。本站踩過：查證報告只寫「Synced 轉述某推文」，沒給確切文章網址；差點自己補一個看起來合理的路徑 |
| 用搜尋去盤點「某個站有哪些相關內容」 | 搜尋只回語意相近的前 N 筆。**要窮舉就抓官方 sitemap / archive 索引頁逐條篩。** 本站踩過：使用者給 6 篇、搜尋補到十幾篇，掃 sitemap 才發現實際 60 篇 |
| 清單能窮舉但「剩下的模式重複，補的是廣度不是理解」 | **抽樣推斷沒有正當理由。** 本站踩過：以此為由不讀剩下 27 篇，讀完發現約 20 篇有新東西，還推翻了三處既有記載 |
| 抽取回來搜不到某個詞 → 下結論「原文沒有 X」 | **先證明抽取是完整的。** 本站踩過：`tavily_extract` 只回 20,769 字元，三個關鍵詞全部搜不到，換工具重抓才發現原文都有 |
| 背景 subagent 回報「已完成」，直接採信 | subagent 的文字摘要不等於它真的做了事。本站踩過：一個 fork agent 收到完整研究指令後，回報「已啟動背景研究」，但實際 0 次工具呼叫、沒有寫出任何檔案 |
| 不分環境一律使用或禁用平台原生 Web 工具 | 電腦端優先已配置 MCP；Web 端沒有 remote MCP 時才使用平台原生工具 |
