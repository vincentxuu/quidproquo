# 基本構件

所有圖型共用的寫法。圖型專屬的構件（生命線、象限軸、泳道）寫在各自的 `types/*.md`。

## 區塊格式

````markdown
```diagram
title: 圖的名稱（約 30 字內，會顯示在圖上方，也是螢幕閱讀器念的名字）
desc: 一句話說這張圖在講什麼內容（不是描述幾何：寫「讀者請求經 Worker 分送到三種儲存」，不寫「左邊一個框連到右邊三個框」）
caption: 選填，圖下方的小字（資料來源、簡化說明）
step: 選填；有寫就會變成可逐步播放的圖，每行一步
step: 第二步……
---
<svg viewBox="0 0 640 400">
  …
</svg>
```
````

- header 只接受 `title`、`desc`、`caption`、`step`、`lang`（`lang` 通常不用寫，跟文章 frontmatter）。
- `<svg>` 只要寫 `viewBox="0 0 W H"`，`role`、`aria-*`、`<title>`、`<desc>`、class、marker 由元件補上。
- 寬 200–800、高 80–1600，超出 build 失敗。

## 繪製順序

1. 背景帶狀（`dg-band`）與邊界框（`dg-zone`）
2. 連線（`dg-line`）——**先畫線再畫節點**，線的端點才會被節點蓋住
3. 節點（`dg-box`＋文字）
4. 連線標籤（`dg-edge`）與徽章
5. 圖例

## 節點

```svg
<g>
  <rect class="dg-box" x="200" y="170" width="150" height="60" rx="6"/>
  <text class="dg-label" x="275" y="192" text-anchor="middle" dominant-baseline="central">Astro Worker</text>
  <text class="dg-sub" x="275" y="212" text-anchor="middle" dominant-baseline="central">SSR・API</text>
</g>
```

- 單行名稱：放在框的垂直中心。名稱加副標：名稱在中心上方 8–10，副標在中心下方 10–12。
- 框寬 ≥ 最長那行字寬＋24。估字寬：中文每字 1em（15px 字 → 15px），英數每字 0.6em。
- 不要所有節點都一樣大：焦點節點可以大一點，次要節點小一點，層級要從大小看得出來。
- 數值都落在 4 的倍數（座標、寬高、間距）；字級照 `style.md`，不受此限。

## 連線規則（六條都是硬性）

1. **只用水平、垂直線。** 兩端不在同一條水平或垂直線上，就用直角轉折，轉角用半徑 8 的圓角。禁止斜線。
   **例外（只限這幾種，各自的參考檔有畫法）：** 循環圖的環狀弧線（`loop.md`）、魚骨圖的斜骨（`fishbone.md`）、桑基圖的流帶曲線（`sankey.md`）、等軸測投影的幾何邊（`exploded.md`、`axonometric-plan.md`）、Wardley map 的依賴線（`wardley.md`，元件位置由演化階段決定，只能斜連），以及數據本身的線（折線、雷達多邊形、旅程情緒線，class 是 `dg-plot-line`／`dg-plot-area`）。這些圖裡**連接兩個元件的箭頭**仍然只用水平、垂直線。
2. **標籤離線 6–10。** 標籤放在線段旁邊，不壓在線上；垂直線段的標籤放左右兩側。`dg-edge` 有描邊遮罩，但間距還是要留。標籤 ≤ 8 個中文字或 14 個英文字元。
3. **線不重疊。** 平行的兩條線至少隔 12；必須交叉時只交叉一次，並在交叉處讓其中一條斷開（見下方「跨線」）。
4. **同一邊多條線要分開接。** 一個框的同一邊接 N 條線，第 k 條接在邊長 × k ÷ (N+1) 的位置，彼此至少隔 12。
   **例外（規則 3、4 都適用）：分叉與合流。** 同一份東西同時送到幾個地方、或幾條路徑匯入同一個目標時，可以從同一個點分出（或匯入）多條線，共用起頭那一小段。分叉點之後各線不可再重疊、不可穿過其他框，轉角照規則 1。表達的是「同一個來源」，拆成各自獨立的接點反而會讓讀者以為是幾件不相干的事。
5. **線不穿過不相干的框。** 繞過去。真的繞不過（例如橫跨全寬的底層框），改成虛線、標籤放在看得到的那一端、箭頭不落在中間的框上。
6. **標籤不壓到後畫的節點。** 標籤的範圍不能和任何節點重疊。

### 直角轉折的寫法

從 (x1, y1) 水平出發、到 (x2, y2) 垂直進入，r = 8：

```svg
<!-- 先往右、再往下：x2 > x1，y2 > y1 -->
<path class="dg-line" d="M x1 y1 H (x2-8) Q x2 y1 x2 (y1+8) V y2" marker-end="url(#arrow)"/>
```

兩個轉角（右 → 下 → 右）：`M x1 y1 H (mx-8) Q mx y1 mx (y1+8) V (y2-8) Q mx y2 (mx+8) y2 H x2`，mx 是中間垂直段的 x。往上或往左時把對應的 ±8 反過來。

箭頭終點停在框外 2–4（框線外），不要插進框裡。

### 跨線

```svg
<path class="dg-line" d="M 100 200 H 192 A 8 8 0 0 1 208 200 H 300"/>
```

在交叉點用半徑 8 的小半圓跳過另一條線。

## 連線標籤

```svg
<text class="dg-edge" x="172" y="188" text-anchor="middle" dominant-baseline="central">HTTPS</text>
```

水平線在 y = 線的 y − 12 附近（字高約 13，下緣離線約 6）；垂直線放在 x = 線的 x ± 10，`text-anchor` 對應用 `start` 或 `end`。

## 圖例

只有在圖用了兩種以上的線型或節點樣式、而且光看文字分不出來時才放。放在**底部一整條**，上方一條 `dg-rule` 分隔，viewBox 加高約 56：

```svg
<line class="dg-rule" x1="20" y1="372" x2="620" y2="372"/>
<text class="dg-tag" x="20" y="396" dominant-baseline="central">圖例</text>
<rect class="dg-box dg-box--accent" x="76" y="388" width="16" height="16" rx="3"/>
<text class="dg-small" x="100" y="396" dominant-baseline="central">焦點元件</text>
```

圖例項目間隔約 120。不要把圖例放在圖中間。

## 逐步播放

在 header 寫 `step:`，再把元素標上 `data-step="n"`（一個元素可以屬於多步：`data-step="2 5"`）。可以標在 `<g>` 上，整組一起亮。

- 播放時，正在進行的步驟變綠、虛線流動，走過的步驟半透明，還沒到的幾乎隱藏；沒標 `data-step` 的元素（標題、邊界框、圖例）一直維持原樣。
- 每一步至少標一個元素，標了的步驟號碼都要有對應的 `step:` 行，build 會檢查。
- 讀者捲到圖上自動播放，播完停一拍再重來；有上一步／暫停／下一步按鈕和「第 n / N 步」；`step:` 的文字只給螢幕閱讀器，不顯示在畫面上，所以圖上的標籤要自己講得清楚；`prefers-reduced-motion` 時不自動播。
- **只在順序本身就是重點時才加。** 架構圖、分類圖、象限圖通常不需要；循序圖、流程、迴圈、時間軸才適合。上限 8 步（RAG 那種完整請求路徑可到 10）。

## 複雜度上限（每張圖）

| 項目 | 上限 |
|---|---|
| 節點 | 9 |
| 連線 | 12 |
| accent 元素 | 2 |
| 註記 | 2 |
| 步驟 | 8（特例 10） |

超過就拆成兩張：一張總覽、一張細節。

**格狀圖型例外**：看板、story map、比較矩陣、熱力圖、權限矩陣、服務藍圖的「格子」不算節點，上限照各自參考檔（通常 12–20 格）；格子之間若有連線，連線仍算在 12 條上限裡。
