## 3. 具體錯誤清單

以下路徑都以 `phases/` 為根；「docs」指該課的 `docs/en.md`，「code」指 `code/main.py`。

### 3.1 程式／演算法 bug（可跑性或結果錯）

1. **04-19 OCR 合成資料無法學習**：code:52-59 與 docs:168-175 寫 `shade = 0.0 if c.isalnum() else 0.5`，再填滿整格。所有英數字元都變成同一個黑矩形，"abc7" 和 "abc2" 的像素完全相同。CRNN 不可能從影像辨字，code:101 的測試結果只能靠猜。
2. **04-21 姿態合成資料身分不可學**：code:54-61 用 `img[:, cy-2:cy+2, cx-2:cx+2] = 0.0` 畫 4 個外觀一樣的點，卻要求第 k 個 heatmap channel 預測第 k 個點。由於位置是隨機的，channel 和點之間沒有任何可辨識的對應。
3. **06-02 chirp 頻率錯**：code:14-21 寫 `f = f0 + (f1-f0)*(t/seconds); sin(2π f t)`，瞬時頻率是 f0+2(f1−f0)t/T。所以實際會從 200 Hz 掃到 7800 Hz，超過 sr=8000 的 Nyquist（4000 Hz）而折疊，跟 docs:151 習題說的「200→4000 Hz」不符。
4. **06-06 講義版 eer() 恆回 100%**：docs:89-97 初始化 `best = (1.0, 1.0, 0.0)` 後，判斷式 `abs(fa - fr) < abs(best[0]-best[1])` 等於 `< 0`，永遠不成立。結果一定回傳 (1.0+1.0)/2 = 100%。code:121-132 已改用 best_gap=inf。
5. **06-16 toy 浮水印偵測讀的是宿主訊號**：code:57-74 只在單一樣本加 ±0.0005，偵測卻用 `1 if audio[idx] > 0 else 0`。宿主正弦振幅約 0.2，主導了正負號，所以還原的位元跟 payload 無關（疑似約 50%，請驗證）。
6. **06-09 BPM 解析失敗**：code:66-71 只認得 "128bpm" 連寫。示範用的 prompt "at 128 bpm" 會被切成兩個 token，結果回落預設的 120。
7. **06-11／12／15／16／17 程式裡有 HTML 實體**：例如 06-11 code:98 的 `"(target: &lt; 500 ms)"`、06-16 code:122 的 `"&gt; 99% bit acc"`。執行時會原樣印出 `&lt;`，看起來是生成時被跳脫過的痕跡。
8. **06-12 `b"".join(buf)`**：docs:92 的 buf 裝的是 sounddevice 回傳的 float ndarray，會丟 TypeError。另外 docs:81-86 與 code:79-87 的 pre-roll 已經含當前 chunk，觸發時又 append 一次，當前 chunk 會重複。
9. **06-04 beam search 示範自打嘴巴**：code:27-47 沒有追蹤 blank 狀態，"hello" 會被解成 "helo world"（code:115 自己也承認）。但 code:120 的標題仍寫 "beam should beat greedy"。
10. **06-14 fake VAD 的對比無法成立（疑似）**：code:31 `duration < 0.03` 對 20 ms chunk 恆真。0.2·N(0,1) 的語音幀 max−min 通常 >0.6，會被當成 transient。咳嗽幀 rms 約 0.36，回傳 0.55，仍判為語音。所以 code:105/110 標題說的「energy 誤觸、Silero 拒絕」無法由這段邏輯產生。另外 TurnDetector（docs:100-113、code:48-63）在 idle 狀態不重置 speech_ms，零星的短脈衝會累加到觸發 START。
11. **04-06 encode／decode 空間不一致（講義版）**：docs:202-203、272-273 的目標是 `tx = cx/stride - cell_x`，也就是 sigmoid 之後的 [0,1) 偏移；但 decode／postprocess 會對 tx 再套一次 sigmoid。docs:222 用「sigmoid 不完全可逆」來解釋，這個解釋是錯的。code:50-53 已改成 logit 版本。
12. **04-02 Sobel 期望值錯**：docs:262 寫 "large positive values on column 7 ... zeros everywhere else"。實際上台階從 col 8 開始，在 padding=1 下 col7 和 col8 都是 4，col15 因為 zero-pad 得到 −4，首末列是 3。
13. **04-04 random_crop 少一格位移**：docs:195-196 寫 `np.random.randint(0, 2*pad)`，上界不含 2*pad，所以永遠取不到最大位移。code:69 已修成 `2*pad+1`。
14. **04-05 凍結 backbone 卻沒凍結 BN 統計量**：code:150 的 feature-extraction 路徑在 `model.train()` 下執行，BN 的 running_mean／var 仍會被小資料更新。這正好就是本課自己警告的 BN drift。
15. **04-05 freeze_bn_stats 說明與實作相反**：docs:196 說 "freeze BN running statistics without freezing its weights"，docs:203／code:86 卻把 BN 的 affine 參數也設成 requires_grad=False。outputs/skill-freeze-inspector.md 又把「BN eval＋affine 可訓練」判為 bug，而這正是 docs:82 推薦的選項 2。
16. **04-22 SH degree-2 正負號**：code:90-92／docs:291-293 的 `C2 = [1.0925, 1.0925, 0.3154, 1.0925, 0.5462]` 全是正數。inria 參考實作的 C2[1]、C2[3] 是 −1.0925，所以第 5、7 項正負號相反，與官方 .ply 預訓練係數不相容。
17. **04-24 split_concepts（講義版）**：docs:118-127 用 `"and" in sentence` 判斷，只把 `"and "` 換掉。本課自己的範例概念 "hand holding a mug" 會被切成 ["h","holding a mug"]；含 "or" 的字（color、door）也會觸發；`;`、`&` 被偵測到卻沒有真的切分。
18. **04-16 分類器輸入沒做標準化**：docs:146-154 的 crop 只除以 255 就送進 ImageNet 預訓練的 convnext_tiny。這正是 04-01 警告的 silent bug。
19. **04-26 skill 顏色轉換**：outputs/skill-depth-to-pointcloud.md 寫 rgb 可以是 float32 [0,1]，但 write_ply 直接 `astype(np.uint8)`，顏色全部變成 0 或 1。
20. **04-18 skill IVF metric**：outputs/skill-image-text-retriever.md 寫 `faiss.IndexIVFFlat(quantizer, dim, nlist)`，沒指定 METRIC_INNER_PRODUCT，預設是 L2，跟「對正規化向量做 IP」的設計不一致。
