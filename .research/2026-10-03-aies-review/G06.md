## 5. Phase 層級總評

### Phase 11 — LLM Engineering
- **整體品質：中等偏弱（平均約 2.9／5）。** 涵蓋面廣，從 prompt 到 MCP 都有，講義篇幅大（500-1100 行），概念解說通順。但「Build It 從零手刻」的承諾只有一半兌現：
  - 有真實手刻的：CoT／ToT、BM25／RRF、LoRA、ROUGE／Wilson、MCP JSON-RPC。
  - 用 mock 冒充的：01 的 LLM 呼叫、10 的 judge、13 的 semantic cache 與 streaming。
  - 直接用框架的：16 的 LangGraph。
  - 程式常有讓 demo 結論失效的 bug，例如 B9、B12、B17、B19、B20、B23。
  - 數字錯誤集中在價格與記憶體算術，例如 E7、E13、E17。
- **最強 3 堂：**
  1. **11-14 MCP**：精簡、規格導向、20 個測試，錯誤處理細緻。
  2. **11-08 LoRA**：純 PyTorch 注入、合併、存讀，並驗證合併前後的輸出差異。
  3. **11-07 Advanced RAG**：BM25 公式與 RRF 算例都正確，parent-child 也清楚。
- **最弱 3 堂：**
  1. **11-01**：mock 加上 TS 測試作弊。
  2. **11-13**：capstone 的宣稱與實作落差最大。
  3. **11-16**：沒有手刻，且有多處 API 誤述。
- **模板化程度：高。**
  - 01-13 共用同一套骨架：Problem → Concept → Build It (Step 1..N) → Use It (註解掉的 SDK 程式) → Ship It (prompt-*.md + skill-*.md) → 5 Exercises → Key Terms 表（"What people say / What it actually means"）→ Further Reading。
  - quiz 每課固定 5 題，題目泛化。
  - 14-17 是另一種風格（無 Learning Objectives、quiz 是 dict 格式），明顯是不同批次產出。
  - 跨課大量重複：04、06、07 的 chunk／TF-IDF／Acme 語料逐字相同。
  - 模型世代混雜：docs 寫 GPT-5／Opus 4.7，skill 檔仍寫 GPT-4o／Claude 3.5／Llama 3，正是「部分更新」的 AI 量產痕跡。
- **適合誰：** 想要快速建立 LLM 應用全貌的初中階工程師，拿來當概念地圖可以。不適合拿程式當正確實作或基準參考；價格與規格數字一律需要另外查證。

### Phase 12 — Multimodal AI
- **整體品質：偏弱（平均約 2.4／5）。** 題材選擇很新、很完整（ViT 到 VLA、Omni、computer-use），每課都附論文清單，作為「閱讀導覽」有價值。但存在幾個系統性問題：
  1. **沒有一課有 "Build It" 節**，卻有 15 課標 `Type: Build`。程式全部是 110-190 行的 stdlib toy，多數是「寫死數字表、相加、查表」。12-13 甚至是腳本化的假訓練。
  2. **事實錯誤密度高於 Phase 11**，而且集中在模型細節，例如：
     - 歸屬錯：TMRoPE 給 Qwen2.5-VL、LLaVA v1 與 1.5 混淆、π0-FAST、Idefics2。
     - 數字錯：Janus-Pro MMMU、Llama-2 GPU-years、4K 影片 token 數、ColPali 儲存倍數。
     - 時序錯：MMMU、Mini-Omni、Qwen3-Omni 的日期。
     - 把 Claude 寫成具備影像生成、影片、音訊能力。
  3. **疑似捏造的量化敘述**：Prismatic 變異分解、OneVision 的 TT 階段與 ablation、InternVL3 的語料比例、多處 benchmark 數字。
  4. 沒有 quiz，也沒有測試。
- **最強 3 堂：**
  1. **12-23 ColPali**：MaxSim 實作正確，與 mean 的對照有說服力。
  2. **12-06 patch-n'-pack**：packing、cu_seqlens、mask 正是實務做法。
  3. **12-04 Flamingo** 或 **12-11 Chameleon**：gate 恆等驗證，以及共享詞表到 bigram 的端到端流程都清楚。
- **最弱 3 堂：**
  1. **12-10 InternVL3**：核心觀念錯，把它說成 "from scratch"。
  2. **12-13 Transfusion**：假訓練。
  3. **12-25 capstone**：重播寫死 plan，自己的 benchmark 只過 1/2，講義與程式規模不符。12-07 也接近這一級。
- **模板化程度：極高。**
  - 25 課的 H2 段落完全相同（8 個：Learning Objectives／Problem／Concept／Use It／Ship It／Exercises／Key Terms／Further Reading）。
  - 25 個 skill 檔全都是 "Given… Produce… Hard rejects… Refusal rules… Output" 的同一格式。
  - 程式都是 `demo_x()` 加 `print("=" * 60)` 的固定結構，最後一課還印出 "every primitive traces back to a specific arxiv paper you can read"。
  - 跨課的同一事實互相矛盾，例如 Perceiver resampler、LLaVA token 數、Qwen2.5-VL 時間 token。
- **適合誰：** 已有 VLM 基礎、能自行查論文核對的讀者，可以把它當「2023-2026 多模態論文索引與術語表」。不適合初學者把講義當作事實來源，也不適合期待「從零實作」的讀者。
