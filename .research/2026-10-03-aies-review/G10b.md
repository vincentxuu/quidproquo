### 第 1 批（32–36）錯誤
- `32-token-positional-embeddings/docs/en.md:71`："the lower dimensions encode coarse position and the higher dimensions encode fine position." 講反了：`denom = base**(2i/d)`，i 小時頻率高、波長短 → 低維編碼細粒度位置，高維波長長 → 粗粒度位置。
- `33-multihead-self-attention/code/main.py:196-206` + `docs/en.md:98`：repeat task 每列都是同一個 id，target 等於當前輸入 token 本身；模型只要把 token embedding 經 V/out_proj/lm_head 映回即可，完全不需要「look one token back」，docstring "A single attention head looking one token back is enough" 與 Learning Objective「watch the loss fall as the heads specialize」（docs:15）都不成立；熱圖餵常數序列（main.py:287-288），各 key 內容相同，權重分布無資訊量。
