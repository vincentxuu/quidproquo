### 13. G04 #49｜07-05 練習說 post-norm 激活爆炸、pre-norm 有界
- 位置：phases/07-transformers-deep-dive/05-full-transformer/docs/en.md:152（對照 :56-58、:171）
- 覆核：原文 "Post-norm's activations should explode; pre-norm's should stay bounded."。post-norm 每個 block 輸出是 `LN(x + sublayer(x))`，前向 norm 被固定在 √d 附近；pre-norm 的 residual stream `x + sublayer(LN(x))` 隨層數累加。用 numpy 實作 12 層 FFN 子層（d=512，標準初始化）：輸入平均 norm 22.68，post-norm 12 層後 22.63（=√512），pre-norm 12 層後 58.95。試圖推翻：Xiong et al. 2020（講義 :171 引用）談的是 post-norm 在初始化時靠近輸出層的**梯度**偏大，不是前向激活爆炸；講義把兩件事搞混，而且練習要量的就是前向 activation norm。
- 判定：✅ 成立。理由：實測方向與練習預期相反，學生照做會得到「與講義相反」的結果。

### 14. G04 #48｜07-05 每層 1.5B × 32 ≈ 7B 算錯
- 位置：phases/07-transformers-deep-dive/05-full-transformer/docs/en.md:83
- 覆核：python3 重算：4·4096² = 67.1M，3·2.6·4096² = 130.9M，每層約 0.198B，×32 = 6.34B。講義寫 "(16 + 32) M = ~1.5B parameters per layer × 32 ≈ 7B"：括號內單位與數值都錯，1.5B×32 會是 48B，只有最後的「≈7B」碰巧接近。Llama 3.1 8B config（https://huggingface.co/unsloth/Meta-Llama-3.1-8B/raw/main/config.json，meta-llama 官方 config 的鏡像）：intermediate_size 14336（r=3.5）、num_key_value_heads 8（GQA）。用真實設定算：(2d²+2·d·1024+3·d·14336)·32 + 2·128256·d ≈ 8.03B，正好吻合 8B。r=2.6 是 Llama 1/2 7B 的比例。
- 判定：✅ 成立。理由：中間步驟錯一個數量級、對應的模型設定也錯；最終 7B 碰巧接近，嚴重度屬中等，審閱者描述沒有誇大。

### 18. G04 #104｜08-13 v = α'·x0 − σ'·x1 正負號錯
- 位置：phases/08-generative-ai/13-flow-matching-rectified-flows/docs/en.md:75（對照 :25-37、code/main.py:94）
- 覆核：講義自己定義 `x_t = α(t)x_0 + σ(t)x_1`，對 t 微分得 `v = α'·x_0 + σ'·x_1`。代入同課的 α=1−t、σ=t：v = −x_0 + x_1 = x_1 − x_0，與 docs:33 與 code:94 `target = x1 - x0` 一致；講義寫的減號會得到 −x_0 − x_1。"Stratonovich-reformulated diffusion" 用詞也不對，Gaussian path 下對應的是 probability-flow ODE，與 Itô/Stratonovich 解釋無關。
- 判定：✅ 成立。理由：直接微分即可證，且與同課 code 的目標式矛盾。

### 19. G04 #107｜08-14 小 N 讓 FID 偏低
- 位置：phases/08-generative-ai/14-evaluation-fid-clip-score/docs/en.md:35；code/main.py:106-113
- 覆核：講義 "small N under-estimates covariance, gives falsely low FID"。實跑 code（兩組相同分佈）：N=50 → 0.0431、N=200 → 0.0288、N=1000 → 0.0022，code 自己印 "biased up at small N"。理論：真實 FID=0 時，有限樣本估計恆 ≥0，偏差必為正。Chong & Forsyth, CVPR 2020（https://arxiv.org/abs/1911.07023）指出 FID 在有限樣本下有偏，需外推到 N→∞ 的 FID∞（外推值低於有限 N 值）。試圖推翻：找不到任何情境讓小 N 系統性地使 FID 偏低。
- 判定：✅ 成立。理由：方向寫反，且同課 code 的輸出直接反證講義。

### 20. G04 #78｜08-03 LCM 被說成 adversarial／GAN distillation
