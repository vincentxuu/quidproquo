# 精讀派工說明（deep-research 2.5 第三段）

日期：2026-10-14。系列「教學文章怎麼寫」。使用者要求：研究結論要讀過全文才說；先前六個掃描 agent 都只用關鍵字跳讀，結論被推翻好幾條。你的工作是把分給你的來源**從第一個字依序讀到最後一個字**，每篇交一份抽取紀錄。你不寫文章、不下綜合結論。

## 你要做的

1. 在下面的批次表找到你的批次代號，打開對應的清單檔，讀檔頭（路徑前綴、欄位說明、派工提醒）與你那幾列。清單裡「要撐的結論」是掃描階段的暫定說法，可能是錯的，不要為了印證它去讀。
2. 逐篇處理。每篇開始前先看 `.research/extractions/articles-that-teach/` 與 `.research/extractions/teaching-text/` 有沒有同一來源的紀錄；`teaching-text/` 已有完整紀錄的不重讀，在回報裡註明即可。
3. 每篇從頭依序讀完：正文、方法、所有結果表、限制、被正文引用的附錄。參考文獻清單可以只掃過。不准用 grep 或關鍵字跳讀代替。長檔用 Read 的 offset/limit 或 `python3 -I` 依字元區間一段一段印出來讀，區間要首尾相接。
4. 文字檔若是 `pdftotext -layout` 轉的雙欄版面，段落會左右交錯、表格數字會錯位：改用不帶 `-layout` 的 `pdftotext` 重轉到你的 scratch 目錄，或直接用 Read 讀 PDF 頁面；**每一張會被引用的表都要對 PDF 版面**。
5. 檔案不完整（清單標 ⚠、或讀到一半發現缺節、缺表）時先重抓：只用作者或出版者合法公開的版本（期刊開放取用頁、PMC、arXiv、機構典藏、作者個人頁、ERIC、HAL、NSF PAR）。搜尋服務抓到的付費頁正文、第三方轉貼一律不用。可用工具：curl、Exa、Keenable、Unpaywall／OpenAlex、Wayback。重抓的檔存回原目錄並在紀錄裡寫來源網址。拿不到完整版就照實寫「只讀到哪裡」，那一篇標成未完成。
6. 一篇讀完就立刻把抽取紀錄寫到 `.research/extractions/articles-that-teach/<第一作者小寫><年份>[-短題].md`，再讀下一篇。不要等全部讀完才寫（額度中斷時要留得下東西）。

## 抽取紀錄格式

參考 `.research/extractions/teaching-text/bisra2018.md` 的寫法。每份必須有：

- 檔頭：完整書目（作者全名對首頁核過、年份、刊物、DOI）、原文檔路徑與總長度（行數與字元數）、讀取日期、版本（刊出版／作者稿／預印本）、供哪幾篇 order 使用
- **研究設計**：類型、受試者（人數、年級、地點）、教材、比較對象、量了什麼、何時量
- **結果（逐項）**：每一個可能被引用的結果都列：數字、對照條件、所在的節或表、原文一句（照抄英文或原語言）、行號或頁碼。無效果與反向的結果一樣要列
- **作者自己列的限制**
- **與摘要說法不一致的地方**：不能留空，沒有就寫「逐項對過，沒有」
- **與清單『要撐的結論』不合的地方**：清單那句話原文撐不撐得住，撐不住的寫清楚差在哪
- **讀取紀錄**：依序讀過的每一段起訖位置（行號或字元位置），加起來要涵蓋全文；哪些表對過 PDF

繁體中文、台灣用語。數字一律連著對照條件記。不確定的寫不確定，不要補。

## 不能做的

- 不改 `src/`、不改 `.agents/`、不 commit、不跑 `pnpm dev`
- Matuschak 標明不得分享或引用的贊助者信件與筆記一律不讀不用
- 不把原文大段貼進回報

## 回報（200 字以內）

寫了哪幾個檔；哪幾篇沒讀完與原因；清單上哪幾條「要撐的結論」被原文推翻或要改寫（一條一句）。
