## toolDegradation

四個研究子任務共同情況：Groundlane MCP 回「not connected」→ 未試 Groundlane 直接 HTTP → Keenable keyless 搜尋可用 → 出版社頁以 curl 直抓 → oliunid／ukclimbing／rockfax／epictv 等 Cloudflare 擋頁改用 Exa web_fetch_exa；firecrawl MCP 也回 not connected。

- part1：
  - Groundlane MCP（`mcp__claude_ai_Groundlane__web_fetch`）：用 ToolSearch 成功載入，但呼叫時回「MCP server "claude.ai Groundlane" is not connected」，沒有再重試。
  - Groundlane 直接 HTTP：跳過，因為 connector 層已斷，換用下面能用的工具。
  - Keenable keyless API（curl）：可用，搜尋主要靠它。
  - 出版社頁面用 `curl -sL` 直接抓：versantesud.it、pietradiluna.com、climb-europe.com、climbing-guide.eu、sestogrado.it 都成功。oliunid.com、ukclimbing.com、rockfax.com、panico.de 回 403；freytagberndt.com 回 404；arcorocks.com 連線失敗。
  - Exa（`web_search_exa`／`web_fetch_exa`）：可用。用它補了被 403 擋掉的 Rockfax book list、Panico 頁面、Arco Walls 預覽 PDF 和 Meisl 的零售商頁。
  - 沒有用到 You.com、Tavily、linkup、jina、firecrawl、WebFetch。
- part2：
  - Groundlane MCP（web_search）：回「MCP server "claude.ai Groundlane" is not connected」，降級。
