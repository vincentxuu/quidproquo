## 與清單「要撐的結論」不合的地方

清單這一列（22#11）的「要撐的結論」是：「實務主張的原話；它講的是職涯與人脈，不是記憶與理解」。

- 這句套在 Camden 身上不成立：原文**不談**職涯、人脈，也不談學習或寫作對作者自己的好處。內容只有「留言變少 → 拿掉 → 改用 Webmentions → 再裝回 Giscus」這段經過，外加「需要 GitHub 帳號」這個門檻的取捨。
- 它能撐的只有很窄的事：一位長年技術部落客自述留言量曾經消失、後來又試著開回來。這比較接近 order 21（留言區）的材料（order 21 的備選也列了它），放在 order 22「寫給別人看，自己學到多少」沒有對應內容。
- 「folks simply stopped commenting」（L29）是作者印象，沒有數字或時間點。
