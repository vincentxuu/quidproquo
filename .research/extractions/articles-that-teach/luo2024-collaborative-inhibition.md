## 研究設計

- **類型**：統合分析，依 PRISMA 2009（L27）。效果量是 Cohen's d，以 Comprehensive Meta-Analysis 3.0 計算，隨機效果模型（L37–41）。
- **比較的是什麼**（L12、L37）：協作組（多人一起回憶）的正確回憶量，對照「名目組」（nominal group，同樣人數各自回憶後把不重複的項目合併）。d = 名目組平均 − 協作組平均，正值代表協作抑制。量的是**學習後的回憶產出**（多為字詞清單一類的項目記憶，L73「This study focuses on the performance of collaborative inhibition in item memory」），不是理解或之後的個人學習成效。
- **檢索**（L28）：中文資料庫知網、萬方、維普；英文 Web of Science、ScienceDirect、EBSCO、ProQuest 學位論文；截止 2023-11-26；初篩去重後中文 76 篇、英文 212 篇。
- **納入**（L29）：排除非實證研究；協作組與名目組都要報正確回憶；同作者學位論文與期刊重複時只收期刊。
- **最後納入**（L29）：77 篇（15 篇碩博士論文、62 篇期刊；中文 21、英文 55、葡萄牙文 1），140 個獨立研究、185 個效果量、總樣本 19,492。年份範圍寫「1996 to 2023」（L29），3.4 節又寫「from 1997 to 2023」（L59）。
- **調節變項**（L30–34）：性別配對（同性／異性，只用兩人組）、成員關係（伴侶、朋友、熟人、陌生人）、文化（東方：中國、日本；西方：美、澳、加、德、法、葡、荷、瑞典、瑞士、土耳其）、有沒有加入記憶監控（如學習判斷 JOL、難易判斷）。L30 說「four potential moderator variables」卻列了五個名稱。
- **編碼**：L30 說第一作者編、第三作者核；L35 又說兩名成員獨立編碼後交叉核對。
- **品質評估**：用 Cochrane RoB 2.0（L36），結果只在 Figure 2，文字檔沒有圖的內容。
- **異質性**（L39）：Q(184) = 688.61，p < 0.001，I² = 73.28%。

## 結果（逐項）

1. **主效果**：d = 0.54（95% CI 0.49–0.58），Z = 23.92，p < 0.01（3.1，L42）。原文「The effect size is Cohen's d = 0.54 (95% CI: 0.49–0.58), Z = 23.92, p < 0.01.」逐一剔除單篇的敏感度分析，d 在 0.525–0.548 之間（L42）。
2. **出版偏誤**（L40）：Fail-safe N = 31,401，遠高於 5k+10 = 935。trim-and-fill 在左側補了 36 個研究後，效果量「slightly reduced from the original 0.54 to 0.40, 95% CI [0.33–0.51], but it still remained significant」。作者據此說沒有顯著出版偏誤。
3. **性別配對**（Table 1，L423–427；文字 L43）：Q_B = 15.08，df 1，p < 0.001。同性 k = 40，d = 0.64（0.45–0.83），p < 0.001；異性 k = 15，d = −0.11（−0.44–0.22），p = 0.52，不顯著。
4. **成員關係**（Table 1，L428–436；文字 L45）：Q_B = 17.68，df 3，p < 0.001。伴侶 k = 9，d = −0.19（−0.69–0.31），p = 0.45；朋友 k = 8，d = 0.18（−0.20–0.55），p = 0.35；熟人 k = 21，d = 0.45（0.26–0.63），p < 0.001；陌生人 k = 46，d = 0.75（0.57–0.93），p < 0.001。伴侶與朋友不顯著。
5. **文化**（Table 1，L437–441；文字 L47）：Q_B = 11.53，p < 0.001。東方 k = 90，d = 0.47（0.33–0.60）；西方 k = 95，d = 0.76（0.66–0.86）；兩者都顯著。
6. **記憶監控**（Table 1，L442–446；文字 L49）：Q_B = 18.47，p < 0.001。沒有監控 k = 173，d = 0.66（0.57–0.75）；有監控 k = 12，d = 0.14（−0.08–0.36），p = 0.20，不顯著。原文「it disappeared after the addition of memory monitoring」。**這 12 個效果量全部來自未發表的學位論文**（L52、L70）。
7. **只看已發表**（Table 2，L467–485；文字 L52–57；記憶監控因只見於學位論文而不納入）：
   - 性別配對 Q_B = 12.61，p < 0.001；同性 k = 24，d = 0.70（0.40–1）；異性 k = 15，d = −0.11，p = 0.52（文字 L53 寫 p = 0.46，與表不一致）。
   - 成員關係 Q_B = 10.64，p < 0.05；伴侶 k = 9，d = −0.19，p = 0.45；朋友 k = 2，d = 0.22，p = 0.57；熟人 k = 8，d = 0.59（0.18–0.99），表列 z = 4.71；陌生人 k = 30，d = 0.70（0.45–0.95）。
   - **文化 Q_B = 2.31，p = 0.13，不顯著**；東方 k = 42，d = 0.54（0.28–0.80）；西方 k = 93，d = 0.76。原文 L57「The moderating effect of cultural factors … was not significant (Q B = 2.31, p = 0.13).」
8. **發表年份**（3.4，L59）：統合迴歸 b = −0.02，95% CI [−0.04, −0.007]，p < 0.01，協作抑制隨年份變小。
9. **年齡**（只出現在討論 L70，結果節與表都沒有）：Q_B = 11.36，p < 0.001；老年（67.2–79.15 歲，k = 11）d = −0.09，p = 0.68，不顯著；成人（18.41–28 歲，k = 75）d = 0.65；青少年（k = 16）d = 0.44；兒童（k = 14）d = 0.52（ps < 0.01）。
10. **社會惰化不是主因（轉述）**：L17 引 Weldon 等 2000、Wang 2016，提高動機、競爭、降低責任分散後協作抑制仍在。
11. **協作的好處（只在未來方向提到，L73）**：錯誤修剪（協作組錯誤回憶較少）與協作後促進（協作後個人回憶較好）。本文沒有分析這兩項。
12. **作者的實務建議**（L76）：分組用男女混合、找關係較近的夥伴、協作記憶任務加入記憶監控。這些建議建立在上面幾個子群結果上，其中異性配對、伴侶、記憶監控各只有 9–15 個效果量。

## 作者自己列的限制

- 檢索抑制假說幾乎沒有直接證據，只有一篇量化研究（L72 第 1 點）。
- 性別配對與成員關係的研究少，樣本不夠穩健；效果量少會降低檢定力、增加估計不穩、可能偏向顯著結果（L72 第 2 點）。
- 納入未經同儕審查的學位論文可能影響內部效度；記憶監控這個調節變項主要來自學位論文（L72 第 3 點、L70）。
- 記憶監控結果可能有年齡、性別組成等混淆（L70）。
- 東西方二分過度概括，忽略文化內部差異與個體差異（L67）；文化差異在排除學位論文後不顯著，可能來自出版偏誤、未發表研究多為降低抑制的介入、或對離群值敏感（L68）。
- 性別配對與關係類型可能有交互作用，但研究太少沒有分析（L62）；性別配對與組別大小的交互作用「purely speculative」（L63）。
- 只研究項目記憶，沒有來源記憶（L73）。

## 與摘要說法不一致的地方

- 摘要（L11）說文化有顯著調節效果（p < 0.01），沒提只看已發表研究時文化調節不顯著（Q_B = 2.31，p = 0.13，L57）。
- 摘要說記憶監控「can successfully moderate collaborative inhibition」，沒提這 12 個效果量全部來自未發表學位論文；正文 L70 自己說解讀要審慎。
- 摘要說協作抑制是「robust effect」；正文的 trim-and-fill 補 36 篇後 d 從 0.54 降到 0.40（L40）。作者解讀為偏誤小，但降幅約四分之一，摘要沒有提。
- 正文與表之間：已發表子群的異性配對 p，文字 L53 寫 0.46，Table 2 寫 0.52（Table 2 這一列與 Table 1 完全相同）。
- 文化的總 n₁ 文字 L47 寫 4265，與西方子群 n₁ 4265 相同，加上東方 2251 顯然對不上；記憶監控總 n₁ 3773，子群 3758 + 507 = 4265，也對不上（L49）。
- Table 2 熟人列 d = 0.59、CI 0.18–0.99、z = 4.71：用 CI 反推標準誤約 0.21，z 應約 2.9；4.71 與 Table 1 熟人列的 z 完全相同，疑為照抄錯誤。p 是否真的 < 0.001 無法判定（以 z ≈ 2.9 推算仍 < 0.01）。我自行核算，原文沒有說明。
- 漏斗圖：L40 說漏斗圖對稱、偏誤小，同一段 trim-and-fill 卻在左側補了 36 個研究。
- 年份範圍 1996 vs 1997（L29 vs L59）；調節變項「four」vs 列出五個（L30）。

## 與清單「要撐的結論」不合的地方

清單寫「一起回憶輸給各自回憶再合併，d = 0.54，校正後 0.40」。數字撐得住（L42、L40）。要補的條件：
- 「各自回憶再合併」是**名目組的不重複總和**，比較的是群體回憶產出，不是每個人學到多少；本文只看項目記憶（L73），也沒有量協作後個人的記憶（作者自己提到有「協作後促進」這種好處，L73）。若 order 20 要拿這篇講「一起讀比一個人讀少了什麼」，得寫明這是**一起回憶時**的產出損失，不能推到一起讀、一起討論的學習成效。
- 抑制不是普遍的：異性配對、伴侶、朋友、老年人、有記憶監控的條件下都不顯著（但這些子群的效果量少，記憶監控全來自學位論文）。
- 「校正後 0.40」是 trim-and-fill 的估計，作者解讀為「沒有顯著出版偏誤」；清單用「校正後」這個詞沒錯，但不能寫成作者承認有偏誤。
