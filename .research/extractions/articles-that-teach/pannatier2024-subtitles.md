## 研究設計

- 類型：線上實驗，3（字幕格式：英文同語字幕 SLS／法文母語字幕 NLS／無字幕）× 3（英語程度：初級／中級／高級）組間設計；程度先測再分層，層內隨機分派格式（第 135 行）。
- 受試者：Prolific 招募、法語母語（或法語加非英語雙語）的學生，2020 年 10 月收資料，每人 10 英鎊（第 132 行）。最後 **131 人**（年齡 M = 22.3，SD = 3.58；女性 63；51% 為非英語的雙語者）（第 134 行）。各格式人數：SLS 41、NLS 46、無字幕 44；各程度：初級 21、中級 55、高級 55（Table 1 表頭，第 183–188 行）。
  - 樣本數依 G*Power：α = .05、1 − β = .85、f = 0.35（第 133 行）。
  - 排除：12 人因瀏覽器安全設定沒看到影片、3 人英語雙語、9 人自評先備知識 ≥ 5（第 134、150 行）。
- 教材：Richard Mayer 2014 年在哈佛的公開 YouTube 演講，剪成 **5 分鐘**，保留講者畫面與投影片，美式英語；英文字幕 750 字、法文字幕 779 字（作者之一翻譯、法語母語領域專家校對）；Flesch 易讀度英 58.7、法 59.6（第 137–140 行）。互動功能全關，**不能暫停、重看、做筆記，只看一次**（第 146、172 行）。
- 量測（後測用法文，學習者母語）：
  - 標示圖（14 分，α = 0.638）（第 156 行）
  - 問卷：8 題選擇＋2 題簡答，記憶與推論（10 分）（第 157 行）
  - 遷移：一題開放題，4 分量尺，評分者一致性 κ = 0.87；11.5% 的人用英文作答（第 158–159 行）
  - 認知負荷：Leppink 等 2014 的 8 題（內在 α = 0.868、外在 α = 0.872）；情境興趣：激發與維持各 4 題（α = 0.927、0.891）（第 161–163 行）
  - 英語程度：Cambridge 25 題線上分級測驗（0–13 初級、14–21 中級、22–25 高級）（第 153 行）
  - 共變項：自評先備知識（M = 0.74）、看字幕影片的經驗（M = 7.55）（第 150–151、210 行）
- 量的時間：看完立即測，沒有延後測（第 171、283 行）。
- 分析：Jamovi、ANCOVA（格式 × 程度，先備知識與字幕經驗為共變項），事後比較 Tukey HSD（第 175–176、231 行）。

## 結果（逐項）

1. **字幕格式對三項學習成績都沒有效果**（Table 2，第 212–229 行）：標示圖 F = 0.366, p = .694, η²p = .006；問卷 F = 1.078, p = .344, η²p = .018；遷移 F = 0.688, p = .505, η²p = .011。原文：「There was no significant effect of condition on any of the performance measures.」（第 231 行）
2. **格式 × 程度交互作用都不顯著**：標示圖 p = .972、問卷 p = .511、遷移 p = .350（Table 2）。作者原本預測初級受益於母語字幕、中級受益於英文字幕、高級在無字幕最好，全都沒出現（第 128–129、277 行）。
3. **英語程度的主效果**：問卷 F = 5.760, p = .004, η²p = .114；遷移 F = 5.957, p = .003, η²p = .090；標示圖 F = 2.609, p = .078（不顯著）（Table 2）。
   - 遷移：高級（M = 2.04, SD = 0.99）> 中級（M = 1.49, SD = 0.94），p = .016, d = 0.542；高級 > 初級（M = 1.24, SD = 1.04），p = .019, d = 0.752（第 232 行）。
   - 問卷：高級（M = 4.98）> 初級（M = 3.38），p = .006, d = 0.8568；中級（M = 4.78）> 初級，p = .015, d = 0.7575（第 232 行）。
4. **共變項**：先備知識只對標示圖顯著（F = 7.645, p = .007, η²p = .060）；看字幕經驗只對問卷顯著（F = 7.607, p = .007, η²p = .060）（Table 2）。作者：「it is FL proficiency and, to a lesser extent, prior knowledge and experience that contribute to participants' performance」（第 233 行）。
5. **認知負荷與興趣**（Table 3，第 244–264 行）：格式對內在負荷（p = .742）、外在負荷（p = .773）、激發興趣（p = .867）、維持興趣（p = .412）都不顯著；交互作用都不顯著。程度只對外在負荷顯著（F = 4.392, p = .014, η²p = .068）。字幕經驗對維持興趣顯著（F = 7.384, p = .008）。
   - 外在負荷事後比較：高級（M = 1.52）低於中級（M = 2.35），p = .043, d = 0.470；高級對初級（M = 2.74）p = .059, d = 0.631（第 265 行）。
6. 整體答對率：遷移 42%、標示圖 48%、問卷 46%，作者據此排除天花板與地板效應（第 270 行）。自評負荷偏低：內在 38%、外在 21%（第 272 行）。
7. 各格子的平均數（Table 1，第 180–208 行），例：遷移題初級 SLS 0.857、NLS 1.83、無字幕 1.13；問卷高級 SLS 4.73、NLS 4.64、無字幕 5.61。這些格子差異都沒有統計顯著，初級每格約 7 人。
8. 作者的設計建議：「the subtitles cannot be considered harmful and, if designers have the option of enabling subtitles in whatever language, they should probably do it – even though the research provides no definitive answer regarding the choice of language」（第 288 行）；並說字幕可以當成使用者自選的偏好、對聽障者有助、對閱讀障礙者可能更難（同行）。

## 作者自己列的限制（4.4 節，第 278–286 行）

- 講者臉部可能分走看字幕的注意力；沒有眼動資料，不知道受試者有沒有讀字幕、讀多少。
- 初級人數少（文中寫 n = 22，對 55、55），因 Prolific 受試者英語經驗多。
- 英語程度只用簡短的通用分級測驗，沒有量聽力。
- 後測用法文；先備知識只用自評，沒有前測。
- 英法兩語相近（同字母、結構相似）；先前 SLS 有正面效果的只見於中文、韓文母語者。
- 只量立即理解，沒有延後測。
- 內容複雜度只用文字易讀度表示，沒有操弄。
- 不能暫停、重看、筆記、查字，可能低估學習者自己補救的空間。

## 與摘要說法不一致的地方

- 摘要說 131 人「allocated to three English proficiency levels」，與正文一致；但方法節同時寫「招到 120 份有效回應」與「最後 131 人」（第 132、134 行），兩個數字怎麼接起來原文沒講清楚。
- 初級人數：Table 1 寫 21，限制節寫 22（第 280 行）。
- 問卷初級平均：Table 1 為 3.36，正文 3.38；高級 SD：Table 1 為 1.64，正文 1.67（第 189–191、232 行）。
- 外在負荷：結果節的高級對初級是 p = .059（不顯著），但討論節寫「advanced-level learners expressing a significantly lower cognitive load than elementary learners」（第 274 行），與結果不合。
- 顯著標記錯置：Table 2 遷移的模型 p = 0.055 標了 *；Table 3 外在負荷的程度效果 p = 0.014 標了 **（表註 ** 是 p < .01）。
- 前置檢核（第 209 行）：說各組先備知識「沒有顯著差異」，但初級的值寫 F(5,15) = 1.34, p = .03；自由度 (5,15)、(3,51) 也與三組比較不合。原文如此，無從判斷是哪裡打錯。
- Table 1 的「維持興趣」列，SLS 欄與「全部」欄的 SD 與上面「激發興趣」列逐格相同（2.62／2.34／2.30；2.04／2.30／2.26），疑似出版時複製錯誤；沒有 PDF 可以排除轉檔問題（見檔頭）。
- 4.3 節說初級在 NLS 條件的負荷「slightly higher (38%)」（第 277 行），對不到 Table 1 的任一格（初級 NLS 內在 4.88、外在 2.71，滿分 10）。
- 摘要「Neither a main effect of the condition nor interactions were found on any measure」與 Table 2、3 一致。

## 與清單「要撐的結論」不合的地方

清單寫：「用外語看教學影片，開不開字幕、哪種語言都不影響內容學習；程度才影響」。
- 「沒找到字幕格式效果」撐得住，但這是**沒有顯著差異，不是證明沒差**：初級每格約 7 人、全體每格約 14 人；G*Power 用 f = 0.35 估樣本，比一般「中效果」f = 0.25 大，偵測小效果的力量不足。寫成「這個實驗沒看到差別」比「不影響」準。
- 情境很窄：5 分鐘、只看一次、不能暫停、看完立即用母語測、英法兩語相近、講者畫面一直在。不能推到可以自己控速的影片，更不能推到「讀文章」。
- 「程度才影響」要修：程度影響問卷與遷移，**標示圖不顯著**（p = .078）；而且先備知識（標示圖）與看字幕經驗（問卷）也各有顯著影響。作者自己的措辭是「程度為主，先備知識與經驗為輔」。
- 作者的結論不是「字幕沒用、不必加」，而是「字幕無害，能開就開，語言選擇沒有定論，可以讓使用者自選」（第 288 行）。引用時不要把方向寫反。
