## 研究設計

- **類型**：受試者間實驗，四組隨機分派（L752–753「participants were randomly assigned to one of four groups」），加眼動追蹤。是一個較大研究的一部分，字彙學習的結果另文發表，受試者與影片相同（L558–566）。
- **受試者**（L571–617）：112 位在一所英國大學就讀的中國籍英語學習者，女 98、男 14，18–34 歲（M = 23.42）。程度 B2–C1，依自報 IELTS（M = 6.84，SD = 0.61）與 Vocabulary Size Test（M = 6,274.31 詞族）。約八成自述常看影片、常用字幕，**最常用的就是雙語字幕**（L589–591：bilingual M = 4.44、captions 3.14、L1 3.03、no subtitles 2.18，滿分 6）。
- **排除**：3K 詞彙水準測驗未達門檻 16 人中，13 人自述看得懂、納入與否結果無差異而保留，其餘 3 人刪除；3 人沒做完後測刪除；6 人校正不良或追蹤遺失，只從眼動分析刪除。最後理解分析 106 人、眼動分析 100 人（L599–617）。各組 IELTS 與詞彙量 ANOVA 無差異（L619–625，例如 overall IELTS F(3, 102) = 0.51, p = .68）。
- **教材**（L635–692）：BBC 紀錄片 *Animal Odd Couples* 四段剪成 23 分鐘、3,488 詞；前 3K 高頻詞覆蓋率 95.57%。中文字幕由第一作者翻譯，參照 Bilibili 網友譯本與數位母語者檢核。依 BBC 字幕指南，每條一行。**雙語字幕是中文在上、英文在下**（L679–681，作者說這是中國大陸常見格式）。字幕平均顯示 1,987 ms。
- **四個條件**：雙語字幕（中上英下）、英文字幕（captions，與語音同語言）、中文字幕（L1 subtitles）、無字幕。
- **量了什麼**：
  - 理解：34 題四選一，**題目用中文出**（L698–700），分全面性與細節題，不測推論（L708–712）；試測後最終 Cronbach's α = .83（L738–740）。看完影片立即紙筆作答、不限時（L774–776）。受試者事先知道會考（L768）。
  - 眼動：EyeLink 1000 plus，1,000 Hz。Level 1 把畫面切成字幕區（1920×270）與影像區（1920×810）；Level 2 把字幕區再切成中文行、英文行（各 1920×100）。535 個字幕顯示區間。指標：總閱讀時間百分比、凝視次數百分比、平均凝視時長、跳過率（L785–862）。
- **分析**：理解用線性迴歸、以詞彙量為共變項、Tukey 事後比較；眼動用混合效果模型（受試者與區間為隨機截距）；RQ3 用簡單線性迴歸。效果量依 Plonsky & Oswald（2014）以 d = .40／.70／1.00 為小／中／大（L939–945）。

## 結果（逐項）

### RQ1 理解（Table 1、Table 2，稿件 p. 21–22，已對 PDF 版面）

- 描述統計（Table 1，L1001–1014；滿分 34）：英文字幕 23.48（SD 4.15，n = 27）；中文字幕 27.38（4.71，n = 24）；雙語字幕 27.93（4.23，n = 30）；無字幕 20.48（4.81，n = 25）。原文：「Both the bilingual and L1 subtitles groups achieved the highest mean scores, with average scores around 80%」（L979–981）。
- 整體模型：字幕條件顯著預測理解，R² = .34，F(4, 101) = 14.72，p < .001；詞彙量正相關 b = 0.001，t = 2.71，p = .01；條件×詞彙量交互作用不改善模型（L985–995）。
- 事後比較（Table 2，L1035–1049）：
  - 雙語 > 英文字幕：b = 4.46，p < .001，d = 0.89（作者稱 medium）
  - 雙語 對 中文字幕：b = 0.52，p = .97，d = 0.26，**不顯著**
  - 雙語 > 無字幕：b = 7.48，p < .001，d = 1.47
  - 中文 > 英文字幕：b = 3.94，p = .01，d = 0.56（作者稱 small）
  - 英文字幕 對 無字幕：b = 3.02，p = .06，d = 0.69，**不顯著**（「only approaching significance」，L1029–1031）
  - 中文 > 無字幕：b = 6.96，p < .001，d = 1.13
  - 原文：「no significant difference was revealed between the bilingual and L1 subtitles groups」（L1027–1029）。

### RQ2 注意力分配

- **Level 1 字幕區對影像區**（Table 3，稿件 p. 24，已對 PDF）：字幕出現時的總閱讀時間比例——雙語組字幕區 0.60、影像 0.39；英文字幕組 0.64／0.35；中文字幕組 0.44／0.55；無字幕組 0.04／0.94。字幕區跳過率：雙語 0.08、英文 0.07、中文 0.10、無字幕 0.88。原文：「the bilingual subtitles group recorded about 60% total reading time and fixations on the subtitling area and about 40% of the time was allocated to the image area」（L1062–1065）。
- **Level 1 組間比較**（Table 4、5，p. 25–26，已對 PDF）：
  - 雙語對英文字幕，字幕區總閱讀時間 b = 0.03，p = .69，d = 0.13，**不顯著**；凝視比例 p = .42，不顯著。原文：「The bilingual subtitles and captions groups spent similar total reading time % and fixation % on the subtitling area, which were both significantly longer than those in the L1 subtitles group, with small effect sizes」（L1129–1134）。
  - 雙語 > 中文字幕：總閱讀時間 b = 0.11，p < .001，d = 0.53；凝視比例 d = 0.46。
  - 平均凝視時長在三個有字幕組之間都不顯著（p = .81–.99）。
  - 跳過率三個有字幕組之間都不顯著（Table 5，中文對英文 OR = 2.47，p = .07）。
- **Level 2 雙語組內中文行對英文行**（Table 6，p. 27，已對 PDF；L1217–1235）：總閱讀時間中文行 0.42、英文行 0.20；b = –0.16，t(534) = –33.45，p < .001，d = 0.82；凝視比例 d = 0.87；平均凝視時長中文 174 ms、英文 97 ms，d = 0.63。英文行跳過率 0.43、中文行 0.11，OR = 9.69。作者在 L1225–1226 把 d = 0.82–0.87 稱為「small effect sizes」。作者自己提醒這組比較跨兩種語言，要小心解讀（L1261–1263）。
- **雙語的英文行對英文字幕組**（L1267–1289）：英文字幕組讀英文行較久，總閱讀時間 b = 0.39，p < .001，d = 1.24；凝視比例 d = 1.36；平均凝視時長 d = 0.57；英文字幕組跳過英文的勝算遠低於雙語組（OR = 0.01）。詞彙量越大，英文字幕組讀英文的時間越少（只在英文字幕組顯著）。
- **雙語的中文行對中文字幕組**（L1291–1307）：雙語組讀中文行較久，總閱讀時間 b = 0.06，t(49) = 2.65，p < .001，d = 0.28；平均凝視時長 d = 0.18；凝視比例無差異 χ²(1) = 2.48，p = .12；雙語組跳過中文行的勝算較低 OR = 0.49，p = .01。

### RQ3 閱讀時間與理解（L1313–1361）

- Model 1（總閱讀時間比例 × 字幕行／組別）：F(7, 96) = 5.05，R² = .22。事後只有英文字幕組顯著：讀英文字幕越久、理解越低，b = –0.32，p = .01。中文字幕組讀中文 b = –0.23，p = .34；雙語組讀中文行 b = –0.37，p = .07；雙語組讀英文行 b = 0.30，p = .24，方向為正但不顯著。
- Model 2（平均凝視時長）：b = –0.11，p = .15，R² = .15，**無關係**。
- 原文結論：「when the L1 input is also available (i.e., when using bilingual and L1 subtitles), there seems to be no relationship between the processing time on on-screen text and comprehension」（L1682–1686）。

### 作者的詮釋

- 冗餘原則在這個情境不成立：「The effectiveness of bilingual subtitles also suggests that the redundancy principle (Chandler & Sweller, 1991) does not seem to apply in this L2 learning context」（L1381–1384）。解釋是受試者選擇性地看，靠中文行、略過英文行（L1478–1499）。
- 教學含意：「results have shown that bilingual subtitles do not lead to increased cognitive overload」（L1637–1639）——注意本研究**沒有量認知負荷**，這句是從眼動與理解分數推的。作者也承認依賴中文行「does not seem to promote a focus on the L2 written form」，若要學語言需另外引導注意英文（L1646–1656）。

## 作者自己列的限制（L1601–1633）

1. 只有 B2–C1、而且**本來就常用雙語字幕**的學習者，不能推到低程度或不熟雙語字幕的人。
2. 只有中英一組語言。
3. 只用中國大陸常見的「中上英下」格式；英上中下是否不同要另測。
4. 只有一支相對短的紀錄片、在「為娛樂而看」的情境；需要不同類型、長度與學習目的的重現。
5. 只看字幕處理，沒有把影像對理解的作用納入；沒有訪談或口語報告。
- RQ3 的正向趨勢作者自己說要小心，「due to the lack of statistical significance」（L1566–1567），也缺口語報告佐證（L1568–1570）。

## 與摘要說法不一致的地方

- 摘要說雙語與中文字幕「both outscored captions and no subtitles」——與 Table 2 一致。
- 摘要「L1 lines in bilingual subtitles were processed significantly longer than in L1 subtitles」：只在總閱讀時間與平均凝視時長成立（d = 0.28、0.18），凝視比例沒有差異（p = .12）。摘要沒提這個例外。
- 稿件內部的數字疑點（是較早版本的稿，刊出版可能已更正，無法核對）：
  - L993–995 交互作用檢定寫 χ²(2) = 39.44，p = .56；χ² 39.44 在自由度 2 下不可能 p = .56，其中一個數字有誤。
  - L1293 寫 t(49) = 2.65，p < .001；t = 2.65、df = 49 的雙尾 p 約 .01，不是 < .001。L1295 的 t(49) = 3.75 對 p < .001 則合理。
  - Table 2 的 d 值與 Table 1 的平均數、標準差對不太上：雙語對中文字幕平均差 0.55、兩組 SD 約 4.2–4.7，直接算 d 約 0.12，表上寫 0.26；雙語對英文字幕直接算約 1.06，表上 0.89。可能是用調整後的估計或別的算法，原文沒說明。不影響顯著性判斷，但**引 d 值時要註明出自作者稿、未對刊出版**。
  - 作者把 d = 0.82–0.87 稱為 small（L1225–1226），依他們自己在 L942–943 定的門檻（.70 為 medium、1.00 為 large）應為 medium 以上，描述與門檻不一致。
  - 文獻回顧把 Liao 等 2020 的樣本寫成 20 人（L445），討論與限制寫 N = 16（L466、L1468）。（Liao 原文見 `liao2020-bilingual-subtitles.md`：招募 20 人；眼動表格每格 16 人、認知負荷 18 人、回憶 15 人。）
- 除此之外逐項對過，沒有。

## 與清單「要撐的結論」不合的地方

清單（24#5）：「雙語字幕的理解與母語字幕相當；注意力多在母語那一行」。

- **前半撐得住**，但要帶條件：雙語 27.93 對中文 27.38（滿分 34），事後比較 p = .97。這是「沒測到差異」，不是等效檢定；受試者是 B2–C1、本來就慣用雙語字幕的中國留英學生，看的是一支 23 分鐘紀錄片，理解題用中文出。
- **後半撐得住**：雙語組字幕出現時，中文行總閱讀時間 42%、英文行 20%，英文行跳過率 43%、中文行 11%。但這是跨語言比較，作者自己說要小心。
- 清單沒寫、但寫文章時不能漏的：雙語與中文字幕**都**顯著勝過英文字幕（d = 0.89、0.56）；英文字幕對無字幕只有 p = .06。雙語字幕「沒增加認知負荷」是作者推論，本研究沒有量認知負荷。所有數字出自較早版本的作者稿。
