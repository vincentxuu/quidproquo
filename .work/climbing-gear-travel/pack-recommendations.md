# 背包推薦研究：多繩距、攀岩旅行、一般出國

查核日期：2026-10-19。僅研究筆記，尚非文章或作者實測。

## 方法與熱門的界線

初始完整 callable inventory 無 Groundlane；先使用 Exa web_search_exa / web_fetch_exa，未用平台 web。先搜尋當前 climbing / multipitch / travel backpack 比較，再讀官方與評測正文。Exa fetch 設 maxCharacters:80000 取得完整比較正文；不只根據搜尋摘要。其後主工作者提供已驗證可用的本機 Groundlane HTTP 路徑，遂用它重抓Climbing評測：HTTP200，證據存 `pack-gl-climbing.json`。這個200只驗證該頁Groundlane抓取，不把此前Exa來源冒稱Groundlane驗證；Groundlane本次20000字上限在Wadi段落中截斷，完整Wadi評測仍依Exa正文。熱門在此指「近期英語專業評測常見、官方仍有產品頁與販售標示」，不是銷量、市占、台灣岩場使用率排名。

母群分三類：背著攀爬的小包、搬裝備到岩場的大包、城市交通與住宿為主的旅行包。英語市場/美國官網偏重北美，Blue Ice 同時核對歐洲頁。未核台灣代理、庫存、台幣價格；官方有頁不等於各色/各尺寸有貨。Black Diamond 本次頁面顯示 Out of Stock，不能寫「現在隨處可買」。

評測利益：Climbing 明示 affiliate commission；Switchback 與 OutdoorGearLab 為導購型比較，適合交叉參考，不當作獨立銷量資料。研究者未實際背負；舒適、耐磨與路線經驗須明確歸屬評測作者。舊款評測不得直接套用新款規格。

## 正文可採用的選購結論

- 以多繩距攀爬為主：先比較Rock Blitz15與Wadi15，按實際水量/保暖衣物確認15 L是否足夠；BUG放現行款待補評測的兼用備選。
- 以sport/trad岩場旅行為主：比較Creek50與Cragsmith45，差別是背負、空重與取物方式，不選「全能冠軍」。
- 也要城市出國旅行：Farpoint40或MLC45作旅運主包，另放一個多繩距小包。行李箱/托運duffel也是合法配置，無需硬要求單包包辦。

### 社群可融入文章的短段落

「社群心得最有用的部分，往往不是『哪一款最好』。MountainProject 的討論裡，有人覺得15L足夠，有人因水袋與大接近鞋需要20L；同一系列也有人稱耐用、有人嫌不夠耐磨。這些是不同身形、路線與舊版產品的個人經驗。試背時把自己的水、鞋和保暖衣裝進去，再穿吊帶抬頭、伸手取裝備，比只看容量更能縮小選擇。」可連結上表2023與2021來源；這是資料綜合，非作者親身試背。
