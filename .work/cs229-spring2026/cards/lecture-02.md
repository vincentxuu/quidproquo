## 主問題

給一份成對的 (x, y) 資料，怎麼把「找一條好的線」寫成可以計算的問題，又有哪幾種算法把它解出來？

## 讀完的能力

1. 把預測問題寫成 h_θ(x) = θᵀx 與 J(θ) = ½ Σ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²，說明 x₀ = 1 與 ½ 的用途
2. 推導 ∂J/∂θ_j，手算一步批次梯度下降與一步 minibatch SGD
3. 說明步長太大／太小的現象，以及 SGD 為何在最佳解附近彈跳
4. 從矩陣形式推出 XᵀXθ = Xᵀy，說出 XᵀX 不可逆時解變成什麼

## 完整例子（本文自擬，非課堂內容）

資料 (1,2)、(2,3)、(3,5)，加 x₀ = 1。

- Normal equations：XᵀX = [[3,6],[6,14]]，Xᵀy = (10,23)，θ* = (1/3, 3/2)，J(θ*) = 1/12
- 批次 GD，α = 0.05，從 (0,0)：J 19 → 0.6325 → 0.1134；θ (0.5,1.15) → (0.58,1.345)；第 77 步 J 進到下限 0.001 內
- α = 0.2：J 19 → 102.52 → 555.13（發散；上限 2/λmax = 2/16.64 ≈ 0.12）
- 一步 SGD（batch 1，α_B = 0.05）：抽第 1／2／3 筆後 J = 15.845／11.534／4.406
- 在 θ* 上單筆梯度 (−1/6,−1/6)、(1/3,2/3)、(−1/6,−1/2)，和為零但個別非零

以上數字已用 numpy 重算。

## 自我檢查題與答案

1. 從 (0.58,1.345) 再走一步 GD → 梯度 (−0.19,−0.69)，θ = (0.5895,1.3795)
2. ½ 換成 25：θ* 不變；梯度放大 50 倍，同一步長可能發散
3. 加入 x₂ = 2x₁：XᵀX 不可逆，v = (0,2,−1) 在零空間；(1/3,3/2,0) 與 (1/3,7/2,−1) 預測相同
4. 在 θ* 抽第 3 筆做一步 SGD → θ ≈ (0.3417,1.525)，J 0.0833 → 0.0891
5. 依標籤排序不打亂：違反「minibatch 反映整體資料」，模型先倒向一類再擺回
