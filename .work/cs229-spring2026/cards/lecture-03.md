## 主問題

最小平方為什麼是合理的選擇？同一個理由能不能搬到分類問題？

## 讀完的能力

1. 從「零均值、IID、高斯」推出最大概似等於最小化 J(θ)，並說明 σ² 為何不影響解。
2. 解釋 p(y | x; θ) 的直線與分號。
3. 寫出邏輯斯迴歸的概似、對數概似，推出梯度 (y − h)x。
4. 推出一維 Newton 更新式，說明多維時 Hessian 的角色，以及每步 n·d² + d³ 的成本為何讓 SGD 成為主力。

## 完整例子（全部自擬，已用 Python 驗算）

1. 三筆資料 (1,1),(2,3),(3,2)、y=θx：θ=1 與 0.5 的 J 為 1、2.25；σ=1 時 ℓ 為 −3.757、−5.007；σ=2 時 −5.086、−5.399；最佳解 13/14。
2. x=1..6 兩群，最小平方分界 3.5；加入 (−23, 0) 後 θ=(0.4359, 0.0256)，分界 2.50，x=3 預測 0.513 被誤判。
3. θ=(−1,1)、x=(1,2)、α=0.1：h=0.731；y=1 更新後 h=0.757；y=0 更新後 h=0.654。
4. 三正一負只有截距：Newton 從 0 → 1 → 1.096339 → 1.098611 → ln 3；梯度上升 α=0.1 第 100 步誤差 3.5e-4。

## 自我檢查題與答案

1. Laplace 雜訊 → 最小絕對誤差。
2. σ=10 時例一兩個 θ 的 ℓ 差 0.0125，排序不變。
3. θ=(0,0)、x=(1,3)、y=1、α=0.5 → θ=(0.25,0.75)，h=g(2.5)≈0.924。
4. 直線是條件（觀察到的資料），分號是參數（非隨機變數）。
5. d=1e6、n=1e8：Newton 每步約 1e20，SGD 1e6，差約 1e14 倍。
