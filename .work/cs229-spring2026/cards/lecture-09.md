- **主問題**：沒有標籤時怎麼分群；硬指派（k-means）換成機率（GMM）之後演算法怎麼變；EM 為什麼需要 Jensen 不等式。
- **讀完的能力**：
  1. 手算 k-means 的指派與更新，並解釋失真函數 J 為何單調不增、為何只到局部最佳。
  2. 寫出 GMM 的生成過程，用貝氏定理手算 E-step 的 w，套 M-step 的加權平均。
  3. 用弦的圖說明 Jensen 不等式及凹函數的方向，指出它在 EM 下界中的位置。
  4. 說出 EM 的「造下界、爬到頂」圖像與它不保證全域最大的理由。
- **完整例子（全部自擬，課堂沒有數值例子）**：
  - k-means：點 1,2,4,7,9,10，初始 μ=(1,2)；J：142 → 45.2 → 26.84 → 21.5 → 15.5 → 9.33，停在 μ=(2.33, 8.67)。
  - 局部最佳：(0,0),(0,1),(4,0),(4,1)；左右分 J=1，上下分 J=16，兩者皆為不動點。
  - φ 的作用：μ=(0,4)、σ²=1、x=2；φ=(1/101,100/101) 時 P(z=2|x)=100/101。
  - EM 一輪：同六個點，初始 φ=(0.5,0.5)、μ=(2,8)、σ²=4；w₁(x=4)=0.818；M-step 後 φ=(0.476,0.524)、μ=(2.314,8.391)、σ²=(1.87,2.83)；log-likelihood −14.94 → −14.22 → −14.03 → −13.99。
  - Jensen：X∈{1,4}；x² 得 8.5 ≥ 6.25；log 得 0.693 ≤ 0.916。
- **自我檢查題與答案**：
  1. 點 0,2,3,10、初始 μ=(0,3) 跑 k-means → 最後 {0,2,3}、{10}，中心 (1.67,10)，J≈4.67。
  2. 解釋 J 在兩步都不增、為何不是全域最佳 → 逐項最小／平均是最小點；舉兩個不動點。
  3. μ=(0,4)、σ²=1、x=1 的 w₁ → φ 相等時 0.982；φ=(0.1,0.9) 時 0.858。
  4. X∈{2,8} 的 E[log X] 與 log E[X] → 1.386 ≤ 1.609；log 為凹，故得下界。
  5. w 全為 0/1 時 M-step 的 μ → k-means 的群平均；GMM 多估 φ 與 Σ。
