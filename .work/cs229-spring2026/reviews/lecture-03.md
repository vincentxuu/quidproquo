## 5. 數學驗算

全部用 Python 重算，與文中數字一致：

- **例子一**：J(1) = 1、J(0.5) = 2.25；σ=1 時 ℓ = −3.757、−5.007；σ=2 時 −5.086、−5.399；常數項 −2.757、−4.836；最佳解 13/14，J = 0.964。
- **例子二**：原資料 θ = (−0.4, 0.2571)，分界 3.5；加入 (−23, 0) 後 θ = (0.4359, 0.0256)，分界 2.5045，x=3 預測 0.5127，離群點預測 −0.1529。
- **例子三**：h = 0.7311；y=1 更新後 θ = (−0.973, 1.054)、h = 0.757；y=0 更新後 θ = (−1.073, 0.854)、h = 0.654。
- **例子四**：Newton 數列 0 → 1 → 1.096339 → 1.098611 → 1.098612，誤差 1.1、9.9e-2、2.3e-3、1.3e-6、4.2e-13；梯度上升 α=0.1 第 1、10、100、200 步為 0.1、0.657、誤差 3.5e-4、1.5e-7。
- **自我檢查**：第 2 題 0.0125；第 3 題 θ = (0.25, 0.75)、g(2.5) = 0.924；第 5 題 1.01×10²⁰ 對 10⁶，約 10¹⁴ 倍。
- **推導**：高斯對數概似、sigmoid 導數、邏輯斯梯度逐步跟過，成立。梯度與 Hessian 公式另用隨機資料對有限差分核對（誤差 2e-9、9e-8），Hessian 特徵值全為負。
- **加權最小平方**：各點變異數不同時，對數概似含 θ 的部分是 −½ Σ (1/σᵢ²)(y − θᵀx)²，權重 1/σᵢ² 正確。
- **梯度更新式正負號**：文中從 ∂ℓ/∂θⱼ = (y − h)xⱼ 到 `θ := θ + α(y − h)x` 自身一致，與講義式 (2.2) 及其後的 stochastic gradient ascent rule 相同。講者兩處說法（43:56、44:56）在文中的轉述沒有矛盾。
- **KaTeX**：修改後全文 342 段公式，錯誤 0。
