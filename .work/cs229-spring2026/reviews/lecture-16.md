## 5. 數學驗算

全部用 Python 重算，結果與文中一致：

- KV cache：2×32×128 = 8,192；×32 層 = 262,144；×2 bytes = 524,288；×10⁵ = 5.24×10¹⁰ bytes ≈ 52.4 GB（十進位）。n_g=8 → 13.1 GB；n_g=1 → 1.64 GB。
- g(j)：n_h=8、τ=4 → head 1–4 為 1，5–8 為 2。自我檢查 1：g(7)=2，KV cache 1/4。
- √d_h：d_h=256 標準差 16（另做 2 萬次模擬得 16.02）；e¹⁶ = 8.89×10⁶；e/(1+e) = 0.731。「完全同向的向量內積是 d_h 量級」成立（a·a = Σa_i² ≈ d_h）。
- sliding window：10⁶×10³ = 10⁹ 對 10¹²。回看範圍每層延伸 w−1，L 層共 L(w−1)，w=3 兩層得 4，寫手的推論正確。自我檢查 3：L×w = 98,304（精確值 98,280）< 199,999，看不到第 1 個 token；8.19×10⁸ 對 2×10¹⁰，比值 1/24.4。
- MoE：α = (0.625, 0.375)，輸出 (1.25, 1.5)；未正規化 (1.0, 1.2) = 0.8 倍。自我檢查 4：(0.25, 0.75)。
- ICL：2+3=5、6+7=13、15+2=17。
- SFT：0.6931 + 1.3863 = 2.0794 = −ln 0.125；每 token 1.04。
- 式 17.32、17.34、17.35、17.36、7.51 與 MoE 的 α 式逐一對照講義，抄寫正確。
