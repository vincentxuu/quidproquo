# 英文口說 PoC 核對

範圍：六情境 19 主卡與 19 延伸句。核對中文、對話動作、句型與術語；逐卡來源放回練習頁。

主要修正：
- ticket 舊題把找到票與持有票混合。新題 ticket-present 明確出示票，Here’s my ticket / Here is my ticket。新目的不沿用舊熟悉度。
- paddle out 中文改為划出去；離岸風追問標明意思。
- belay 明確有繩攀登，請人確保與準備完成口令有別。
- How did you do... 明確朋友剛完成；腳點追問過去放置。
- weekend 明確已過的週末；面試內容為角色練習、須依自己的經驗調整。
- 延伸句分清替換、追問、補充；不把不同目的當同義句。

資料範圍：多數完整句為依來源用法改寫；週末主句在教材直接出現。來源不代表整段自寫情境有原文佐證，也不支持最自然／最常用等比較。沒有母語者測試或語料頻率研究。
