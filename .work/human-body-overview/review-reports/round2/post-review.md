## 🔴 必修

1. 「主脊」與表格不是同一條線，讀者看不出表格怎麼從主脊長出來（地圖節第 1–2 段 + 表）
   - 主脊句：神經 → 肌肉 → 肌腱 → 骨頭（再加能量／血管）。表格卻是 零件（骨、肌肉、肌腱）→ 能量 → 適應 → 動作 → 疼痛 → 年齡 → 找不到證據。主脊的第一環「神經」在表中要到「適應」「動作與平衡」才出現，順序還是反的（表從骨頭開始）。description 寫「神經、肌肉、肌腱、骨頭」，表第一列寫「骨頭、肌肉、肌腱」，也是這個落差的症狀。
   - 後三段（疼痛與姿勢、年齡與差異、找不到證據）根本不在主脊上，文章沒說它們是「主脊上常見問題」，讀者會把它們當成另外三個主題。
   - 「從看得到的零件，走向不容易看到的機制」是第二條排序原則，和「神經先送訊號」那條因果鏈並存，沒有說誰管誰。
   - 修法：(a) 主脊句改成與表同序，例如「骨頭、肌肉、肌腱組成會動的零件；能量讓它們出力；神經指揮它們；練過之後這些都會改變」，並把表加一欄「對應主線哪一環」（零件＝骨／肌／腱；能量＝收縮耗能；適應＝負荷後三者與神經的改變；動作＝神經控制）；(b) 表後補一句「後三段是在這條線上最常出現迷思和例外的地方」。(c) 不然就誠實說：主脊解釋一個動作怎麼發生，表格是學習順序，兩者不同，並說明為什麼這樣排。
   - 規劃表的弧線是「零件 → 能量 → 適應 → 神經與動作 → 疼痛 → 年齡 → 找不到」，正文與它一致，要動的是主脊句，不是表。

2. 主脊裡兩個斷言沒有 inline 來源（地圖節第 1 段）
   - 「收縮要消耗能量，肌肉也靠血管送來氧氣、帶走廢物」沒有連結；前兩個斷言有 OpenStax 連結，這一句沒有。依 8.5 屬必修。補 OpenStax §10.3（Muscle metabolism）之類實際讀過的頁面連結，或刪去血管那半句（能量系統是 order 4，這裡也是越界的預告）。
   - 「WHO 的指引主要建立在系統性回顧上」（Q1）、「WHO 用 GRADE 分四級」（Q2）、「強力與有條件兩種」（Q3）這些外部事實，連結只掛在節首一次，建議在 Q1／Q2 的句子再掛一次 WHO 連結，並待 post-verify。

3. 第二個例子對 Lazarczuk 2022 的說法略超出來源（Q4）
   - 「其中 3 項納入受過良好訓練的人，這幾項都沒有看到肌腱硬度的變化」：精讀紀錄（claims #7）寫的是「髕腱（PT）硬度」沒有變化，且出自作者的 Limitations；正文寫成泛稱「肌腱硬度」。改成「髕腱硬度」，或說「作者指出這 3 項沒看到髕腱硬度變化」。
   - 「受試者多半沒有訓練背景」：來源是「未受過訓練或休閒運動者」，建議照寫。
   - 「發現…變硬」：來源是 associated with（訓練前後差，無對照），後面雖有補充，但前半句是因果語氣；可改「訓練後測到變硬」。

## 🟡 建議修

1. 前三段缺的東西（開頭）
   - 做到的：說出誰（不需背景的成人）、做什麼（一篇一部位／機制並標證據可靠度）、不做什麼（不診斷、不開課表）、讀完能做三件事。
   - 缺：(a) 開頭三問在本篇沒有答案，也沒說答案在哪，讀者會覺得被騙；加一句「這篇不回答它們，只教你怎麼判斷；肌力在『適應』，背痛在『疼痛與姿勢』」。(b) 沒說這系列大約多長、從哪開始讀（規劃表是 21 篇，但篇目會變，不必寫死數字，可寫「共約二十篇，順序依地圖」）。(c) 「部位或機制」「證據」對沒接觸過的人偏抽象，第 2 段加一個具體例子（如「肌腱怎麼因負荷改變」）。
   - 這篇對台灣讀者的位置（6.65）幾乎是零：全文沒有台灣來源，規劃表把國健署指引列為 order 0 主力來源卻沒用上。至少加一句：台灣國健署也有成人身體活動建議，讀它時一樣可以問這四題；或在第 2 段說明為何用 WHO。這是規劃表的承諾落空，不是風格偏好。
2. 「證據四題」的結構：Q1 其實是兩個問題（單一還是整合／研究設計與因果），且「關聯不等於有效」只在 Q1 末尾一句帶過。規劃表 order 0 明列「關聯不等於有效」。建議：Q1 只講整合 vs 單一；把「觀察性研究只看到一起出現」與「有無對照組」獨立成一題或明確標成 Q1 的第二半，讓四題變成：來源（單一／整合）、設計（對照／觀察）、確定性、對象。若不想變成五題，可把 Q3（建議強度）降成 Q2 的延伸，因為對讀者的行動是同一個——「問證據哪一級」。
3. 每題的可執行動作不均（讀者很難拿來用）
   - Q1：沒有動作。補「看見數字時，找一個『整理了多少項研究』的字眼，找不到就當單一研究」。
   - Q2：只有定義，沒說網路上大多數說法根本沒有 GRADE 等級時怎麼辦。補「沒有人說明確定性＝當作未評級，不要當作高」。這句話才是可帶走的動作。
   - Q3：舉了「強力建議／證據低」的例子很好，但沒說為什麼會這樣（WHO 在利弊權衡後認為即使證據弱也值得建議）。缺這句，讀者可能誤以為 WHO 自相矛盾或強建議不可信。
   - Q4：動作隱含在「像不像你」，可補成「寫下研究對象的年齡、訓練程度、部位，和自己逐項比」。
   - 文末「兩個動作」只覆蓋 Q1／Q2／Q4，Q3 沒有對應步驟。動作 2（抄表 2 的四級定義）價值偏低，且「表 2」未驗證；改成「拿一個你關心的建議，回 WHO 指引找它的建議強度與證據等級」更貼近 Q3，也更像動作。
4. Q4 的第二個例子過重、位置不對
   - 一句話塞了 61 項、15 人、3 項、下肢四個限制（register-scan 數字密度命中此段）。其中「無對照組」「樣本小」屬 Q1／設計問題，只有「對象：健康成人、多未受訓、受訓者無變化、只涵蓋下肢」才是 Q4。
   - 這也踩 6.8 主題歸屬：order 3 就是這篇統合分析的主場，總覽把它的限制幾乎講完了，order 3 要不重複就得縮。建議總覽只留對象相關的兩點，其餘留給 order 3；「手指滑車或肩膀」那半句是好的橋，保留。
   - 第一個例子（WHO 不處理競賽訓練）只一句，也沒說「如果你是競技選手怎麼辦」；與「例子偏向攀岩」相扣的話，可改成攀岩者讀到「久坐／一週 150 分鐘」類建議時，要注意對象是一般成人。
5. 會過期或有風險的句子
   - 「段落和其中的主題，之後會依能找到的可靠證據增刪」：已是軟承諾，可以，但地圖的七段含「找不到證據的說法」「性別、身體組成」，規劃表標 🔴 的 order 10、12 還沒決定補或降級；表中「動作」「疼痛是什麼」行若最終被砍，表會與系列不符。發布前用 series.ts 實際登錄的篇目對一次表。
   - 「站內另有攀岩的應用系列」：目前有入口文，但這是跨系列連結，篇目不由本系列控制；可接受，但注意中文標題是「攀岩卡關該開始訓練嗎：分辨技術、心態還是體能，以及九篇閱讀順序」，正文用的短名〈攀岩卡關該開始訓練嗎〉與 H1 不完全相同（zh），en 則完全省略副標。這屬可選的一致性，見 🟢。
   - 「今晚就能做」是時間詞，無害，但標題若日後被引用就怪；可改「現在就能做」。
6. description 與 tldr 內容高度重疊（兩者都是主線 + 四個問題）。description 建議改成對搜尋者的利益點，例如「一張把骨頭、肌肉、肌腱、神經串起來的地圖，加上判斷健身說法的四個問題」；tldr 保持現狀即可，但「沿著一條身體運作的主線」仍抽象，可換成「從骨頭、肌肉到神經與疼痛」這類具體名詞。
7. 範圍：規劃表 order 0「不講任何具體訓練建議」——本文沒有越界（沒有組數、重量、頻率；「兩個動作」是讀者判斷練習，不是訓練處方）。✔。但規劃表 order 0 另要求「每篇在地圖的哪一段」：目前只列段落、不列篇，讀者不知道「肌腱」在哪一段。若不想寫死篇數，可在表加一欄「例如」（零件：骨頭與關節、肌肉怎麼收縮、肌腱）。
8. 發布前行政項（非內容）：series.ts 尚無「認識人體」登錄（規劃表自述），draft: true；英文版系列名是「Understanding the Human Body」，zh 為「認識人體」，登錄時要兩邊對上，否則 lang-parity／series-order 檢查會紅。

2. glossary 三條好；Q1 的核心詞「觀察性研究」「對照組」與 Q3 的「強力建議／有條件建議」正文有用卻未定義，若採 🟡-2 的重組，這些最該進 glossary（比現有三條對讀者更有用）。
3. 兩版對照（零差異清單）：結構、H2 數、表格七列、連結目標、glossary 三條、數字（61、15、3、四級、五件事）完全一致；zh 的 aliases 與 en 的 aliases 互指正確。可選差異：en 的 difficulty 仍是 `入門`（schema 是中文 enum，合法）；en 的 check-post-references WARN 可忽略；zh 攀岩連結寫短名而 en 寫完整英文標題（連結目標都對，-en 後綴也對）。修 🔴-1／🟡-2 後兩版都要同步改，翻譯時別只改一邊。
