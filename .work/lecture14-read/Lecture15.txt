                         Move Operations
       The mov instruction copies bytes from one location to another.
   It’s akin to the assignment (=) in C where the arguments are reversed.
                              mov src,dst

src can be any one of:
• Immediate                $0x314
                                             dst can always be a register, but it can never
                                              be an immediate. It can also be a memory
                                            location, though only one of src and dst can
• Register                  %rbx                 be a memory location in any one mov
                                            instruction. x86-64 doesn’t support arbitrary
                                                     memory-to-memory moves.
• Memory Location        0x6005c0

int sum_array(int arr[], int nelems) {       We’re finally understanding some real
   int sum = 0;                          assembly! What makes sense at this point?
   for (int i = 0; i < nelems; i++) {
      sum += arr[i];                   • Registers store addresses and values
   }                                   • mov src, dst copies value from src to dst
   return sum;                         • sizeof(int) is 4
}                                      • Instructions executed sequentially by default

                     From Assembly to C
Spend a few minutes thinking about where the mov instruction might come
into play. What line of C might compile to each of the following?
• Examples:
1. mov        $0x0,%rdx                                long y = 0;
2. mov       %rdx,%rcx                               long offset = y;
3. mov       $0x42,(%rdi)                              arr[0] = 66;
4. mov       (%rdi,%rcx,8),%rax                   long w = arr[offset];
