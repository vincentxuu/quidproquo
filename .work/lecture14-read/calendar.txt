Lecture Code

Any code examples worked in class will be posted into
/afs/ir/class/cs107/lecture-code/lect[N] where you replace [N] with the
lecture number. You can make a copy to compile or modify by doing the
following, which will make a folder in the current location called
lect[N] that is a copy of the lect[N] code.

    cp -r /afs/ir/class/cs107/lecture-code/lect[N] lect[N]
