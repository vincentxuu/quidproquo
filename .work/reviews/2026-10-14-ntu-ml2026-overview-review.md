## 3. 「手算一次」KV Cache（zh L52–70／en L52–70）

- Llama 2 7B：32 層、32 個 attention head、hidden 4096 → head 維度 128；7B 是 MHA（KV head＝32），設定正確。
- 2×32×32×128×2 = 524,288 bytes ✔；= 0.5 MiB ✔（十進位是 0.524 MB）。
- ×4096 = 2,147,483,648 bytes = 2 GiB ✔；×16 = 32 GiB ✔。
- GQA KV head 32→8：四分之一，16 段 8 GiB ✔。
- 自我檢查第 3 題：0.5 MiB × 32768 = 16 GiB ✔。
- 權重：Llama 2 7B 約 6.74B 參數 ×2 bytes ≈ 13.5 GB（12.6 GiB），「約 13 GB」合理；32 GiB 與 16 GiB 都明顯大於它，結論不受單位影響。
- 例子有條件、計算、結果、意義（L70），且明示是本文教學例子（L54），符合契約。

建議（不擋）：
- 3-a：「剛好 0.5 MB」嚴格說是 0.5 MiB；可加一句「這裡 1 MB 取 2²⁰ bytes」，或改寫為「約 0.5 MB」。
- 3-b：Llama 2 7B 原生 context 是 4096、本身沒用 GQA；GQA 那段與第 3 題的 32k 都是假設情境。可在 L68 寫「假設改用 GQA（Llama 2 70B 與之後許多模型的做法）」、第 3 題寫「假設模型支援 32k」，避免讀者以為 7B 本身如此。
