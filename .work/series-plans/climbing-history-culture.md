## 目標讀者

在岩館爬了一段時間、開始好奇「為什麼抱石用 V、先鋒用 5.10」「龍洞的路線是誰開的」的台灣攀岩者，不限程度。不寫給：想學打 bolt 倫理的人（C 系列〈誰決定一條線要不要打 bolt〉）、想看奧運規則與賽程的人（K 賽事系列）、想找書的人（〈攀岩書籍知識版圖〉）。

## 入口

order 0 是世界史，用讀者在岩館摸得到的東西開場（粉、岩鞋、岩點、難度表、自動確保器旁的比賽海報），一樣一樣倒推回它出現的年代。讀完後讀者知道自己每次去岩館用的東西各有一段歷史，接著讀台灣史看這些東西怎麼傳到台灣。

## 弧線

世界：岩館裡的東西從哪裡來 → 台灣：這些東西怎麼傳進來、誰在龍洞開路線、岩館怎麼變多（書單〈攀岩書籍知識版圖〉不收進系列，只從兩篇連過去）

排序原則：可見先於不可見（從岩館裡的物件倒推歷史，不從 1864 年順寫）；先世界後台灣，台灣篇才能說「這件事在台灣晚了幾年」；兩篇都是概念文，不需要五層結構；有爭議的年份並列，標出來源；跟 C、K、書單重疊的地方只放一段加連結。

## 斷崖處理

- 0：世界史範圍 150 年，容易變成年表。只回答一個問題（岩館裡的東西從哪裡來），每個物件一節，年份密集的部分收進 `<details>` 年表；clean climbing 與運動攀登各一段，連到 C 系列 order 15，不重講。
- 0→1：世界史結尾用「1970 年代末，台灣攀岩者讀著朋友從美國帶回的《Climbing》雜誌」（AAC 專訪）接到台灣篇。
- 1：龍洞的 bolt 年表 C 系列 order 15 已經整理過，台灣篇只講 bolt 以外的事（俱樂部、觀摩會、指南、岩館、組織），bolt 事件一句帶過並連結。
- 1：台灣篇牽涉戒嚴（出國要以運動代表隊名義申請、大砲岩砲管被毀），只寫跟攀岩有關的事實與來源，不延伸評論。
- 1→K：中正盃之後的台灣賽事只寫到 1990 年代，現行賽事連 K 系列〈亞洲與台灣賽事〉（K 尚未寫，寫台灣篇時先放純文字預告，K 上線後補連結）。

### 範圍卡

- **order 0**：講三個發源地（1864 薩克森 Falkenstein、1886 Napes Needle、1887 多羅米堤 Vajolet 塔）與「攀岩從登山分出來」的意思；1911 Preuss 六條規則與 1913 薩克森規則（倫理比 bolt 早了半世紀）；難度等級（1923 Welzenbach／UIAA、1956 YDS、楓丹白露）；岩鞋（1935 Allain）；繩子（二戰後尼龍、1953 kernmantle）；抱石與粉（1934 楓丹白露、1958 John Gill）；大岩壁（1958 The Nose）；人工岩牆（1937 比利時、1939 Seattle、1964 Leeds）；比賽（1940s 蘇聯速度賽、1985 SportRoccia、1989 世界盃、1991 世錦賽、2007 IFSC、2021 東京）。不講：clean climbing 與運攀的倫理爭議（一段＋連 C order 15）、攀岩文學（連書單）、奧運格式與計分（連 K）、高山攀登史（H 系列）。讀完後讀者能指著岩館裡任三樣東西說出它大約出現在哪個年代、從哪裡來。例子：拿 V 級與 5.10 解釋為什麼抱石和繩攀用兩套等級。自我檢查：「楓丹白露和 John Gill 誰先開始抱石？」答：楓丹白露 1930 年代（Allain），Gill 1950 年代把體操動作和粉帶進來，兩者是不同的傳統。前置：無（可搭配〈攀岩入門〉）。
- **order 1**：講日治時期臺灣山岳會在大砲岩的講習會（1930 年代，國家攝影文化中心照片）；戰後林淵霖與 1951 年「攀岩」一詞第一次出現；1967 年前後用軍用麻繩岩訓；1972 百岳熱潮下攀岩不受重視；1981 攀岩者俱樂部（RCC）成立、1982 第一屆全國攀岩觀摩大會（大砲岩、26 人）、觀摩會到中正盃（1986）、RCC 加入中華山協後的海外攀登（1986 白朗峰、1987 優勝美地）；龍洞發現（1976／1977／1978 並列）、1987 解嚴後大量開發、1989 龍洞宣言、1993 手繪路線圖、1995 國人第一條 5.13a、1998／2005／2012 三本指南；岩館（1997 蘭州街國手訓練中心→1999 對外營運→2004 商業化→2012 熄燈；2015 起抱石館三倍）；組織（1996 攀登協會、1997 中華山協攀岩委員會、2020 TOCC）；AAC 專訪的四個世代說法。不講：龍洞的 bolt 事件與倫理（一句＋連 C order 15）、各岩場岩質與規定（連 C order 14）、現行賽事（連 K）、高山遠征史（只提 RCC 那幾次作為「攀岩從登山分出來」的證據）。讀完後讀者能說出台灣攀岩的三個轉折（1981 RCC 把攀岩從登山分出來、1987 解嚴後龍洞大量開發、2010 年代中期抱石館讓攀岩變成城市運動），並知道自己在龍洞爬的路線大約是哪個年代開的、去哪裡查。例子：1982 年第一屆觀摩會的評審發現「臂力好就能爬完，不必用平衡技巧」，對照今天岩館 new school 路線。自我檢查：「台灣第一間岩館是哪一間？」答：看「第一間」怎麼定義，1997 蘭州街是國手訓練中心、1999 對外營運、2004 商業化，2001 年前 Y17 也已營運，所以沒有單一答案。前置：order 0。
