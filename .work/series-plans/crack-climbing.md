# 系列規劃：裂隙攀登技術（crack-climbing）

使用者確認：2026-10-26（回覆「可以，照這樣寫」，13 篇 order 0–12；先寫總覽＋手掌裂隙給使用者看）

研究筆記：`.work/research/crack-climbing/research-note.md`（各主題檔同目錄）。

## 目標讀者

會在岩館爬、讀過〈裂隙怎麼爬〉總論（攀岩動作技術 order 9），想去龍洞或出國爬傳攀、要把每種尺寸練到能用的台灣攀岩者。不寫給：完全沒碰過戶外的人（先讀總論與 C 系列）；要學放保護的人（C 系列〈傳攀保護〉）。

## 入口

order 0 是總覽：裂隙按尺寸分成哪幾種、每種用身體哪部分、對應幾號 cam、手大小怎麼改變答案、全系列每篇在哪個尺寸，以及世界上哪些岩場以哪種尺寸出名。前置：〈裂隙怎麼爬〉。

## 弧線

總覽（尺寸地圖）→ 手掌（最先學、最穩）→ 腳塞（配手一起用）→ 指裂 → 薄手／ring lock（最尷尬的尺寸）→ 拳 → 寬裂 → 擠身縫與煙囪 → layback、內角與斜裂（組合）→ 屋簷 → 膠帶、手套與鞋 → 訓練與學習路徑 → 日本與韓國的裂隙岩場與影片

排序原則：從最穩、最好學的尺寸開始，往窄和往寬兩邊擴；一篇一個尺寸；組合技（layback、斜裂、屋簷）放在單一尺寸都會之後；裝備與訓練放後段當工具箱。

## 斷崖處理

- 3→4：薄手在指與手之間，兩邊都塞不好，放在指裂後、借用指裂的 ring lock 與手裂的緊手概念。
- 5→6：拳到寬裂是質變（從「手卡住」變「全身卡住」），order 6 開頭用尺寸地圖重新定位，arm bar／chicken wing 先講再講 stack。
- 8→9：屋簷需要倒掛塞腳與翻出唇緣，前置 order 1、2、8。
- 每篇派別之爭並列（knee lock、T-stack、腳塞深度、頂繩練寬裂），不選邊。

## 共用規格

教學口吻、約 4,000 字；每節至少一個「今晚就能做的動作」；每個技巧附 3–6 支 2020 年以後的影片，盡量來自不同岩場、不同人（職業／教練／一般攀岩者、女性、大手／小手），至少一支日本或韓國；影片以 `youtube` fence 嵌入，有字幕／章節依據才加 `start`；每篇有「大手／小手」段；文末「練習題：N 個情境」3–5 題 `<details>`；中英同步；每篇 `.work/reviews/<slug>.md` 三節審稿。

## 範圍卡

- **order 0**：講尺寸分類（指尖／指／薄手／手／拳／寬裂／擠身／煙囪）與 cam 號數對照、身體部位、手大小對照表、塞的共通原則（只簡述，連總論）、世界裂隙岩場對尺寸。不講單一技巧細節。讀完後讀者能看一條縫判斷尺寸並知道該讀哪篇。
- **order 1**：講塞手步驟、拇指朝上／朝下、緊手／標準／鬆手、交叉 vs 平移、大手小手。不講腳（order 2）。讀完後讀者能在岩館裂隙或龍洞手縫做出能掛重的塞手。前置：order 0。
- **order 2**：講各尺寸腳塞（指縫腳尖、手縫整腳轉入、拳寬縫腳）、深度、腳跟下沉、取出、鞋子簡述、卡腳風險。讀完後讀者能在手縫用腳站穩不痛。前置：order 1。
- **order 3**：講拇指朝下／朝上指塞、指節卡點、pin scar、指縫腳法、何時改 layback。讀完後讀者能分辨指縫三種寬度並選對塞法。前置：order 1、2。
- **order 4**：講 ring lock、thumb cam、緊手、finger stack、為何這尺寸最難、大手小手差異最大。讀完後讀者能在薄手尺寸做出 ring lock。前置：order 3。
- **order 5**：講拳塞掌心朝內朝外、緊拳鬆拳、拇指位置、拳縫的腳。讀完後讀者能做出不轉動的拳塞。前置：order 1、2。
- **order 6**：講寬裂共通原則、arm bar、chicken wing、hand stack、leavittation、heel-toe／knee lock、側向選擇、裝備，派別並列。讀完後讀者能在寬裂用 arm bar＋heel-toe 往上移。前置：order 5。
- **order 7**：講 squeeze 的肩髖呼吸、煙囪背腳對撐與 stemming、從煙囪轉回裂隙。讀完後讀者能在煙囪安全上移。前置：order 6。
- **order 8**：講 layback 判準（韓國教練三條件）、jam-back、內角對撐、斜裂上下手方向與平移。讀完後讀者能在內角決定塞或 layback。前置：order 1–3。
- **order 9**：講屋簷手先或腳先、倒掛腳塞、拇指耐力、翻唇緣。讀完後讀者能說出屋簷裂隙的動作順序並在岩館屋簷練。前置：order 1、2、8。
- **order 10**：講膠帶手套貼法與重複使用、五款市售手套比較與爭議、裂隙鞋選擇、皮膚保養。讀完後讀者能貼出一副可重複用的膠帶手套。前置：order 0。
- **order 11**：講 80% 靠實際去塞、岩館裂隙牆、自製 crack machine、頂繩繞圈、課程（美加英日韓台）、受傷預防。讀完後讀者能排出一個月的裂隙練習計畫。前置：order 0。
- **order 12**：講日本、韓國主要裂隙岩場與岩質、各岩場代表路線、各技巧的日韓影片清單、日韓教學頻道。連本站日本岩場、韓國岩場系列。讀完後讀者能選一個日韓岩場並找到該看的影片。前置：order 0。
