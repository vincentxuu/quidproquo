## 系列範圍與選案

母群分為三段：成人口說的既有方法與證據文章、具體溝通任務教材、台灣成人可使用的真人／AI／實體／海外／交換管道。本輪收錄範圍由 `.work/english-relationship-audit/unified-series.json` 記錄，既有30篇與下表新增4篇構成最終34篇，不按「英文」關鍵字把其他教學寫作或軟體文章收進來。

方法與情境是系列的正式內容，讀者可先在站內開始練，再依遇到的卡點選擇外部回饋。具名服務仍各有專篇，介紹課型、流程、老師／教材、完整費用組成、預約／取消／退費、社群經驗、具體任務與限制。官網可證實方案；個人心得用來形成試課觀察問題，不證明成效或整體品質。

## 依賴與斷崖處理

order 0 是共同入口；order 1–3 建立練習方式與證據界線，order 4–18 可按近期情境選讀。第一次練習卡住後，再從 order 19–31 選能補足回饋的管道；order 32–33 把上課與選擇帶回下一輪練習。已有明確需求的讀者可直接跳進對應情境或平台，但要帶著同一個任務檢查。

| 位置 | 認知跳躍／風險 | 橋接與檢驗 |
|---|---|---|
| 0→1 | 看完總覽仍只想挑品牌 | 先錄一段自己會遇到的工作或生活任務，留下第一個卡點；沒有必要先買課 |
| 1→2 | 方法整理容易被讀成固定天數的效果承諾 | 立刻讀跟讀研究，區分來源建議與實證結果；能說出一項研究支持的範圍和一項未測的能力 |
| 2→3 | 知道研究限制，卻不知道實際如何選材料 | 用agency既有原音區段示範：理解→模仿→不看稿說意思→換成自己的例子；原站字幕和頁內全文分開 |
| 3→4 | 跟得上原音，被誤當作自己能組句子 | 情境篇改由中文需求起步，先自己說再對照；接一個不同條件或追問，不能只追著聲音唸 |
| 4→5 | 從一般旅遊跳到攀岩專用詞與安全口令 | 先練租裝備、時段與路線需求；口令需與夥伴約定，英語練習不取代攀登技能與現場安全查證 |
| 6→7 | 能報進度卻無法處理來回協作 | 從陳述卡點轉到澄清、委婉異議與補救，確認對方能理解下一步 |
| 8→9 | 跟朋友聊天轉成正式面試，容易照搬別人履歷 | 情境可借，經歷不可借；以本人真實專案替換角色、數字與成果，區分轉述、猜測和已知 |
| 10→11 | 技術故事跳到STAR模板，容易只背格式 | 用既有專案補出背景、個人任務和結果；模板用來組織，不替代內容 |
| 11→12→13→14 | 從準備好的故事轉到技術解題、未知追問與設計取捨 | 演算法／系統設計知識視為讀者已有背景，本系列只練如何把思路說清楚；不懂就先澄清、標示假設或承認未知 |
| 14→15–18 | 從準備面試回到日常、旅程異常與運動現場 | 依近期需要選讀：日常分清意思、旅遊按缺的資訊問、衝浪問不同現場條件、岩館分清請示範與提供beta的角色。醫療、航空政策及運動安全不由句型替代 |
| 18→19–31 | 從自己練直接跳到購課選項 | 帶同一題與卡點去試用；線上、AI、實體、海外與交換依需要選讀，不要求依序買遍 |
| 真人立即課→固定老師 | 不限堂數容易變成最低單價幻想 | 比較延續性、可用時段與預約成本；不要用理論最大課量當實際成本 |
| 線上→實體／海外 | 把到校或出國等同進步 | 同時計入出席、通勤、住宿與課外互動，檢查是否留出自己說話的機會 |
| 31→32→33 | 上過課／交換過就以為完成學習 | 留下回饋再同題重說，接未準備的追問與換情境；用結果調整管道，不把背稿流利當遷移證據 |

前置知識：不要求先讀語言學論文；order 2 用白話區分研究測量與生活對話。order 12、14 的演算法與系統設計僅作說話場景，非技術入門課；缺技術背景時先選旅遊、工作或日常篇，不讓技術名詞成為全系列門檻。
