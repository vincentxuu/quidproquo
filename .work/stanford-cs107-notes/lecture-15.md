## Agenda and evidence

- Move instructions and operand forms: immediate, register, absolute memory, indirect, base+displacement, indexed, scaled indexed.
- General address expression combines displacement, base, index and scale; scale is 1, 2, 4 or 8.
- Practice traces distinguish loading a value from computing an address and reverse assembly into C array access.
- Revisits `sum_array`, then uses several etudes to infer variables and expressions from operand choices.
- Ends with a preview that arithmetic/control instructions build on the same register-memory model.
