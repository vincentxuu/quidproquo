# ADR 0003：來源導讀由 agent 選題，英文原音預設附跟讀

日期：2026-10-10

## 背景

使用者提供多種文章、訪談與影片來源，希望同時理解主題並練習英文；由使用者逐篇先定讀者問題，增加寫作前的負擔。

## 決定

由 agent 依來源證據、本站既有內容與讀者用途決定問題、角度及大綱。有英文原音的導讀預設加入短摘錄、中文對照、原音定位與練習；未核對部分明示待補。完整規則見 `docs/content-source-writing-rules.md`，執行入口為 post skill。

2026-10-10 修正：交付明分「頁內逐字稿對照」及「原站字幕跟讀」。短引文、理解摘要與影片入口不能取代使用者要求的完整段落對照；實際形式與要求不同時記錄缺口，不能自行宣告完成。以 post skill 交付檢查表逐段留下證據，並核對中英文入口和部署結果。

## 理由與後果

把選題責任交給 agent，讓使用者提供來源即可開始。自主選題不允許編造原話或個人經驗；取得字幕不代表可全文轉載，也不代表原音已核對。發文頻率與定期收集流程仍待另訂。
