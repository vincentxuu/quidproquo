# ADR 0004：課程導讀標題與教學驗收

## 背景

課程文章混用第 N 講、L N、週次與分篇，頁尾又使用日期鄰文；部分導讀把来源查核放在概念解說前。使用者於 2026-10-11 核准全數標題與導讀修正，並要求防止再次發生。

## 決定

中文標題採「主題｜課程 第 N 堂」，英文採「Topic | Course Lecture N」。週次、作業、實驗、助教課、原有分篇與總覽保留實際角色；官方第 0 堂保留，無原課序號的重組文章用主題單元，不從 series.order 推堂次。保留 URL 與日期。頁尾依主系列 order 導航。五個寫作 skill 共用 course-guide-contract，確定性標題檢查併入 pnpm verify；全批遷移後不再豁免舊標題。來源底本和可用性限制保留，但來源區排在教學主體後。教學內容修正須具體例子、理解檢查與独立語意審稿，不以 lint 宣稱教學驗收。

## 理由與後果

同系列能辨認課程位置，台灣讀者使用「堂」，課程來源狀態不再取代導讀。機械檢查負責可判定的格式、範圍與雙語一致性；語意審稿負責學習目標與例題對齊。查證、格式、教學與正式發布分開回報。
