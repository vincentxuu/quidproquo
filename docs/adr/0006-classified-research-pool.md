# ADR 0006：依主題分類的共用研究池

日期：2026-10-24。狀態：Accepted。

## 背景

城山找片發現大量跨頻道候選，但資料只留在單次研究目錄，下次研究容易重做搜尋或只沿用熟悉頻道。使用者要求所有有機會共用的研究與搜尋成果回到pool，而且依主題分類，不限頻道。現有deep-research有每次來源清單，岩場索引偏向已採用主張，兩者不能取代包含未採用候選與查核歷史的共用來源入口。

## 決定與理由

採 `.research/pool/`，主題類別沿用網站16類別並設子題，來源類型另作欄位。來源以canonical URL產生穩定ID且全球唯一；閱讀觀察與搜尋紀錄按研究ID獨立保存，不把前次讀取狀態覆寫成全域可信標籤。來源在首次登錄類別保留實體，後續跨分類以同ID合併分類、增加觀察，避免複製漂移。由 `AGENTS.md`要求有重用價值的公開研究先查、補搜、每輪寫回；deep-research與post另提供操作入口。CLI寫入預設dry-run，明確`--write`後使用排他鎖，寫前整體驗證；不宣稱跨檔交易。

## 後果

來源、工具失敗、衝突與淘汰理由可跨研究重用；引用時仍須核對讀取範圍與新鮮度。單次臨時搜尋也遵守指引，但不會由工具自動攔截或抓取。只回填已整理的公開metadata與短觀察，不整批掃入raw、私有內容或未核實的舊已讀標記；首批是城山，其他類別後續按研究逐步回填。保留既有岩場facts與runtime evidence store，本次不改D1、schema、CI或品質閘門。
