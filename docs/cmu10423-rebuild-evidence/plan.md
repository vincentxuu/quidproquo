## 學習弧線與範圍卡

目標：具機器學習入門概念、可讀 Python 的讀者；先能追蹤生成與訓練，再理解模型表示、調適、條件生成、效能與評估。數學橋接走既有 CMU 10-301／11-785 導讀，抽象公式在直覺和完整例子之後。

最後一欄是建議閱讀順序，非全部必要先備；正式範圍卡另列必要概念。ICL不必先LoRA，VLM不必先文生圖，影片不必先音訊生成，FlashAttention不必先分散式訓練。SSM補線性代數與離散系統橋接。

## 斷崖與邊界

- L1→L2：用同一短序列比較RNN順序狀態與attention加權，再教矩陣。
- L7→L8→L9：噪聲預測、訓練與採樣參數化、潛在變量與證據下界分開，保留數學橋接。
- L10→L11：参数更新与上下文调适分開；ICL不能消失在跨堂篇的開頭。
- L12→L13→L14→L15A：文字條件、視覺理解、attention注入、query橋接各有單獨輸入輸出例。
- L15B→L16→L17→L18：算力分配、條件計算、分散式、記憶體IO不混成「效率」。
- L19→L20→L21：長上下文、推理算力、狀態序列架構保留各自問題，跨連但不合併。
- L24A/B→L25→L26A：聲音表示、聲音生成、影片時間關聯、動作條件轉移各自驗收。
- L22→L26B：實際風險與對齊理論的假設／結論分開。
