這篇的作用是讓你看到各種排版長什麼樣子。看完可以直接刪掉這個檔案。

## 標題可以分層

### 這是第三層

一般段落長這樣。**粗體**、*斜體*、[連結](https://example.com)、`程式碼片段` 都可以用。

## 引用別人的話

> 引用的時候用大於符號開頭。
> 引用要註明出處，這是基本禮貌，也是讓人相信你的方式。

## 清單

- 第一點
- 第二點
- 第三點

有順序的話：

1. 先做這個
2. 再做那個

## 表格

| 項目 | 說明 |
|---|---|
| 標題 | 必填 |
| 日期 | 必填，格式 2026-01-31 |
| 摘要 | 選填 |
| 標籤 | 選填 |
| 草稿 | 選填，填 true 就不會公開 |

## 程式碼

```js
console.log('你不一定用得到這個，但它就在這裡')
```

## 圖片

把圖片放進 `public/` 資料夾，然後這樣寫：

```markdown
![圖片說明](/你的圖檔名.jpg)
```

## 想先存起來不公開？

在最上面的設定區塊加一行 `draft: true`，這篇就不會出現在網站上。改成 `false` 或整行刪掉才會公開。

也可以把 `date` 填成未來的日期，時間到了它自己會出現。
