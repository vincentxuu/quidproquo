## 這家公司做什麼

Zenity 是一套「專為 AI Agent 設計」的資安與治理平台——當業界大多數資安預算還在保護模型本身與單一 prompt 時,Zenity 押的是完全不同的攻擊面:Agent 一旦拿到權限在企業系統裡自主行動,真正的風險發生在「它做了什麼」,而不是「它被問了什麼」。

平台分三層:發現與可觀測性(即時盤點環境裡每一個 Agent、擁有者、可觸及的資源、行為模式)、治理與姿態管理(部署前就套用 secure-by-design 政策,並隨 Agent 演化持續驗證)、偵測與應變(逐步驟的執行期監控,在不安全動作完成前攔截,每次事件都回饋進偵測引擎)。2025 年 Gartner 將 Zenity 列為 Agentic AI TRiSM 領域的 Cool Vendor,2026 年 4 月的報告進一步稱其為「AI Agent 治理領域最值得對抗的公司」。公司也持續貢獻 OWASP Top 10 與 MITRE ATLAS 等開源資安框架的研究。

共同創辦人 Ben Kliger 與 Michael Bargury 皆出身 Microsoft,兩人的洞察來自於:低代碼自動化工具演變成 Agent 之後,留下了一個既有資安廠商都沒填補的治理缺口——他們在「Agent」這個詞還沒被大量使用前就已經在做這件事。Bargury 本人也是該領域頗具知名度的資安研究者。

## 這筆融資的訊號

### 對 Agent 生態的意義

Zenity 是 quidproquo watchlist 已追蹤的公司(section B7),這輪 $125M Series C 落在同一波「Agent 行為治理」募資潮的最前緣:三週內,Onyx Security 拿下 $113M Series B、Obsidian Security 拿下 $85M Series D,三家專攻「Agent 執行期治理」的公司在同一個月內合計吸金超過 $320M。這代表這個細分賽道已經從「一家獨大」變成「投資人相信能撐起多家公司的市場」——資安預算正式把「Agent 治理」列為獨立科目,而不是模型安全的附加功能。

### 投資人在賭什麼

Norwest 領投部落格的標題直接點出論點:「Agent 就是新的邊界」——傳統資安建立在「網路邊界」與「身分邊界」之上,但自主行動的 Agent 讓這兩種邊界概念同時失效,因此需要一個屬於 Agent 自己的治理平台,而不是把舊工具改造沿用。SoftBank Vision Fund 2、Hitachi、LG Technology Ventures 這幾家工業 / 製造業背景的策略投資人跟投,訊號很清楚:他們賭的不只是企業 IT 系統裡的 Agent,而是 Agent 深入營運技術(OT)與工業系統之後的治理需求。

### 值得觀察的數字

- 團隊規模 230+ 人,是本篇同期報導的 Agent 安全新創中人數最多的一家,顯示已經走過純研發階段,進入規模化銷售與客戶成功；
- 累計融資約 $185M,是 2021 年成立以來、在「Agent」還不是主流用詞的年代就開始建置的產品累積成果;
- 同一個月內 Zenity($125M)、Onyx($113M)、Obsidian($85M)三家「Agent 執行期治理」公司合計募得 $320M+,顯示這個賽道的資金集中度正在快速提高。

## Watchlist 狀態

Zenity 已在 watchlist section B7(Agent 安全 / 治理 / 資安技術)。追蹤重點更新為:$125M Series C(Norwest 領投)、Gartner 認證「AI Agent Governance 領域最值得對抗的公司」、「Agent 就是新邊界」論述,以及 SoftBank/Hitachi/LG 等工業策略投資人加入後對 OT/工業場景治理的潛在延伸。

## 今日收穫

Zenity 2021 年成立時,「AI Agent」還不是一個被廣泛使用的詞——他們是從 Microsoft 內部低代碼自動化工具的治理缺口反推出這個問題的,而不是看著 2025-2026 年的 Agent 熱潮才決定進場。這跟同期拿到大輪的 Onyx、Obsidian 有類似軌跡:真正在這波「Agent 治理」資金潮裡拿到最大單的,幾乎都是兩三年前就已經在啃這塊硬骨頭的團隊,而不是看到風口才組隊的新玩家。認知差在於:判斷一個安全賽道是不是真實存在,或許該看的不是誰現在募資最多,而是誰在沒有熱度加持的時候就已經在做。
