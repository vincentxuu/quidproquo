## 這家公司做什麼

HiddenLayer 是做 AI 安全的公司——保護企業的模型、Agent 與工作流程不被對抗性攻擊、供應鏈污染或惡意程式注入滲透。

核心產品覆蓋 AI 生命週期的四個環節：資產探索（找出企業內有哪些模型和 Agent 在跑）、AI 供應鏈安全（掃描約 50 種 AI 檔案格式，確認開源模型沒有被偷換成「掛羊頭賣狗肉」的惡意版本）、攻擊模擬（紅隊測試）、以及 runtime 防護（即時攔截 prompt injection、Agent 被操縱、工具濫用）。這輪的新產品「Agent Harness Security」把 Runtime Security 模組延伸到保護會自主寫程式、審查程式、上線程式的 coding agent。

客戶集中在金融服務與大型科技公司，也拿下美國國防部與情報體系的合約，其中一家客戶是「週活躍使用者超過 7 億的前沿模型供應商」——執行長暗示很可能是 OpenAI 或 Anthropic。ARR 過去一年成長超過 10 倍，來到「數千萬美元」量級，九成以上成長來自新客戶。

## 這筆融資的信號

### 對 Agent 生態的意義

這輪錢的三個重點：Agentic Runtime Security（企業要看清 Agent 在生產環境裡實際做了什麼，即時攔截操縱和越權操作）、保護自主 coding agent（這類 Agent 寫程式、審查、部署的自主權比傳統開發工具高很多，出錯的代價也更大）、以及擴張到歐洲和 EMEA。Gartner 估計企業今年在 AI 安全產品上的支出會達到 $28.3 億，比 2025 年多 83%，明年上看 $47.8 億——HiddenLayer 這輪算是接住這波預算轉移的其中一家。

### 投資人在賭什麼

Delta-v Capital 管理超過 $1.6B 資產，專注基礎設施軟體與雲端服務的成長期投資，這是典型的「賭賽道成熟」打法——三年前 HiddenLayer 第一輪融資時，AI 攻擊還很難舉出實際案例，如今 Agent 大規模上生產環境後，安全需求從「要不要」變成「多快要」。同一週還有 Noma、Zenity 各自募到超過 $100M，Air Security 也在 9/1 拿到 $50M——Agent 安全這個子領域正在快速堆疊資本，而思科、Palo Alto Networks、Check Point 這類大型資安廠商過去傾向直接併購（Robust Intelligence、Protect AI、Lakera），意味著這批新創的退出路徑可能不是 IPO，而是被收購。

### 值得觀察的數字

- ARR 一年成長超過 10 倍，90% 以上來自新客戶——顯示不是既有客戶擴大用量，而是全新的需求在冒出來
- 39 項已授權專利、65 項申請中專利，研究團隊深度是這輪估值的重要籌碼，不只是賣工具而是賣「率先建立的威脅分類法」
- 96% 的企業認為 AI 對核心營運至關重要，但將近三分之一無法確定自己是否曾發生過 AI 相關資安事件（HiddenLayer 自家 2026 AI Threat Landscape Report）——這個落差正是 HiddenLayer 賣的東西

## Watchlist 狀態

HiddenLayer 尚未在 watchlist 中。建議加入 section B7（Agent 安全 / 治理），與已在追蹤的 Zenity、Onyx Security、Air Security 並列，追蹤重點：AI 供應鏈安全 + Agent Runtime 防護 + coding agent 安全，$100M Series B，Delta-v Capital 領投。

## 今日收穫

三年前 HiddenLayer 第一輪融資最大的疑問是「AI 攻擊到底存不存在足夠規模的市場」，現在的疑問變成「安全廠商能不能跟上 Agent 自主權擴張的速度」——coding agent 已經在生產環境自己寫、自己審、自己上線程式，傳統開發工具的安全模型完全不夠用，這是一個問題定義本身在半年內被重寫的例子。
