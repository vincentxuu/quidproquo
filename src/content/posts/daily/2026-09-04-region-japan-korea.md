## 區域：日韓

本週日韓的共同主線是「國家隊模式」：政府與電信、通訊巨頭聯手把 AI Agent 當成公共基礎建設在推，速度和規模都比市場自然演化快得多。同一週，SoftBank 用一筆槓桿意味濃厚的認股權證交易，提醒這整場基建競賽背後的資金結構其實相當脆弱。

## 本週重要動態

### 南韓砸 512 顆 B200 打造全民 AI Agent 國家隊，KT 同週把方案賣進友利銀行

南韓科學技術情報通信部（MSIT）指定 SK Telecom、KT、Kakao 三個聯盟打造免費、無使用上限的全民 AI 服務，政府今年合計提供 512 顆 NVIDIA B200 GPU，並規劃 2027 年起補貼營運成本，目標年底前全國上線。這不是一般聊天機器人，官方要求的是能代替使用者實際執行任務的 Agent——涵蓋公共服務申辦、醫療、金融、教育、居住等領域。Kakao 的做法是把 KakaoTalk 當成主要入口，結合通用聊天機器人與能處理預約、申請、付款的 Agent，並計畫透過 Agent 市集發放專用 Agent。（[Korea Herald](https://www.koreaherald.com/article/10855962)）

同一週，KT 宣布獲選重建友利銀行（Woori Bank）的 AI 客服與諮詢機器人系統，這是南韓五大商業銀行中第四家採用 KT 的 AICC（AI Contact Center）方案。KT 這次導入新推出的「Agent Connector」，把聊天機器人、諮詢機器人、AI Banker 與 AI Agent 串接起來，使用者換頻道諮詢時上下文仍能延續，同時讓 Agent 直接處理金融實際任務而非只做導引。（[Seoul Economic Daily](https://en.sedaily.com/technology/2026/08/31/kt-to-rebuild-woori-banks-ai-chatbot-and-consultation-bot)、[The Elec](https://www.thelec.net/news/articleView.html?idxno=13469)、[Herald Business](https://mbiz.heraldcorp.com/article/10856817)）

國家隊政策與 KT 的銀行案例合在一起看，說明南韓的打法不是「政府補貼＋企業自己想辦法落地」的兩段式，而是同一批電信商同時吃下公共版與企業版的 Agent 基礎建設，公私兩線一起鋪。

### LINE Yahoo 啟動全社橫跨任務小組，目標把 Agent i 開發速度提升十倍

LINE Yahoo（LY Corporation）於 8 月 28 日向媒體公開 8 款新的 Agent 原型，並宣布自 9 月 1 日起正式啟動「Agent i 全社橫跨任務小組」，由 CPO 慎 埈鎬（Shin Jun-ho）親自擔任小組長。官方數字顯示：Agent i 自 2026 年 4 月 20 日上線以來，領域 Agent 數量四個月內從 7 個擴大到 27 個，成長約 4 倍，6 月單日平均延伸使用者數已達 1,200 萬（約當日本人口一成）；目標是 10 月前把領域 Agent 擴大到累計 40 個，並讓 Agent i 從 LINE、Yahoo! 內建功能獨立成單一 App。（[LY Corporation 官方新聞稿](https://www.lycorp.co.jp/ja/news/release/020773)）

這個「十倍量產」目標背後的底氣，來自 LINE 在日本月活躍使用者已於 2025 年 12 月突破 1 億、Yahoo! JAPAN 月活躍使用者約 5,400 萬——LINE Yahoo 不需要從零獲客，只要把 Agent 塞進使用者每天都會打開的既有入口即可。

### NTT Data 攜手 Palo Alto Networks，目標 2029 年前做到 10 億美元 AI 資安聯合業務

NTT Data 與 Palo Alto Networks 宣布合作開發企業級 AI 資安服務，使用自主 Agent 進行威脅偵測與回應，雙方目標在 2029 年底前做到合計 10 億美元的聯合業務規模。（[Nikkei Asia](https://asia.nikkei.com/spotlight/cybersecurity/japan-s-ntt-data-teams-with-us-company-on-ai-for-enterprise-cybersecurity2)）這則消息與 KT-友利銀行案例呼應：日韓兩地的傳統系統整合商（NTT Data、KT）都選擇把「AI Agent 資安／可信賴度」當作切入企業客戶的主打賣點，而不是單純比拼自研模型能力。

### SoftBank 用 55 億美元認股權證綁住 OpenAI，撐起尚未獲利的 SB Energy IPO

SoftBank 旗下資料中心公司 SB Energy 為留住 OpenAI 作為主要租戶，發給對方價值約 55 億美元的認股權證；SB Energy 上半年淨損約 32 億美元，營收約 1.39 億美元，主要仍來自舊有能源業務，目前正推進 IPO。Nvidia 先前也宣布將為 SB Energy 在美國俄亥俄州興建的 OpenAI 資料中心提供高達 1,050 億美元的融資。（[CNBC](https://www.cnbc.com/2026/09/01/sb-energy-ipo-softbank-open-ai-nvidia.html)）三方在資金與租約上高度綁定，意味著這座資料中心帝國的營收基礎，很大一部分建立在關係企業之間互相認股、互相融資的循環上，而非獨立驗證過的外部需求。

## 深度分析

我認為本週日韓最值得注意的信號，是兩種「國家隊」打法的分岔：南韓走的是政府直接補貼＋電信商執行的公私協力模式，日本走的是既有巨頭（LINE Yahoo）靠自有流量內部動員的市場模式，但兩者殊途同歷——都在用行政或平台力量，人為壓縮 Agent 從原型到全民規模的擴散時間。

用波特五力分析（Five Forces）拆解：

**新進入者的威脅被政策與流量雙重壓低**：南韓政府直接指定 SK Telecom、KT、Kakao 三家聯盟並提供 GPU 補貼，等於用行政力量預先篩掉了潛在的獨立新創競爭者——一家沒有電信牌照或既有使用者基礎的南韓 AI Agent 新創，很難拿到同等規模的政府資源競標全民服務。LINE Yahoo 的十倍量產任務小組也是同樣邏輯：靠 LINE 破億的月活躍使用者和 Yahoo! JAPAN 既有入口，把「取得使用者」這個新創最貴的環節直接免除。

**供應商議價力集中在晶片與雲端資本**：南韓政府補貼的是 512 顆 NVIDIA B200，SoftBank 需要 Nvidia 提供 1,050 億美元融資才能蓋出 OpenAI 要的資料中心——日韓這波 Agent 基建競賽的實際瓶頸，不在模型或應用層，而在誰能拿到晶片與資本。SoftBank 用認股權證換租約穩定性，本質上是在議價力不對等的情況下，用股權而非現金留住供應鏈上游的關鍵客戶。

**替代品的威脅則反過來被企業案例壓低**：KT-友利銀行、NTT Data-Palo Alto 這兩個案例，都是把「Agent 資安與上下文延續性」包裝成企業採購時的差異化賣點，用既有的系統整合關係鎖住客戶，讓企業更難改用其他 Agent 供應商——這和上一篇中國區域焦點觀察到的「轉換成本護城河」邏輯一致，只是日韓這裡的鎖點是既有的電信／系統整合合約關係，而非帳號或協作平台生態。

## 對台灣創業者的啟示

- 如果你在做企業金融或政府數位服務相關的 Agent 產品：KT-友利銀行案例顯示，銀行不是直接找 AI 新創，而是找既有的系統整合商（KT）用「上下文延續＋既有 AICC 經驗」的組合標案。台灣的金融、電信系統整合商（如中華電信、資策會體系）若跟進類似打法，獨立 Agent 新創想切入金融客戶，得想清楚自己是要正面競標，還是找系統整合商合作、把自己定位成他們的 Agent 引擎供應商。
- 如果你的產品仰賴單一超級 App 通路（類似 LINE、KakaoTalk 在日韓的角色）：台灣沒有等量級的國產超級 App，LINE 在台灣雖然普及但入口權在 LINE 手上，不是本地團隊能掌控的變數。與其複製「內建進超級 App」的打法，更務實的路線是走 MCP 式的開放整合，讓你的 Agent 能被多個入口呼叫，而不是賭單一平台的流量。
- 如果你在評估資料中心或 AI 基建相關的投資／合作案：SB Energy 這筆 55 億美元認股權證交易提醒，日韓這波 AI 基建競賽的財務結構，有一部分建立在關係企業互相融資、互相租賃的循環上。台灣如果有雲端或機房業者想複製類似的「綁定大客戶換資本」模式，應該先問清楚對方的營收有多少比例來自這類循環性交易，而不是只看合約金額大小。

## 今日收穫

之前以為日韓的 AI Agent 進度落後美中，主要卡在模型能力。這週看下來才發現，日韓真正的策略重點根本不在模型層——南韓政府直接補貼電信商把 Agent 當公共建設鋪、LINE Yahoo 靠既有破億使用者內部動員十倍量產——兩地都選擇跳過「先做出最強模型」這一步，直接用既有的行政力量或流量規模把 Agent 鋪給全民。但 SoftBank 那筆 55 億美元認股權證也提醒我，這種靠行政與資本力量壓縮出來的擴散速度，底層的財務基礎未必比模型能力更穩固。
