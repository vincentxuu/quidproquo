## 這家公司做什麼

Atira 是做工業銷售工程（industrial sales engineering）AI 協調層的公司——把客戶詢價單（RFQ）送進來到報價送出去之間，原本要業務工程師、技術專家、法務、商務團隊跨部門耗上數週到數月的流程自動化。

核心產品串接客戶既有的 CRM、ERP、CPQ 系統，處理往往橫跨多國語言、附帶圖紙與法規標準的非結構化詢價規格書，自動辨識需求、產出配置提案、技術文件與報價選項。Atira 估計這類工業銷售工程流程全球年度人力支出超過 $128B，大多仍靠人工拼湊，是傳統企業軟體長期沒真正碰過的一塊。

公司 2024 年 11 月成立，不到一年已簽下十幾家客戶，從 Robel、Theegarten-Pactec、Fette Compacting 等中型製造商，到年營收超過 €1B 的全球企業：ABB E-Mobility 已全球部署，Chiron Group 正從德國擴展到美國市場，一家大型工程集團把 Atira 用在價值數億歐元的專案上，Rema Tip Top 則跨澳洲、巴西、智利的業務團隊都在用。這些客戶全部是在零商業開發人力的情況下，靠客戶互相介紹拿下的。

## 這筆融資的信號

### 對 Agent 生態的意義

Accel 合夥人在投資部落格裡把賭注講得很直白：「很快，AI agent 會在每一筆複雜 B2B 交易的兩端同時運作，協調它們的系統將和一個世代前的 ERP 一樣，成為產業的基礎設施。」這輪資金代表 VC 開始把「企業對企業之間的 Agent 協調層」，而不只是單一企業內部的 Agent 應用，當作下一個基礎設施機會——尤其鎖定製造業這種長尾、高複雜度、軟體從未真正深入過的工作流程。這筆錢會用來擴大 go-to-market 團隊、加速產品開發、支援國際擴張，並延伸到相鄰的商業流程：定價智慧、售後服務、供應商協調。

### 投資人在賭什麼

領投的 Accel 合夥人 Harry Nelis 與 Alex Reinert 的邏輯是：工廠自動化已經五十年，但客戶與供應商之間的「對話」——也就是銷售工程流程——幾乎沒被軟體碰過，因為輸入是非結構化的、答案也不是預先知道的。這條思路延續了 Accel 過去投資 Celonis（流程探勘）的路線：先攻進企業裡沒人碰過的「暗流程」，再把它變成資料層與協調層。值得留意的是，這輪的天使投資人名單裡就有 Celonis 共同創辦人暨共同執行長 Bastian Nominacher，以及 Whirlpool CEO Marc Bitzer——後者代表製造業老將親自下注這個賽道，而不只是財務投資人。

### 值得觀察的數字

- 客戶反映詢價到報價時間縮短最多 80%，多數製造商原本因為工程頻寬不足回絕 20% 到 40% 的詢價機會，Atira 主張同樣團隊規模下能承接更多訂單
- 不到一年內簽下十幾家客戶，其中包含年營收超過 €1B 的全球企業（ABB E-Mobility、Chiron Group），這種客戶密度在同階段 Seed 輪新創中並不常見
- 累計 $17.5M（$15M Seed + 先前未公開的 $2.5M Pre-Seed），高於多數同輪次的垂直產業 Agent 新創募資規模，反映投資人對「工業複雜銷售流程」這個利基的溢價

## 今日收穫

多數 Agent 新創在搶「通用助理」或「coding agent」這種高關注度賽道，但 Atira 選的是工業銷售工程這種沒人想碰的「暗流程」——ABB、Chiron 這種年營收破十億歐元的客戶願意在公司零業務開發人力的情況下自己找上門，說明真正的痛點常常藏在最無聊、最沒人做過的角落，而不是最熱鬧的賽道裡。
