## 這家公司做什麼

Cognition 是做自主 AI 軟體工程師 Devin 的公司——不是輔助工程師寫 code 的助理，而是能獨立規劃、寫程式、跑測試、修 bug、開 PR 的 agent，2024 年 3 月以「全球第一個 AI 軟體工程師」的定位推出。

核心產品線圍繞 Devin 展開：Devin 本體處理端到端的開發任務；2025 年收購 Windsurf 後改名為 Devin Desktop，補上 IDE 端的體驗；這次 Series E 公告新增 Devin Auto-Triage（事件發生時自動先做一輪排查）、Devin Security Swarm（找漏洞並分級）、Devin Automations（讓 Slack、GitHub、Linear 等系統的事件直接觸發任務，不用每次開對話）。公司刻意把自己定位為「獨立 agent lab」——可以自行選用或混用不同模型（含自家模型），不綁死單一模型供應商。

客戶已經涵蓋 NVIDIA（晶片設計）、GE Aerospace（航太）、Citi（金融服務）、Mercedes-Benz（汽車）、Modal（AI 基礎設施）等產業標竿企業，過去一年在華盛頓特區、東京、新加坡、倫敦、聖保羅、馬德里開設新據點，加上原有的舊金山、紐約、奧斯汀。年化營收（run-rate revenue）從 2026 年 5 月的 $492M，四個月內成長到近 $900M。

## 這筆融資的信號

### 對 Agent 生態的意義

這是目前 coding agent 賽道規模最大的一輪融資，把 Cognition 的估值推到 $48B——距離上一輪（$26B）僅隔約三個半月，漲幅接近 85%。這代表 VC 不再把「AI 寫程式」當成單一功能特性，而是願意把它當成一個可以獨立撐起數百億美元估值的基礎設施層。公告本身也透露資金用途的方向：從「輔助寫程式」擴張到「主動處理維運與安全」（Auto-Triage、Security Swarm），以及把 Devin 嵌進企業既有的事件系統（Automations），這意味著 Cognition 想從「開發工具」往「持續運作的維運 agent」擴張，直接和既有的 incident response、應用安全類產品搶地盤。

### 投資人在賭什麼

a16z 與 Accel 首次進場就直接領投，而不是從早期輪次培養起，代表它們判斷 Cognition 已經是這個賽道的頭部玩家、值得用溢價買入場券——這和 Accel 稍早投資工業銷售 agent Atira 的邏輯不同：那是押注一個沒人碰過的冷門利基，這裡則是押注一個已經證明能快速起量的熱門賽道裡的龍頭。原有投資人 Founders Fund（從種子輪就領投，是 Cognition 最忠實的支持者之一）、General Catalyst、8VC 全數加碼跟投，顯示內部投資人對成長曲線有信心，沒有因為估值翻倍而卻步。NVIDIA 本身也是跟投方之一——它同時是 Cognition 的客戶（晶片設計團隊用 Devin）和投資人，這種「既是使用者又是股東」的結構，在近期大型 AI 基礎設施輪次中越來越常見。

### 值得觀察的數字

- 年化營收從 $492M（2026 年 5 月）漲到近 $900M（2026 年 9 月），四個月成長約 83%，換算成年化成長率遠超過同階段大多數 SaaS 公司
- 估值 $48B 對比 ~$900M 年化營收，隱含倍數約 53x——高於典型後期 SaaS 公司的 15-25x，反映市場對「agent 能取代多少工程師工時」仍給予高度溢價
- 公司自稱 89%（Series D 公告數字）的自家程式碼由 Devin 提交，這個「自己吃自己的狗糧」比例是同類公司裡少見的具體驗證指標

## Watchlist 狀態

Cognition（Devin）已在 watchlist section B1（Coding AI / 開發工具），追蹤重點更新為：自主 coding agent 從「輔助開發」擴張到「主動維運與安全」（Auto-Triage、Security Swarm、Automations），$2B+ Series E，估值 $48B，a16z／Accel 領投。

## 今日收穫

三個半月內估值漲 85%、年化營收漲 83%，兩條曲線幾乎同步——這輪融資與其說是「Cognition 值多少錢」的重新定價，不如說是投資人在賭這個成長率能不能繼續維持到下一輪：如果營收成長開始落後估值漲幅，$53x 這種倍數會是第一個被質疑的數字。
