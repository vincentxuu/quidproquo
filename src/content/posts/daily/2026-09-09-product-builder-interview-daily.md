## 今日主題

Strategy & Execution 這輪考的不是背出 Porter's Five Forces 有哪五個力，是看你能不能在一個「市場已經有強力對手」的模糊題目裡，講出具體要不要打這場仗、以及打的話公司手上有哪個資產可以轉成護城河。多數人講策略題會停在「市場很大、我們有品牌優勢」這種空泛結論，面試官接下來一定會追問「那你憑什麼贏」。

今天用五力分析先判斷這個市場值不值得打、競爭強度來自哪裡，再用 TAM-SAM-SOM 把市場切成可以在第一年內驗證的範圍，讓策略題不再只是講故事，而是有具體的市場邊界和取捨依據。

## 核心框架速記

### Porter's Five Forces：判斷這場仗值不值得打

進入一個新市場前，先用五力分析判斷這個市場的競爭結構，而不是只看「市場夠不夠大」：

| 力量 | 判斷問題 | 對 PM 決策的意義 |
|------|---------|------|
| 現有競爭者的競爭強度 | 對手有幾家？靠什麼競爭（價格、功能、生態）？ | 強度越高，越需要明確的差異化定位，不能打功能對功能的消耗戰 |
| 新進入者的威脅 | 進入這個市場的門檻高不高？自己算不算「新進入者」？ | 如果自己是後進者，要問清楚為什麼「現在」進場、為什麼「是自己」能贏 |
| 替代品的威脅 | 使用者不用這類產品時，會用什麼代替？ | 替代品威脅低，代表教育市場的成本較低，但也可能代表這個需求本來就不夠痛 |
| 供應商的議價能力 | 這個產品依賴哪些上游（雲端服務、資料、平台方）？ | 依賴度越高，護城河越容易被上游反過來卡住 |
| 買方的議價能力 | 使用者換到對手產品的成本高不高？ | 決定護城河該建在「留住既有使用者」還是「搶新使用者」 |

**常見失誤**：把五力分析當成填空表格背答案，而不是用來回答「這場仗值不值得打」這個具體問題。面試官要聽到的是結論，不是五個力都講一遍。

### TAM-SAM-SOM：把市場切成可執行的第一步

市場夠大不代表現在打得贏，要把市場切成三層，才知道第一年該打哪一塊：

| 層級 | 定義 | 對 PM 決策的意義 |
|------|------|------|
| TAM（Total Addressable Market） | 這類產品理論上能觸及的全部市場 | 用來說服公司「這個方向值得投資」，但不能直接拿來訂季度目標 |
| SAM（Serviceable Addressable Market） | 以公司現有的通路、技術、定位能實際觸及的市場 | 決定「我們該打哪個區隔」，通常會排除自己完全沒有優勢的區隔 |
| SOM（Serviceable Obtainable Market） | 在明確時間框架內（通常一年）真正能拿下的市場 | 這是面試官真正想聽的數字——具體、有時間框架、能反推成功指標 |

面試被追問「這個市場你打算怎麼切入」，答案要落在 SOM 這層，講清楚第一批要打的具體區隔，而不是重複 TAM 的宏大數字。

## 今日練習題

### 題目

「公司做的是一個以設計師為核心使用者的協作工具，市場上已經有一到兩個站穩腳步的白板協作產品。你會怎麼決定要不要切入這個市場？如果決定要做，第一步要打哪一塊？」

（題型：策略案例題；自擬 based on Figma 於 2021 年推出 FigJam、正面對決白板協作龍頭 Miro 的真實產品決策）

### 拆解思路

1. **釐清問題**：先確認範圍——「切入」是指做一個獨立新產品，還是在既有產品裡加一個新模組？決策的時間框架是多久？這個決定要對齊公司的哪個目標（留住既有客戶、還是打開新客群）？
2. **用五力分析判斷值不值得打**：現有競爭者（如 Miro）的競爭強度很高，走的是範本庫、企業治理這條路線；但買方議價能力這一項要反過來看——如果公司本身已經有一批設計師使用者，這批使用者換到白板工具的「額外」切換成本其實很低，因為決策不是「要不要換掉現有白板工具」，而是「要不要多開一個既有帳號體系裡的功能」。
3. **用 TAM-SAM-SOM 收斂第一步**：TAM 是整個視覺協作市場；SAM 縮小到「已經在用公司既有設計工具的團隊」，因為這是公司唯一具備既有優勢的區隔；SOM 是「一年內能從既有付費帳號滲透到新功能的比例」，這個數字要具體到能反推功能優先順序。
4. **決定差異化定位**：不追求功能對功能複製現有龍頭的範本庫和企業治理，而是主打「跟既有設計檔案無縫串接」——開會討論可以直接把設計稿拉進白板，這是既有龍頭做不到的資產優勢，護城河建立在既有的多人協作技術和使用者網路上，不是重新打造一個獨立產品。
5. **定義成功與風險**：主要指標是「既有付費帳號中開通並持續使用新功能的比例」；風險是核心設計產品的工程資源被分走，要講清楚停損點——如果一年內滲透率沒有到某個門檻，要收斂範圍還是暫停投資。

### 範例回答（面試時可以這樣講）

> **問題釐清**：「我想先確認範圍——這裡的『切入』我會假設是在既有產品的帳號體系裡做一個新模組，而不是從零開始的獨立產品，時間框架抓一年。我想先問一下，這個決策要對齊的目標是留住既有客戶對抗流失，還是打開一群還沒用過我們產品的新客群？我會先假設是前者，因為對手已經很成熟，直接搶新客群的邊際成本會很高。」
>
> **值不值得打、打哪裡**：「用五力來看，這個市場的現有競爭強度很高，對手靠範本庫和企業治理站穩腳步，正面拚功能對功能我們贏不了。但買方議價能力這一項要反過來看——我們已經有一批設計師在用我們的核心產品，他們要不要多開一個帳號體系裡的白板功能，切換成本遠低於從零選一個新工具。所以我會把 SAM 收斂到『已經是我們付費客戶的團隊』，SOM 訂在『一年內這批客戶有多少比例會開通並持續使用新功能』，而不是去跟對手搶整個白板市場的 TAM。」
>
> **差異化與風控**：「差異化不會是複製對手的範本庫，而是主打『跟既有設計檔案無縫串接』——開會時可以直接把設計稿拉進白板討論，這是對手因為沒有我們的核心產品資產而做不到的事。護城河建在既有使用者網路和多人協作技術上，不是重新打造一個獨立產品去正面對決。風險是這會分走核心產品的工程資源，所以我會設一個停損點：一年後如果既有客戶的滲透率沒到某個門檻，就先收斂範圍，而不是繼續加碼跟對手拚功能廣度。」

### 自我核對清單

用這張表檢查你的回答有沒有漏掉關鍵點：

| 核對項目 | 有提到？ |
|---------|---------|
| 用澄清問題把「切入方式」「時間框架」「對齊目標」收斂清楚 | |
| 用五力分析講出具體結論（值不值得打、強度來自哪裡），不是背答案 | |
| 用 TAM-SAM-SOM 把市場收斂到 SOM 這層具體數字，不是停在 TAM | |
| 差異化定位講清楚護城河從公司哪個既有資產來，不是喊口號 | |
| 有講到成功指標與風險停損點，不只是「我們會贏」 | |
| 加分項：提到如果進場失敗要怎麼收斂或退出 | |

## 今日案例

**Figma：用既有設計師網路切入白板協作市場，正面迎戰 Miro**

Figma 在 2021 年推出 FigJam，切入的白板協作市場當時已經被 Miro 站穩龍頭地位，範本庫和企業治理功能都比 FigJam 成熟得多。FigJam 沒有選擇在範本數量或企業功能上跟 Miro 硬碰硬，而是主打跟 Figma 既有設計檔案的無縫串接——團隊開會討論時可以直接把設計稿拉進 FigJam 白板，這是只做白板工具的 Miro 做不到的事，因為它沒有 Figma 手上這批既有的設計師使用者和多人協作技術資產。FigJam 因此在「設計相關的跨職能協作」這個具體區隔站穩腳步,而不是想一口氣拿下整個白板協作市場。

**面試連結**：這個案例是「後進者不拚功能對功能、改用既有資產當差異化」的最佳示範，可以直接拿來回答「你會怎麼決定要不要切入一個已經有強力對手的市場」或「舉一個公司善用既有優勢打入新市場的例子」。重點不是背 FigJam 這個名字，是講清楚它怎麼把 SAM 收斂到自己唯一有優勢的區隔，而不是跟龍頭搶整個市場的 TAM。
