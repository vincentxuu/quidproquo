## 這家公司做什麼

Euno 是做「企業 AI-native context brain」的公司——讓 AI agent 能理解企業資料的意義、來源、治理規則，把「context」變成 agent 能可靠行動的基礎設施。

核心產品持續研究並重建企業資料的血緣（lineage）、意涵（meaning）、所有權（ownership）與治理規則，即時建構會隨組織成長而演化的 context graph。技術差異化在於：不靠人工維護的資料目錄（data catalog），而是從 agent 與資料互動的操作訊號裡反推出哪些資料該被信任、如何被使用的規則，再持續用 agent 回饋精煉這套 context——本質上是「context 會自己學習與更新」，而非「由人一次性建置」。

目前客戶涵蓋 Fortune 500 企業與市場情報平台 AlphaSense、電信巨頭 Zayo Group，並在 2026 年被 Gartner 列入《Coolest Vendor Innovations in Data Management》報告。

## 這筆融資的信號

### 對 Agent 生態的意義

Euno 精準卡在一個新興但關鍵的位置——企業想部署自主的、跨領域的 agentic workflow，但 agent 要能安全、可靠地「懂」企業資料，需要一層過去不存在的基礎設施：能持續學習、能即時執行治理規則的 context 層。這輪 $23M 不是要證明市場存在（領投方 N47 已經確信），而是要在「context 層」這個尚未有明確贏家的新戰場站穩位置——公司自己表示未來 12 個月內可能再融一輪。

### 投資人在賭什麼

這輪最特別的地方是天使投資人名單——Wiz 共同創辦人 Yinon Kostika、Cyera 共同創辦人暨 CEO Yotam Segev、Eon 共同創辦人暨 CEO Ofir Ehrlich、Tavily 創辦人 Rotem Weiss——清一色是以色列資安 / 資料新創圈的連續創業者，而不是傳統機構投資人湊數的天使名單。這代表資安圈的老玩家親自下注「企業資料治理」正在被 AI agent 重新定義，而兩位創辦人 Sarah Levy（前 Sight Diagnostics CTO、前 IDF 資安部門主管）與 Eyal Firstenberg（前 Unit 8200 科長、前 LightCyber VP R&D，該公司後被 Palo Alto Networks 收購）本身出身以色列資安圈的核心人才管道 Talpiot 與 Unit 8200，是被視為「自己人」的團隊。

### 值得觀察的數字

- 這輪 Series A 規模在 Dealroom 追蹤的 9,256 筆同類企業軟體 A 輪交易裡排在第 90 百分位——即使只是 $23M，也顯著高於同賽道 A 輪中位數
- 累計融資僅 $29M，但已進入 Fortune 500 客戶名單並拿下 Gartner Cool Vendor 認證，顯示產品驗證速度快於募資速度
- 團隊近 30 人卻已服務 AlphaSense、Zayo 等大型企業客戶，人均產值指標值得後續追蹤

## 今日收穫

過去談「AI agent 的記憶層」多半想到 mem0、Zep 這類「給單一 agent 存記憶」的產品，但 Euno 瞄準的是完全不同的問題——不是 agent 記不記得住什麼，而是企業能不能持續告訴 agent「這份資料該怎麼理解、能不能信任、誰有權限看」。當 agent 數量從 1 個變成上百個、跨部門運作時，這種「治理即基礎設施」的能力，可能比「記憶容量」更早成為企業採用 agent 的瓶頸。
