## 這家公司做什麼

Jack & Jill 是做「雙邊 agent 招募媒合」的公司——它在求職者和雇主兩側各放一個 AI agent，讓兩個 agent 互相協商找出匹配，而不是走傳統的履歷投遞與人資篩選流程。

核心產品是兩個對話式 agent：Jack 代表求職者，用語音對話（不是打字聊天機器人）進行類似職涯教練的深度訪談，挖出履歷上看不到的資訊（例如「跟主管處理不好」「理想薪資範圍」），再結合每天掃描的數百萬個職缺判斷這個人真正想要什麼。Jill 代表雇主，讀職缺描述、研究雇主公司、詢問問題釐清「這個職位的成功長怎樣」，然後直接從 Jack 的候選人網路中尋源，而非依賴公開投遞池。當兩個 agent 都判斷候選人與職缺匹配，才直接促成雙方見面，不需要走申請流程。

公司自述其候選人網路已成長十倍達到 35 萬名專業人士，Jill 已服務超過 5,000 家企業（包含 Ramp、Attio、Multiverse、Corgi），兩個 agent 加總已促成 25,000 場面試，目前每月再新增 5,000 場。美國市場（舊金山、紐約）啟動後的成長速度是倫敦同期的近四倍，營收自 Seed 輪以來成長 40 倍。

## 這筆融資的信號

### 對 Agent 生態的意義

這筆 $40M A 輪把招募這個垂直領域從「更好的搜尋/篩選演算法」重新定義成「雙邊都有 agent 代理協商」的市場結構。新資金主要用於擴大美國市場布局——公司今年 1 月才在舊金山、6 月才在紐約落地，顯示這是先在英國驗證模式、再用募資快速複製到最大勞動市場的打法。

### 投資人在賭什麼

領投方 Air Street Capital 合夥人 Nathan Benaich 的公開邏輯是「下一步不是更好的履歷搜尋或更自動化的主動出擊，而是雙邊都有 agent 代理，只有雙方都會接電話才促成介紹」——換句話說，這筆錢賭的是「申請氾濫」本身正在讓履歷投遞這個機制失靈，解法不是加更多過濾器，而是換掉整個媒合機制。

### 值得觀察的數字

- 候選人網路十倍成長（Seed 到現在），累計 25,000 場面試、每月再新增 5,000 場，顯示媒合量已具備一定規模而非早期原型
- 美國推出後面試量是英國同期的近四倍，顯示產品可能更適合美國這種職缺與人才流動性更高的市場
- 有使用者已累積 144 通 Jack 對話，顯示語音 agent 訪談確實被高頻使用，而非一次性體驗

## 今日收穫

多數 agent 招募新創的敘事是「幫某一邊做得更快」（例如幫雇主篩履歷、幫求職者投更多職缺），但 Jack & Jill 的賭注是雙邊都要有 agent、而且要讓兩個 agent 互相協商——這代表隨著求職雙方都開始用 agent 自動化操作，傳統以「投遞量」為核心的招募機制本身會失效，贏家會是能讓兩個 agent 互相溝通、而非各自優化自己那一側指標的平台。
