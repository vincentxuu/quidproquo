## 這家公司做什麼

Factory 是做企業級自主 coding agent 的公司——目標客戶是大型工程組織，讓 AI agent 不只是自動完成程式碼片段，而是規劃任務、開 pull request、審查變更、跨repository 協調工作。

核心產品是 Droids 平台，採模型無關（model-agnostic）設計，可在 Anthropic Claude、DeepSeek 等不同模型之間切換，公司把這點定位成「不綁死單一 AI 實驗室」的保險策略。目前已有 NVIDIA、Blackstone、Royal Bank of Canada、Palo Alto Networks、Adobe 等企業客戶採用，公司自稱有數十萬名開發者在使用其產品。

Factory 已在 quidproquo watchlist 的 B1（企業級自主 Coding Agent）section 中列名追蹤,這次融資是其成長曲線的最新一筆數據點。

## 這筆融資的信號

### 對 Agent 生態的意義

Factory 的估值成長分成三段：4 月 Series C 的 $150M 拿到 $1.5B、7 月追加輪 $120M 推到 $4B、這次 $200M 再衝到 $5B——五個月內完成三次資本市場的重新定價,不是單次估值跳升。資金將用於加速研發、產品成長與全球市場擴張，反映投資人押注的不是單一產品功能，而是「軟體工廠」這個新的企業預算科目正在成形。

### 投資人在賭什麼

Khosla Ventures 從 Series C 就已進場,這次與 Blackstone、Sequoia Capital 一起加碼,顯示既有投資人選擇持續加注而非稀釋退出。Blackstone 本身也是 Factory 的企業客戶,這種「先當客戶、再當股東」的模式與同期 AlphaPai 的機構投資人參與邏輯相似——用自身龐大的工程組織驗證產品,同時用股權綁定確保優先取得客製化整合。Marc Benioff（Salesforce CEO）以天使身分加入,則是老牌企業軟體高層對「agent 取代部分工程職能」這個命題的個人下注。

### 值得觀察的數字

- 估值 5 個月內從 $1.5B 到 $5B,漲幅逾 3.3 倍,漲幅節奏明顯快於多數同賽道對手（如 Cognition 同期估值到 $48B 花了更長時間累積多輪）
- 累計融資僅五個月內就從約 $220M（Series C 後）成長到逾 $400M,新增資本幾乎全數集中在同一年內的三輪
- 同賽道的 Cursor、Cognition、Poolside 都在近期完成大輪融資,顯示企業級 coding agent 這個子領域的資本集中度正在快速提高,而非分散給更多新進玩家

## Watchlist 狀態

已在 watchlist section B1（企業級自主 Coding Agent）,追蹤重點更新為：五個月內估值從 $1.5B 三級跳至 $5B,Khosla/Blackstone/Sequoia 共同支持,model-agnostic 定位持續作為對抗單一 AI 實驗室依賴的核心賣點。

## 今日收穫

Factory 這五個月的三段式估值跳升,比單一輪次的金額更值得注意的是節奏本身——4 月、7 月、9 月連續三次資本市場重新定價,說明企業級 coding agent 不是一次性的估值泡沫,而是投資人在持續追蹤客戶採用曲線後不斷上修的結果;當 Blackstone 這種既是 LP 又是企業客戶的機構願意在同一家公司身上重複下注,代表這個賽道的「產品-採購」驗證迴圈已經比多數 AI 新創走得更快。
