## 區域：東南亞

東南亞的 AI Agent 生態這週出現一個鮮明的落差：資金端幾乎全部流向新加坡一地，鄰國合計募資金額甚至不到新加坡的百分之一；但另一方面，馬來西亞在政策上明確表態要補位，企業層則有 Grab 這種本地 super app 示範出自建 Agent 平台的路徑——這是首次為東南亞單獨寫一篇區域焦點，值得把資金、政策、企業三條線放在一起看。

## 本週重要動態

### 新加坡吸走東南亞近乎全部 AI 資金：93 億美元 vs 鄰國合計不到 4000 萬美元

市場情報平台 Tracxn 的統計經《Eco-Business》與《The Independent Singapore》報導：新加坡籍「原生 AI」公司（從創立起就以 AI 為核心業務的公司）截至 2026 年 7 月已累計透過 227 輪募資，取得約 93 億美元的股權融資，年度融資金額從 2024 年的 8.69 億美元（35 筆交易）成長到 2025 年的 20 億美元（41 筆），2026 年前 7 個月已募得 41 億美元、超越去年全年一倍以上。相對地，同期越南、馬來西亞、印尼、泰國的原生 AI 新創合計募資僅 3700 萬美元（越南 1900 萬、馬來西亞 800 萬、印尼 600 萬、泰國 400 萬美元）。Tracxn 也提醒，今年的成長很大一部分來自單一筆交易——Kling AI 的 28 億美元 D 輪，占東南亞今年原生 AI 融資總額約 68%。（[Eco-Business](https://www.eco-business.com/news/singapore-dominates-southeast-asia-ai-funding-as-investment-surges/) · [The Independent Singapore](https://theindependent.sg/singapore-attracts-us-9-3b-in-ai-funding-outpacing-southeast-asian-peers/) · [AIFrontPage](https://aifront-page.com/singapore-ai-funding-enterprise-ai-tech-in-asia-conference/)）

### 馬來西亞公布《國家 AI 行動計畫 2026–2030》，喊出「AI Nation」目標

馬來西亞通訊部長 Fahmi Fadzil 9 月 7–8 日在吉隆坡 WAIC CONNECT Malaysia 2026 上公布《國家 AI 行動計畫 2026–2030》（AI Nation 2030），目標是 2030 年前讓馬來西亞擠進全球 AI 指數（Global AI Index）前十名，並讓 AI 每年多貢獻 0.8 至 1.2 個百分點的 GDP 成長（約合 130 億至 200 億馬幣）。計畫涵蓋 949 個職位、10 個產業的技能盤點，目標培訓 70 萬名勞工，並已就《AI 治理法案》（AI Governance Bill）在 7 月 10 日至 8 月 1 日進行公眾諮詢。馬來西亞官方強調重點是「把運算容量轉化為實際經濟價值」，而非單純比拼資料中心規模。（[Malay Mail](https://www.malaymail.com/news/malaysia/2026/09/11/malaysia-wants-to-be-an-ai-nation-by-2030-what-does-that-mean-for-malaysians/234187) · [Technode Global](https://technode.global/2026/09/09/malaysia-targets-5b-in-gdp-gains-from-ai-annually-communications-minister/)）

### Grab 把 500+ 個內部 Agent 標準化到自研框架 LLM-Kit

《InfoQ》報導，東南亞 super app Grab 已將超過 500 個內部 AI Agent 服務，統一遷移到自建的 Agent 框架 LLM-Kit 上，內建評測、追蹤、金鑰管理與工具伺服器整合功能；Agent 執行時可從 50 多個 MCP server 動態發現可用工具，使新 Agent 服務的上線時間從原本約兩週縮短到約一小時。這是東南亞企業自建 Agent 基礎設施的具體案例，而非採用矽谷框架。（[InfoQ](https://www.infoq.com/news/2026/09/grab-agent-platform/)）

### 新加坡 MAS 發布 SAFR 框架，規範金融業自主 Agent

新加坡金融管理局（MAS）董事總經理 Chia Der Jiun 在 Global FinTech Fest 2026 上表示，AI 在新加坡金融業已從試點階段進入規模化部署，MAS 同時公布名為 SAFR（Safeguards for Agentic Finance at Runtime）的白皮書框架，針對自主 AI Agent 的身分驗證、執行前檢查與稽核追蹤訂出治理要點；MAS 也已就《AI 風險管理指引》展開公眾諮詢，訂出金融機構在 AI 生命週期各階段的監理期待。業界人士同時指出，SAFR 屬於非強制性框架,實際效果將取決於採用的廣度而非法規強制力。（[OpenGov Asia](https://opengovasia.com/singapore-sets-out-ai-governance-priorities-for-financial-sector/?c=us) · [Crowdfund Insider](https://www.crowdfundinsider.com/2026/09/309795-singapore-central-bank-urges-financial-sector-to-prepare-for-ai-driven-transformation/) · [Technode Global](https://technode.global/2026/09/11/mas-says-ai-set-to-transform-singapore-financial-system/)）

## 深度分析

我認為本週東南亞最值得注意的信號，是資金端的「新加坡磁吸」和企業端的「本地自建能力」同時在發生——用五力分析的「進入壁壘」與「供應商議價力」兩個維度來看更清楚。

**進入壁壘（Barriers to Entry）**：93 億美元對不到 4000 萬美元的資金落差，代表的不只是「新加坡新創比較強」，而是資金供給端本身高度集中在新加坡——大型 VC 的區域總部、律師與稽核生態、資本市場出場管道幾乎都設在新加坡。這形成一種事實上的進入壁壘：就算你的目標市場是印尼或越南，若團隊與公司主體不在新加坡，能接觸到的資本規模就是天壤之別。這和美國「矽谷集中」的邏輯類似，但東南亞的集中程度更極端——單一城市拿走區域 99% 以上的資金。

**供應商議價力（Supplier Power）／新進入者威脅**：阿里雲 QwenCloud 在曼谷辦 Qwen Conference Thailand 2026、吸引近 400 家企業客戶參與，顯示中國雲端大廠正用「生態綁定＋區域會議＋開發者社群」的組合打法，快速滲透東南亞的企業 Agent 採用市場——這和它在中國國內「模型＋框架垂直整合」的打法一致，只是換了戰場。對本地 SaaS 與 Agent 開發商而言，這代表未來在爭取企業客戶時，議價對手不只是新加坡的新創，還有帶著補貼與生態系一起進場的外部雲端巨頭。

不過 Grab 的案例提供了另一種可能：不靠外部框架，直接自建內部 Agent 平台（LLM-Kit）。這說明東南亞本地的大型平台型公司,已經有能力用「內部工具鏈標準化」來對抗前述兩種外部壓力——這比單純採購矽谷或中國的 Agent 框架更能保留自主性,也比從零創業更容易複製到其他有規模的本地企業。

## 對台灣創業者的啟示

- 如果你在做企業 Agent 基礎設施或工具鏈：Grab 的 LLM-Kit（500+ Agent 標準化、50+ MCP server 動態工具發現、上線時間從兩週縮到一小時）是一個可以直接參考的內部平台範本——台灣做企業 AI 平台的團隊（如 iKala、Appier 這類在 watchlist 上、本身也服務東南亞市場的公司）可以評估是否要把類似的「企業內部 Agent 標準化框架」包裝成產品，賣給東南亞同樣面臨 Agent 數量暴增但治理跟不上的中大型企業，而不是只賣單一 Agent 應用
- 如果你正在替東南亞市場的產品募資：新加坡的資金磁吸效應是結構性的，不是短期現象——與其在馬來西亞、越南、印尼當地找資金,應該優先考慮在新加坡設立實體或對接新加坡的 VC，即使你真正服務的市場是其他東南亞國家；這也解釋了為什麼很多東南亞創業者「總部設新加坡、市場在別處」
- 如果你在做金融科技或 AI 治理合規產品：MAS 的 SAFR 框架是非強制性的，代表市場上存在「機構想採用但缺乏落地工具」的缺口——台灣在資安與合規領域有經驗的團隊，可以評估往新加坡金融業的 Agent 治理稽核工具方向擴張，卡位這個「軟性監管但企業主動性高」的市場，比直接和新加坡本地新創拼泛用 Agent 應用更有機會

## 今日收穫

之前以為東南亞的 AI 創業活動大致平均分布在新加坡、印尼、越南、泰國幾個主要市場。這週看完 Tracxn 的資金統計才發現，這個區域其實正在快速二極化——新加坡吸走近乎全部資金,鄰國合計募資不到新加坡的百分之一。但同時馬來西亞選擇不跟新加坡拼資金規模，而是把目標訂在「GDP 貢獻」和「就業轉型」這種和募資金額無關的指標；Grab 也選擇自建內部框架而非依賴外部平台。這說明面對資金極度集中的現實，區域內的其他玩家並不是被動等待，而是各自找到了不靠資本規模取勝的路徑——這對同樣不具資本規模優勢的台灣創業者，或許比看新加坡的成功案例更值得參考。
