## 這家公司做什麼

Enhans 是做企業 Agentic AI 作業系統的公司——它把自己定位成連接「AI 模型」與「企業真實系統」之間的執行層，讓 Agent 不只是回答問題，而是真的能在 SAP、ERP、CRM 裡把工作做完。

核心產品 AgentOS 用本體論（ontology）把散落在各系統裡的資料和業務規則結構化，讓 AI Agent 能依據這套結構做出決策並執行任務；架構刻意做成模型無關（model-agnostic），企業可以自己掌控資料與 AI 決策流程，不綁死在單一模型供應商上。旗下的 Computer Use Agent「ACT-2」能像人類使用者一樣操作真實網站與軟體，在 2026 年 8 月發布的 Online-Mind2Web 基準測試（衡量 Agent 在真實網站上完成任務的能力）中排名全球第二。

目前 AgentOS 已在製造、金融、零售、醫療、國防與公部門等產業投入實際生產環境運作，客戶包括 POSCO、LG、樂天集團旗下企業——這次募資最特別的地方正是這三個客戶集團的投資公司首次以策略投資人身分入股，而不只是採購方。Enhans 也是 Microsoft for Startups Pegasus Program 與 Microsoft AI Startup Alliance 的成員。

## 這筆融資的信號

### 對 Agent 生態的意義

這輪錢會用在三件事：擴充 AgentOS 背後的資料、流程與執行基礎設施；開發針對特定產業的「Industry Packs」，把該產業的資料結構和業務規則直接封裝進產品；以及強化受監管產業客戶所需的資安與治理能力，同時往海外市場擴大招募。這代表 Enhans 想從「幫特定財閥客製化部署」，走向「可複製給不同產業、不同國家企業」的標準化作業系統。

### 投資人在賭什麼

Stonebridge Ventures 董事總經理 Youngdon Song 的說法很直接：「企業 AI 正走到一個轉折點，從只會產生答案的系統，變成真的能把工作做完的 Agent」。但真正值得注意的是 POSCO Investment、LG CNS、樂天 Ventures 這三家客戶集團旗下投資公司的加入——這是 Enhans 第一次拿到「自己客戶所屬集團」的策略投資，等於供應商關係反過來變成股權關係，比單純的財務投資人背書更難得，因為代表這些財閥集團認定 Enhans 的技術值得綁定長期戰略關係，而不只是採購一次性專案。

### 值得觀察的數字

- 累計融資 $60M，其中最新這輪 Series C 就佔 $38M，等於單輪金額超過先前所有輪次總和，顯示投資人加碼速度在近期明顯提升
- 上一輪 Series B 是 2025 年 1 月，中間在 2026 年 4 月拿到 NAVER Ventures 策略投資，本輪 Series C 落在 2026 年 9 月——不到一年半內完成三次募資動作，節奏相當密集
- ACT-2 在 Online-Mind2Web 基準測試全球排名第二，是少數有公開、第三方基準佐證的企業 Computer Use Agent 產品

## Watchlist 狀態

Enhans 尚未在 watchlist 中。建議加入 section D10（企業 AI 平台），與 Moveworks、Glean、ServiceNow、UiPath 並列追蹤，追蹤重點：本體論驅動的 AgentOS 作業系統層，以及 Computer Use Agent「ACT-2」在企業真實系統中的執行能力。

## 今日收穫

過去看企業 Agent 融資，習慣把「客戶跟投」當成公關話術，但 Enhans 這輪讓我重新想了一次：當 POSCO、LG、樂天旗下的投資公司願意用股權而不只是採購合約來綁定一家 Agent 新創，代表的不是「這家公司產品做得不錯」，而是這些財閥判斷「企業導入 Agent 需要的作業系統層」本身就是值得長期卡位的戰略資產——就像當年沒有企業會把 ERP 供應商當成單純的軟體採購對象一樣。
