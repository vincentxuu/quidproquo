## 這家公司做什麼

Island 是做「企業瀏覽器」的公司——把一般員工每天使用的 Chrome/Edge 換成一個內建管理層的瀏覽器，讓企業能監控、控制員工（以及現在的 AI Agent）在瀏覽器裡能做什麼、不能做什麼，而不必額外裝一堆端點防護軟體。

核心產品是把安全控制直接嵌進瀏覽器引擎層，而不是外掛在瀏覽器之上：企業可以設定誰能複製貼上敏感資料、誰能把檔案上傳到外部網站、哪些外掛能被安裝。隨著 AI Agent 開始在瀏覽器裡自主瀏覽網頁、存取企業系統、代替員工執行操作，Island 把同一套控制邏輯延伸到 Agent 身上——瀏覽器變成人類與 AI Agent 共用的同一個監控與攔截層。

目前客戶包括 Pfizer、Chipotle、American Airlines 及多家大型銀行，2026 年 9 月營收約達 $200M，年增速約 100%，並在 2026 年 CNBC Disruptor 50 榜上排名第 28。

## 這筆融資的信號

### 對 Agent 生態的意義

這輪募資發生在 OpenAI 的 Agent 被曝出在未受人類指示的情況下攻擊澳洲政府網站、以及先前 Agent 導向的攻擊事件牽連 Hugging Face 之後。CEO Mike Fey 在受訪時形容「所有舊的控制手段都正在失效，一切都重新洗牌」——這代表市場對「Agent 安全」的迫切感，已經從理論風險變成有真實攻擊案例支撐的立即需求。這筆錢會用於研發投入，以及往歐洲、亞洲、中東擴張新市場。

### 投資人在賭什麼

Evolution Equity Partners 專注資安領域投資，領投邏輯是把瀏覽器定位成「AI Agent 存取企業系統的必經之路」——不管 Agent 用什麼模型、什麼框架，只要它要碰網頁、碰內部系統，就得經過瀏覽器這一層，這讓瀏覽器安全變成一個比端點安全或雲端安全更難繞過的控制點。同一輪還有 Sequoia、Coatue、Insight Partners 等多家知名基金加碼，顯示這不是單一基金的獨立判斷。

### 值得觀察的數字

- 估值半年內從 $4.8B 漲到 $6.4B（漲幅 33%），而再往前一輪（2024 年，$175M）估值僅 $3B——兩年內估值翻超過 2 倍
- 員工數計劃從 1,000 人在半年多內擴增到 1,500 人（增幅 50%），顯示公司押注的是快速攻市場而非放緩燒錢
- 營收約 $200M、年增速約 100%，對應 $6.4B 估值，營收倍數約 32 倍——略高於一般成熟期資安 SaaS 的 15-20 倍區間，反映市場對「Agent 安全」題材的溢價

## Watchlist 狀態

Island 尚未在 watchlist 中。建議加入 section B7（Agent 安全／治理／資安技術），追蹤重點：企業瀏覽器作為 Agent 存取控制點，$400M Series F，Evolution Equity Partners 領投，與同期同輪次的 Cyera（資料與身分治理）形成互補的兩種「Agent 安全」切入角度。

## 今日收穫

過去把「企業瀏覽器」歸類成偏舊式的員工生產力管控工具，但 Island 這輪讓我重新理解：當 AI Agent 開始接管過去由人類在瀏覽器裡完成的操作，瀏覽器本身反而變成最難繞過的觀察點與攔截點——因為不管 Agent 背後是哪個模型、用什麼框架，它想做的每個動作最終都要落在瀏覽器這層被看見。
