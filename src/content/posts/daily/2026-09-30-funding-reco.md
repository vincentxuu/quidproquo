## 這家公司做什麼

Reco 是做「Agent 安全」的公司——當企業裡的 AI Agent 數量開始失控，Reco 幫資安團隊看清楚有哪些 Agent 在跑、它們用什麼身分和權限、能碰到哪些資料和系統，並在必要時收回不該有的存取權限。

公司最早做的是 SaaS 安全，去年開始把定位擴大成涵蓋整個「Agent 生態系」，核心技術是 Reco Graph——把 Agent、身分、應用程式、權限、資料和工作流程之間的關係全部連成一張圖。CEO Ofer Klein 說，轉型的關鍵原因是企業建立和部署 AI Agent 的速度已經快到自己都追不上：在一家財星 100 大客戶的環境裡，Reco 一次盤點就發現 21000 個公司不知道存在的 Agent；在一家大型金融服務客戶那裡，則抓到一個離職員工設置、能存取 Salesforce 並把資料外洩到公司看不到的網域的 Agent。

目前客戶超過 100 家，金融服務業約佔四成，年度經常性營收在「兩位數百萬美元」等級，Klein 預期今年會成長三倍。產品目前整合超過 280 個應用程式，包含 OpenAI、Anthropic、Microsoft Copilot、Salesforce、ServiceNow 和 Workday。

## 這筆融資的信號

### 對 Agent 生態的意義

Reco 自己在新聞稿裡引用 Gartner 預測：一般財星 500 大企業到 2028 年平均會有超過 15 萬個 Agent 在跑，2025 年時這個數字還不到 15 個——這正是這輪錢真正要賭的東西。TechCrunch 報導同一天就點出，光是 Crunchbase 和 PitchBook 上能查到的「Agent 安全」新創就至少有兩打，包括專門審核 Agent 使用工具的 Air、幫企業控管 Agent 能碰哪些資料的 Cymphony，以及做偵測應變的 CrowdStrike。這個賽道已經進入「工具太多、誰都想幫你治理」的擁擠期。

### 投資人在賭什麼

AT&T Ventures 的投資邏輯很直接——AT&T 本身就是 Reco 的客戶，這次策略投資等於用真金白銀替自家內部驗證過的產品背書。Reco 的差異化路徑是靠既有的 SaaS 安全客戶基礎和 280 個應用程式整合的覆蓋度，讓客戶不用因為要顧 Agent 就再換一套系統；新進場的 Forestay 和 Quadrille Capital 則是典型的成長期資本，賭的是 ARR 三倍成長的預期能不能兌現。

### 值得觀察的數字

- 2 月 Series B 到現在不到 8 個月，估值「翻倍以上」，累計融資從 $85M 衝到 $140M
- 單一客戶環境裡就抓出 21000 個未知 Agent，數字本身就是「Agent Sprawl」規模的具體證據
- 187 名員工（Tracxn 統計）對比兩位數百萬美元 ARR，人均產值在資安新創裡偏高，顯示產品仍以平台化的自動偵測為主、還沒進入重服務階段

## Watchlist 狀態

Reco 尚未在 watchlist 中。建議加入 section B7（Agent 安全／治理／資安技術），與 Zenity、Hidden Layer、Prompt Security、Noma Security 並列追蹤，追蹤重點：Reco Graph 從 SaaS 安全延伸到 Agent 治理的轉型速度、AT&T 這類策略投資人的客戶背書效應，以及跟 Cymphony、Air 這類同期融資對手的定位差異。

## 今日收穫

Reco 這輪融資的訊號不在金額，而在「轉型速度」——一家原本做 SaaS 安全的公司，靠著把既有客戶關係和 tech stack 延伸到 Agent 治理，8 個月內估值翻倍以上，說明在 Agent 安全這個擁擠賽道裡，先卡住客戶信任比先做出差異化技術更值錢。
