## 這家公司做什麼

OneByZero（OBZ）是做「企業 AI 部署與治理」的公司——專注把大型企業裡仍停留在 PoC 階段的生成式 AI，落地成能實際跑在正式系統裡、受治理框架約束的「AI Coworkers」。

核心產品是 NEO 平台加上一組預建的 AI Coworkers（例如處理社群客服回覆的 Jenny、處理資料遷移協調的 ETL Crew、處理招募流程篩選的 Tara Reyes），每個角色對應企業裡具體的職能，並透過「前線部署工程團隊」（forward-deployed engineers）在客戶環境裡客製、上線並持續優化。NEO 的核心賣點是治理層：企業可以定義 AI 被允許做什麼、哪些環節必須保留人類判斷，以及每個 Agent 動作都留下可稽核記錄——這讓 OBZ 能在金融、電信這類高監管產業裡取得導入許可，而不只是停在概念驗證。

過去三年，OBZ 已在金融服務、電信、零售產業完成部署，公司稱部分客戶的客服互動自動化比率超過 90%、部分資料遷移交付速度提升 50%，年營收連續三年以超過 100% 的速度成長。目前營運橫跨澳洲、印度、印尼、馬來西亞、菲律賓、新加坡、泰國、美國、越南九個市場，並是 AWS GenAI Innovation Centre 全球 22 個合作夥伴之一。

## 這筆融資的信號

### 對 Agent 生態的意義

OBZ 代表的是「顧問服務 + Agent 平台」混合模式在東南亞企業 AI 市場裡的驗證——比起賣一個自助式（self-serve）Agent builder，OBZ 靠前線工程團隊把 Agent 嵌進客戶既有系統的做法更接近傳統系統整合商，但交付的產品是 Agent 而不是客製化軟體。這反映出企業現階段要的不是更多工具，而是有人把 Agent 真正放進生產環境、並對結果負責。

### 投資人在賭什麼

Jungle Ventures 管理合夥人 Yash Sankrityayan 的說法聚焦在「三年實戰經驗」——投資邏輯不是技術本身，而是 OBZ 在大型且複雜的組織裡部署 AI、並拿出可驗證結果的執行紀錄，這與多數仍在種子階段、靠 demo 說故事的 Agent 新創形成對比。這也符合 Jungle Ventures 長年專注東南亞中小企業與區域龍頭的投資主題，而非追逐矽谷式的高速燒錢成長。

### 值得觀察的數字

- 公司稱營收連續三年年增超過 100%，放在「企業 AI 部署」這個服務密集度高的賽道裡，增速偏高
- $20M 是公司成立三年來第一次外部募資，代表此前完全靠營收自籌，這種「先賺錢再募資」的路徑在 Agent 新創裡並不常見
- 募資後計劃進入日本市場，並擴張到醫療保健與公共部門——這是從「私營企業導入」往「高監管產業」擴張的信號，和 Valon 在房貸服務走的路線類似

## Watchlist 狀態

OneByZero 尚未在 watchlist 中。建議新增至 section D10（Moveworks、Glean、ServiceNow、UiPath 旁），追蹤重點：這種「前線部署顧問團隊 + 治理型 Agent 平台」的混合模式，在規模化後能否維持毛利率，還是會被迫往純顧問服務的低毛利結構靠近。

## 今日收穫

多數企業 Agent 新創的敘事是「我們的平台讓你自己就能部署 Agent」，OneByZero 的敘事反過來——「我們派工程師進你的系統，Agent 落地由我們扛責任」。這輪募資說明至少有一類買家（高監管、大型、技術資源有限的企業）更願意為「有人負責到底」付錢，而不是為「更好用的工具」付錢。
