## 今日主題

Metrics & Analytics 面試裡，定義一個北極星指標只是及格線，真正拉開分數的是能不能主動講出「如果全公司都去衝這個數字，哪裡會先出問題」。面試官拋出的題目往往故意帶一個隱藏的資源分配情境——優先做 A 就等於犧牲 B——就是要看候選人是不是只會選指標，還是能同時講出取捨。

這個主題在面試中重要，是因為真實的產品決策極少是「這個指標該不該優化」的單選題，而是「把資源與使用者的注意力從一個地方挪到另一個地方，划算嗎」的配置題。能不能把北極星指標跟它的取捨同時講清楚，直接反映候選人有沒有在真實組織裡做過指標治理。

## 核心框架速記

### 北極星指標三要素檢驗法

挑選北極星指標候選項時，用三個條件逐一檢驗，而不是直接選一個「聽起來很重要」的數字：

| 條件 | 檢驗問題 | 不符合的徵兆 |
|------|----------|-------------|
| **反映核心價值** | 這個數字上升，使用者是不是真的拿到更多價值？ | 選了一個業務方便報告、但使用者感受不到的數字（如總曝光次數） |
| **領先指標** | 能不能比營收、留存這類落後指標更早反映出問題？ | 指標要等一個季度才會動，來不及當作團隊的日常訊號 |
| **團隊能直接影響** | 產品與工程團隊的日常決策能不能直接牽動這個數字？ | 指標主要受外部因素（大盤、季節性）驅動，團隊怎麼做都動不了它 |

**面試時的用法**：拿到「幫 XX 功能定義北極星指標」的題目時，先丟出一到兩個候選項，再用這三個條件當場篩一遍——講出「這個候選項在哪個條件上比較弱」，比直接宣布一個答案更能展現判斷過程。

### 護欄指標配對法

選定候選北極星指標後，立刻幫它配一個「被過度優化時會先出事」的護欄指標：

1. **找資源的零和關係**：這個指標的上升，是不是建立在某個有限資源（使用者的時間、團隊的工程量）被重新分配的基礎上？
2. **指名被犧牲的對象**：如果資源確實是從別處挪過來的，被挪走資源的那一方是什麼（另一個功能、另一群使用者、另一個部門的目標）？
3. **配一個會先亮紅燈的數字**：幫被犧牲的那一方找一個具體指標，一旦它惡化到某個門檻，就該停下來重新評估，而不是繼續慶祝北極星指標上升。

**面試時的用法**：面試官最常見的追問是「如果這個指標持續上升，但另一個指標開始下滑，你怎麼辦」。先主動講出護欄指標，等於提前回答了這個追問,比被動等對方問更有說服力。

## 今日練習題

### 題目

「幫 Instagram Reels 定義一個北極星指標，並說明如果把資源優先給 Reels、犧牲 Stories,會有什麼取捨？」

（來源：Meta PM 分析思考面試真題，[Meta Product Manager Interview Guide, aced.io（原 Exponent）](https://www.aced.io/guides/meta-product-manager-interview)）

### 拆解思路

1. **釐清問題**：先問面試官——這題問的是 Reels 現在的生命週期階段（剛推出需要衝採用率，還是已經成熟需要衝營收），以及「資源優先給 Reels」具體指的是什麼——是工程資源、演算法推播權重，還是廣告庫存分配？不同資源的取捨完全不同。
2. **定義使用者**：拆成創作者跟觀看者兩種角色，各自再拆一次——習慣用 Stories 跟熟朋友維持日常聯繫的核心使用者，跟被演算法推薦吸引、刷 Reels 消磨時間的瀏覽型使用者。資源往 Reels 傾斜對這幾種人的影響方向不一樣。
3. **結構化分析**：用三要素檢驗法篩北極星指標候選項——「Reels 總觀看時長」反映價值但不夠領先；「每位日活躍使用者的 Reels 完整播放次數」同時滿足反映價值（真的看完才算）、領先（比留存更早反映）、可被團隊影響（演算法與內容供給都能直接牽動），是比較站得住的候選項。
4. **提出方案與取捨**：使用者在 App 裡的總時間是零和的——Reels 觀看時長上升,如果不是整體使用時間變長,就代表某處的時間被擠掉,最直接的候選就是 Stories 的發文與觀看量。護欄指標配對：幫「Reels 完整播放次數」配一個「每位使用者的 Stories 發文率」，一旦 Stories 發文率跌破某個門檻，代表核心使用者的日常聯繫習慣正在被侵蝕，不是單純的使用時間轉移。
5. **定義成功**：成功不是「Reels 指標持續上升」，而是「整體 App 使用時間池變大、Reels 吃掉的是新增的注意力而非挪用 Stories 的既有注意力」。同時監控整體日活躍使用者與整體 App 使用時長有沒有同步成長——如果只有 Reels 漲、整體沒漲、Stories 跌，這就是用一個指標的亮點掩蓋另一邊的流失。

### 範例回答（面試時可以這樣講）

> **問題釐清與定位**：「我會先確認 Reels 現在處於哪個階段——是還在推廣期要衝採用率,還是已經成熟要開始證明營收價值,因為這會決定北極星指標該往『觸及與採用』還是『深度與變現』哪個方向定義。我也會確認『資源優先給 Reels』具體指的是演算法推播權重、工程投入,還是廣告庫存——這三種資源的取捨完全不同。」
>
> **候選指標與取捨分析**：「我會提『每位日活躍使用者的 Reels 完整播放次數』當候選北極星指標,因為它同時滿足反映價值、領先、可被團隊影響這三個條件。但我不會只停在這裡——使用者在 App 裡的時間是零和的,如果 Reels 的觀看時長上升、整體使用時間沒有同步變長,那代表這些時間很可能是從 Stories 擠過來的。我會幫這個候選指標配一個護欄:每位使用者的 Stories 發文率,因為發文率下滑代表的是核心使用者的日常聯繫習慣被侵蝕,比單純的觀看時長轉移更傷產品的長期黏著度。」
>
> **成功定義**：「所以我衡量這個決策成不成功,不是只看 Reels 的指標有沒有漲,而是同時看三個數字:Reels 完整播放次數、整體 App 每位使用者的總使用時長、Stories 發文率。只有當整體使用時長也跟著漲、Stories 發文率沒有明顯下滑,才能說 Reels 吃到的是新增的注意力,而不是把 Stories 的既有使用者體驗換成了帳面上更好看的 Reels 數字。」

### 自我核對清單

用這張表檢查你的回答有沒有漏掉關鍵點：

| 核對項目 | 有提到？ |
|---------|---------|
| 先問清楚題目裡「資源優先給誰」具體指的是哪種資源 | |
| 用三要素（反映價值、領先、可被影響）篩選北極星指標候選項，而非直接宣布答案 | |
| 指出使用者時間或資源是零和關係，講出被犧牲的一方是誰 | |
| 主動配一個護欄指標，而不是等面試官追問才講 | |
| 定義「成功」時同時看北極星指標與護欄指標，而非只看北極星指標有沒有漲 | |
| 加分項：講出要監控的整體盤面指標（如整體 App 使用時長），用來分辨是「新增」還是「轉移」 | |

## 今日案例

**Meta：Instagram 把超過一半廣告庫存搬去 Reels，用真實數字示範了「資源傾斜」的取捨**

根據市場情報公司 Sensor Tower 的數據，Meta 的 Instagram 在 2025 年有超過一半的廣告曝光跑在 Reels 上，相較 2024 年的 35% 大幅成長；在美國，使用者花在 Instagram 上的時間裡，Reels 占比也從 2024 年的 37% 漲到 2025 年的 46%。同一份數據顯示，Instagram 的日活躍使用者較去年成長 2%，而這個成長主要由 Reels 使用量帶動——換句話說，Meta 不只把演算法推播權重往 Reels 傾斜，連廣告庫存分配都跟著重新配置，賭的正是「Reels 吃到的時間是整體池子變大帶來的新增注意力,而不是單純把 Stories 跟 Feed 的既有使用者體驗換成 Reels」。

**面試連結**：這個案例把今天的練習題從假設情境變成了真實的資源配置決策——Meta 自己就在回答「把資源優先給 Reels，犧牲的是什麼」這個問題，而「整體日活躍使用者是不是同步成長」正是面試官期待候選人主動提出的那個護欄層級指標。回答這類題目時，可以直接引用這個案例說明「大公司做這類決策時,真正在意的不是單一格式的數字,而是整體盤面有沒有被稀釋」。
