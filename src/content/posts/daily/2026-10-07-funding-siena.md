## 這家公司做什麼

Siena 是做「消費品牌客戶對話 Agent」的公司——從一個處理客服工單的同理心 AI Agent 起步，現在想做成品牌所有客戶互動共用的「Agent of Record」。

核心邏輯是：品牌已經有一堆「系統記錄」（ERP 記錄訂單、Shopify 記錄店面、另一套系統記錄會員點數），但沒有一個系統記錄「關係」本身——顧客說了什麼、為什麼退貨、上週在 DM 問了什麼。Siena Intelligence 把對話、訂單、訂閱、評論、會員資料整合成共用的客戶情境，再由 Siena Memory 把這個情境帶著走，讓顧客從客服轉到購物、轉到社群、轉到語音通話時不用重新自我介紹。公司已經把這套邏輯從客服 Agent 擴張出 Shopping Agent（商品推薦與結帳）、Social Agent（社群留言與 DM 管理）、QA Agent（品質評估）。

目前合作品牌包括 SPANX、FIGS、HexClad、Comfrt 等數百家消費品牌，累計自動化處理超過億筆客戶互動。案例顯示 Eskiin 用 Social Agent 把每週留言互動量從約 1,600 筆提升到 2,400 筆，SPANX 靠 Siena 抓到特定地區物流商造成的出貨延誤模式。

## 這筆融資的信號

### 對 Agent 生態的意義

Siena 的敘事代表客服 Agent 賽道正在往「統一客戶情境層」整合——過去是客服、社群、行銷各用各的工具，各自握著一部分客戶資料。Siena 的賭法是：既然都要幫品牌處理客戶互動，不如把所有互動管道的 Agent 建在同一套共用記憶之上，而不是讓品牌自己拼接工具、自建中介層。這呼應整個企業 Agent 市場正在發生的現象——單點功能 Agent 正在往平台化的「Agent 作業系統」整併。

### 投資人在賭什麼

York IE 普通合夥人 Tom Holahan 的說法是「Siena 可能變得跟品牌的電商平台一樣不可或缺」——投資邏輯不是賭單一功能的轉換率，而是賭 Siena 能不能把自己卡進品牌的核心基礎設施位置，變成跟 Shopify 同一層級的「客戶關係系統」。這類賭注的風險在於：Siena 要同時打贏客服、社群、購物、語音四條戰線的既有玩家，而不是靠一個功能打出護城河。

### 值得觀察的數字

- Social Agent 在 Eskiin 的案例裡把每週留言互動量從 1,600 提升到 2,400（+50%），週末回覆時間從 48 小時縮短到 1 分鐘內——這是 Agent 直接替代人力輪班的具體數字
- 公司不按席位收費，改成按結果與情境用量計價，意味著客戶擴大 Agent 使用規模時帳單不會因為加人頭而跳升，這是客服 Agent 賽道裡逐漸常見的計價模式轉向
- 取得 Meta 與 TikTok 的社群對話串接授權花了 6 個月，顯示平台端對「把客戶對話交給第三方 Agent」仍有審查門檻，這會是同賽道其他玩家複製 Social Agent 模式時的隱性成本

## Watchlist 狀態

Siena 尚未在 watchlist 中。建議新增至 section D1（客服/CX），追蹤重點：Siena 從單一客服 Agent 擴張成跨管道「Agent of Record」平台的路線，與其他客服 Agent 新創相比，是否能真正建立起「共用客戶記憶」的護城河，還是最終還是被拆解成單點功能被個別取代。

## 今日收穫

多數客服 Agent 新創的敘事是「我們把客服這件事做得更好」，Siena 的敘事是「客服只是我們取得客戶理解的第一個管道」——這輪募資說明投資人願意為「誰握有客戶關係的共用記憶」這個更大的位置買單，而不只是為單一功能的自動化效率買單。
