## 這家公司做什麼

Ghost 是做「Agent 專用個人電腦」的公司——不是在雲端幫你跑 Agent，而是賣一台你自己擁有、放在家裡的硬體，讓 Agent 全天候在上面運作。

核心產品 Core 是一台售價 $3,499、沒有螢幕的桌上型主機，內建 Nvidia RTX Pro 4000 SFF Blackwell GPU，預裝 Qwen-3.8-Next、Qwen-3.8-27B、Gemma-4-31B 三個模型，使用者透過手機 App 或語音操作。Core 把一個人的桌面檔案、App、智慧家庭裝置資料集中到這台裝置上，讓 Agent 能持續理解使用者的生活並代為行動；所有模型權重、記憶與個人資料都留在裝置本機，官方強調即使 Ghost 公司倒閉，裝置仍能繼續運作。

Core 於 10 月 5 日開放預購，首批在數小時內售罄。創辦人 Zain Javaid 年僅 19 歲，此前是量化交易背景，團隊其他三人也都在 20 多歲。

## 這筆融資的信號

### 對 Agent 生態的意義

目前主流 Agent 多跑在雲端伺服器上，由大型科技公司掌控資料存取權；Ghost 賭的是，一旦使用者開始把個人資料、帳密、智慧家庭控制權都交給 Agent，「這台裝置屬於誰、資料存在哪裡」會變成跟 Agent 能力本身一樣重要的賣點。

### 投資人在賭什麼

a16z 這輪押的是「本地運算＋隱私」的敘事——隨著 Agent 被授權的自主權限越高（金錢、帳密、裝置控制），把運算留在使用者自己手上的硬體方案，可能比持續依賴雲端服務商更有長期防禦力，邏輯類似他們過去在消費硬體與去中心化運算上的佈局。

### 值得觀察的數字

- $11M 種子輪對硬體公司而言規模不算大，但首批預購在「數小時內」售罄，顯示至少存在一群願意為「自己擁有的 Agent」付費的早期使用者
- 售價 $3,499 已內含 GPU 成本，官方強調不需要額外加購顯卡，定價策略對比同樣能跑本地模型但非 Agent 專用的高階桌機
- 創辦團隊四人平均年齡約 21 歲，是近期罕見由 Z 世代團隊主導、直接挑戰硬體與 AI 基礎設施層的案例

## Watchlist 狀態

Ghost 尚未在 watchlist 中。建議加入 section B8（沙箱/執行環境），追蹤重點：消費級 Agent 專用硬體，強調本機執行、不依賴雲端的隱私訴求。

## 今日收穫

原本以為「Agent 硬體」只會是雲端服務商順便賣的周邊，但 Ghost 首批預購數小時內售罄顯示，把 Agent 的運算、記憶與資料主權還給使用者本人，可能是雲端 Agent 之外被低估的一條路線。
