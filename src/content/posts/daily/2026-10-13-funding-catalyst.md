## 這家公司做什麼

Catalyst 是做散戶交易 agent 的公司——使用者用自然語言說出投資意圖,agent 把它轉換成可執行的交易策略,並在使用者核准後自動執行。

核心產品讓使用者設定風險參數來約束 agent 的行為,agent 負責把「意圖」拆解成具體的交易工具選擇、成本最佳化,並在訊號出現的時間點執行。創辦人 Dylan Iskandar 把目標描述為「人不需要靠避險基金才能避險」——也就是讓一般散戶也能用上原本只有專業機構才負擔得起的交易複雜度。

公司由 25 歲的 Justin Zheng 與 21 歲的 Dylan Iskandar 於 2025 年共同創立,目前已完成一輪針對強力交易者（power traders）的 pilot,公司稱短短幾週內產生了數億美元的交易量，產品正從 waitlist 逐步開放給更多使用者。

## 這筆融資的信號

### 對 Agent 生態的意義

Catalyst 是「agent 作為投資顧問兼執行層」這個賽道裡,目前資金規模最大的早期案例之一。Sequoia 合夥人 George Robson 把 agent 形容為「使用者在金融世界裡的一套盔甲」——這代表財富管理正在從「給建議」轉向「自然語言意圖→自動執行」的 agent 化路徑。

### 投資人在賭什麼

Sequoia 最近也主導了機器人數據公司 Mecka 的 $60M B 輪,顯示這家 VC 持續押注「agent 把複雜系統變得可操作」這個主題。跟投名單裡出現 Coinbase Ventures 與 Jump Trading 這類交易基礎設施玩家,透露他們把 Catalyst 看作潛在的流量或執行合作夥伴,不只是單純的財務投資。

### 值得觀察的數字

- Pilot 階段幾週內就產生「數億美元」交易量（具體數字未揭露），但驗證了散戶對 agent 代為執行交易的接受度
- 公司成立僅數月,就拿下由 Sequoia 領投的 $30M 種子輪,是今年金融 agent 領域最大的種子輪之一
- 跟投陣容中有兩家交易基礎設施公司（Coinbase、Jump Trading）,產業戰略資本的參與度明顯高於一般種子輪
