## 這家公司做什麼

Fragment 是做 agent 金流基礎設施的公司：讓 AI agent 處理帳單與會計時，先用複式記帳確認每一筆錢的來源和去處對得起來，才讓錢真的移動。

開發者把 Fragment 的工具接進自己的軟體，它提供一組「金融積木」，執行長 Thomas Neckel 的比喻是：Claude Code、Cursor 是讓 agent 自動寫程式的積木，Fragment 則是讓 agent 自動處理交易的積木。重點不是讓 agent 更會付錢，而是在付款前檢查帳是平的，降低錯帳成本。

公司有約 50 到 60 個付費客戶，包括企業卡新創 Ramp、財務軟體 BILL 與數位市集 Whop，他們把 Fragment 當成共用的交易紀錄，減少人工核對不同財務系統數字的工作。共同創辦人是執行長 Thomas Neckel 與前 Robinhood 工程師、技術長 Varun Mohan。

## 這筆融資的信號

### 對 Agent 生態的意義

agentic commerce 的基礎建設正在一層一層補上：Visa 與 OpenAI 6 月合作讓 agent 在使用者設定的額度內購物，Mastercard 推出 agent 互相付款的服務，Stripe 與 Tempo 3 月推出讓 agent 付費取用工具與資料的標準。這些解決的是「agent 怎麼付錢」，Fragment 補的是「付之前帳對不對」。agent 誤刪資料庫、逃出測試環境的案例愈多，企業愈需要在錢移動之前有一道可驗證的檢查。

### 投資人在賭什麼

FirstMark 合夥人 Adam Nelson 說的目標是「成為任何人替 agent 加上金融能力時的標準工具組」。種子輪由 Stripe 領投，代表金流業者本身也認為需要這一層。值得注意的是，這輪在 2025 年中就已完成，現在才公開，搭的是 agentic commerce 這波聲量。

### 值得觀察的數字

- 付費客戶約 50–60 家，含 Ramp、BILL、Whop
- 種子輪 $11M＋A 輪 $12M，A 輪金額跟種子輪幾乎一樣，代表這輪是延續驗證，還沒到規模化
- 從完成募資到公開相隔一年以上，下一輪要看客戶數與交易量能不能跟上 agentic commerce 的成長

## Watchlist 狀態

## 今日收穫

之前以為 agent 付款的問題主要在授權與額度，Fragment 的做法提醒我：就算授權對了，帳不平一樣是損失。agent 能動用的錢愈多，「事前對帳」愈像跟權限控管同等級的基本功。
