## 這家公司做什麼

Zenzap 是企業版的團隊聊天平台，員工和 AI agent 在同一個對話串裡分派任務、交換文件、追進度。

它想取代的是很多公司拿 WhatsApp 群組辦公的習慣：消費級通訊軟體讓公司管不到員工怎麼用、資料散在個人帳號裡。Zenzap 自建安全架構、行動介面與聊天體驗，接上數千個企業應用的 connector，內建預設 agent 與自動化，員工用文字或語音就能叫 agent 做事，公司稱設定一個 agent 不到 90 秒。平台宣稱符合 SOC 2、HIPAA、ISO 27001 與 GDPR，資安長可以集中管理員工與 agent 能碰哪些工具與資料。

公司稱已服務數千個組織，客戶在平台上建了超過 40,000 個自動化工作流程，例如把請求轉給對的人、找缺漏的發票、更新 CRM、在護理機構交班前確認給藥流程已完成。執行長 Guy Weiss 把目標市場講得很直接：Slack 沒打進去的非科技組織，例如醫療與房地產。

## 這筆融資的信號

### 對 Agent 生態的意義

第一波 AI 工具大多是「一個人對一個 chatbot」。Zenzap 賭的是團隊層級：agent 跟一群人共用同一份脈絡，在大家已經在用的對話裡接任務。對倉儲、物流、診所這類現場工作，入口是手機聊天室而不是桌機上的 SaaS，誰先佔住這個入口，agent 的分發就容易很多。

### 投資人在賭什麼

Bessemer 與 Lightspeed 共同領投，押的是「工作溝通 × agent」在非科技產業的空白。這些組織沒有導入 Slack 或 Teams，也缺乏自己整合 agent 的工程能力，現成的聊天介面加 connector 是比較低的導入門檻。要注意的是，這輪在 2025 年 8 月就已完成，今天公開是配合出 stealth。

### 值得觀察的數字

- 40,000+ 個客戶自建的自動化工作流程
- 45 人團隊服務「數千個組織」，客戶數與營收都未揭露
- 種子 $11M → A 輪 $33M，A 輪是種子的 3 倍

## Watchlist 狀態

Zenzap 尚未在 watchlist 中。建議加入 section B3（Agent 平台），理由：團隊聊天室形態的 agent 平台，鎖定非科技產業的現場工作，與 Slack、Teams 內建 agent 的路線不同。

## 今日收穫

之前以為企業 agent 的入口會是 Slack、Teams 這些既有平台，Zenzap 的定位提醒我：很多產業根本沒有導入這些工具，它們的「現有工作流程」是 WhatsApp 群組，agent 要進去得先換掉那個群組。
