## 區域：中東（含以色列）

本週中東 AI 生態的主線，是從過去幾個月常見的「主權基金砸錢投資」敘事，轉向「自己動手建治理系統、自己動手做產品」。UAE 聯邦政府的 Agent 控制塔上線、沙烏地 Cycls 推出四款本地化 Agent、杜拜辦全球競賽——這些動作的共同點是把 AI Agent 當成需要被治理、也值得被量產的基礎設施,而不只是用錢換時間的採購項目。但同一週的資金數據也提醒一個現實:這股自建能量目前幾乎全部集中在阿聯和沙烏地兩國。

## 本週重要動態

### UAE 聯邦政府「Agent 控制塔」正式上線：每個政府 Agent 都要連線受監控

UAE 人工智慧、數位經濟與遠距工作應用國務部長 Omar Al Olama 10/14 在世界經濟論壇杜拜年會上證實，UAE 聯邦政府已建置「Agent 控制塔」(Agent Control Tower)：所有聯邦政府部署的 AI Agent 都必須連接這套系統，每一個決策步驟與行動都會被記錄，並同時接受 AI 與人工的持續稽核。這是今年 5 月 UAE 內閣通過的聯邦 Agentic AI 部署框架的落地——該框架設定兩年內把至少 50% 的聯邦服務轉為 AI 系統驅動的目標。（[Gulf News](https://gulfnews.com/business/economy/uae-reveals-control-tower-to-monitor-ai-government-agents-1.500710167) · [The National](https://www.thenationalnews.com/news/uae/2026/10/14/minimise-catastrophes-uaes-ai-minister-highlights-dangers-of-autonomous-arms/)）

Al Olama 在同場活動特別強調信任的不對稱性：「政府只要做錯一個決定，就會流失大量信任,而信任一旦流失要花很長時間才能找回來。」這段話把 UAE 這套治理系統的動機講得很清楚——不是為了限制 Agent 的能力，而是為了在「50% 聯邦服務 AI 化」這個激進目標和「一次失控事件就可能摧毀公眾信任」的風險之間，找一個可以對外交代的平衡點。

### 沙烏地 Cycls 推出四款主權雲端 Agent：法律、行銷、股市各自垂直化

沙烏地 AI 平台 Cycls 10/14 推出四款垂直化 AI Agent：Super（通用研究與工作任務）、Haseef（專攻沙烏地法律，可查詢法規、判例並草擬文件）、Badee（行銷活動從企劃到阿拉伯語內容產製與投放）、Namaa（追蹤沙烏地主板與平行市場 Nomu 的公司財報與技術指標）。Cycls 由工程師 Mohammed Alrujayi 與 Mohammed Alogayyil 於 2021 年創立，這次產品線建立在沙國境內的主權雲端基礎設施上，模型與資料都留在境內。（[PCMag Middle East](https://me.pcmag.com/en/ai/38341/cycls-launches-four-ai-agents-for-saudi-arabia) · [Enterprise IT World MEA](https://enterpriseitworldmea.com/cycls-launches-specialised-ai-agents-for-saudi-market/)）

Cycls 的打法值得注意的地方，是它沒有做一個「全能多語言 Agent」去跟 OpenAI、Google 這類全球玩家正面競爭，而是選擇「主權雲端 + 深度綁定沙國法律／語言／股市」的窄而深路線——這跟杜拜、UAE 偏好治理基礎設施的打法不同，是產品層級的本地化策略。

### 杜拜啟動全球「Create AI Agents」競賽：獎金逾 68 萬美元

杜拜王儲兼副總理 Sheikh Hamdan bin Mohammed bin Rashid Al Maktoum 宣布啟動「Create AI Agents Championship」全球競賽，獎金池超過 250 萬迪拉姆（約 68 萬美元），由杜拜數字經濟商會主辦。這項競賽是杜拜原有「Create Apps Championship」的延伸，參賽者需在今年 12 月前提出 AI Agent 原型、提案與示範影片，面向任何技術背景、無年齡限制的全球參賽者開放。（[Business Wire](https://www.businesswire.com/news/home/20261008883373/en/Dubai-Launches-Global-Create-AI-Agents-Championship-with-Prize-Pool-Exceeding-AED-2.5-Million) · [Fast Company Middle East](https://fastcompanyme.com/news/dubai-launches-global-push-to-turn-ai-agents-into-real-world-products/)）

同一週，夏迦投資局（Invest in Sharjah）也在夏迦投資論壇推出名為 Najm 的 AI 招商代理，協助外國投資人在數秒內找到廠房、倉儲選址等投資機會，目標是今年把外國直接投資規模推高 20%、達 25 億美元。（[The National](https://www.thenationalnews.com/business/economy/2026/10/14/sharjah-turns-to-ai-to-boost-growth-and-speed-up-business-processes/) · [Gulf News](https://gulfnews.com/business/sharjah-launches-najm-an-ai-agent-to-guide-investors-1.500710070)）

### 資金高度集中：UAE 與沙烏地囊括今年中東新創募資近九成

創投數據庫 MAGNiTT 的數據顯示，中東新創企業今年前九個月共募得 29.8 億美元，其中阿聯和沙烏地阿拉伯合計囊括近 90%。（[Semafor](https://www.semafor.com/article/10/13/2026/uae-and-saudi-arabia-account-for-almost-90-of-298-billion-of-startup-capital-in-2026)）這個數字替本週一連串「中東 AI 治理與產品自建」的動態劃出了邊界——目前這股能量幾乎完全發生在兩個國家內，其他中東市場（約旦、黎巴嫩、埃及等）暫時不在這波自建浪潮的核心。

### 以色列資安公司 Zenity 揭露 AWS Bedrock AgentCore 嚴重漏洞鏈

以色列 AI 資安公司 Zenity Labs 本週在多倫多 SecTor 2026 資安大會公開完整細節的「AgentCorruption」漏洞鏈：攻擊者只需對一個公開的 AWS Bedrock AgentCore Agent 送出單一提示詞，就能透過內部暫時憑證存取機制，取得同一 AWS 帳號、同一區域內所有 AgentCore Agent 的原始碼、長期記憶、API 金鑰與 Secrets Manager 中的憑證，甚至能植入惡意記憶，讓 Agent 未來把對話內容外送到攻擊者控制的目的地。Zenity 已於 2025 年 12 月將漏洞負責任揭露給 AWS，AWS 已將 IMDSv2 設為預設並收緊執行角色權限，但對研究是否構成「漏洞」有不同意見。（[Zenity 官方新聞稿](https://zenity.io/press-release/zenity-labs-discloses-agentcorruption-a-chain-of-aws-agentcore-flaws) · [Dark Reading](https://www.darkreading.com/cloud-security/agentcorruption-aws-environments-at-risk-single-prompt) · [Business Wire](https://www.businesswire.com/news/home/20261008316155/en/Zenity-Labs-Discloses-AgentCorruption-a-Chain-of-AWS-AgentCore-Flaws-That-Allowed-One-Prompt-to-Take-Over-All-AgentCore-Agents-Within-an-AWS-Account-and-Region)）

這起揭露提醒一件容易被忽略的事：中東 AI 生態的分析焦點常常只放在 UAE、沙烏地的主權基金與政府採購，但以色列在 Agent 安全研究這個更底層、更技術性的領域，持續產出具全球影響力的發現——這次受影響的是 AWS 這類全球雲端巨頭的核心 Agent 平台，不是區域性的小型系統。

## 深度分析

我認為本週中東最適合用波特五力分析（Porter's Five Forces）裡的「新進入者的威脅」與「購買者的議價力」兩個角度來看，因為這週的事件剛好同時展示了這兩種力量在這個區域的獨特形態。

**購買者議價力的極端集中**：UAE 聯邦政府本身就是全球規模數一數二的 AI Agent 採購方——「Agent 控制塔」這個治理基礎設施一旦成形，就等於替進入 UAE 政府採購體系的供應商訂下了一套強制規格（必須可連接控制塔、必須可被稽核）。這種「單一買方制定規格」的局面,在民主國家的多層級採購體系裡很難出現，但在 UAE 這種中央集權程度較高的體制下可以快速落地——這同時是效率優勢，也是對外部供應商的進入門檻。

**新進入者威脅的本地化壁壘**：Cycls 選擇做「沙國法律 + 阿拉伯語行銷 + 沙股市場」這三個深度本地化的垂直 Agent，而不是跟全球平台拼通用能力，本質上是在用「對當地法規、語言、市場結構的深度理解」當護城河——這種壁壘 OpenAI、Google 這類全球玩家短期內很難複製，因為它需要的不是模型能力，而是在地知識密度。

**資金集中度強化了前兩個力量**：MAGNiTT 的「UAE + 沙烏地佔近九成募資」數據，本質上是在說新進入者的威脅在這兩國之外的中東市場特別低——沒有資金，就很難有新創挑戰現有的治理框架或產品壁壘。這三個力量疊加在一起的結果，是中東的 AI 治理與產品創新，正在往「UAE 和沙烏地的中央集權效率」與「本地深度知識壁壘」兩條路徑收斂，而不是走向開放競爭。

## 對台灣創業者的啟示

- 如果你想把 AI Agent 治理或合規工具賣進中東政府：UAE「Agent 控制塔」這種「所有 Agent 必須連接中央稽核系統」的採購規格，很可能成為其他中東國家效仿的範本——如果你的產品要打入這個市場，應該把「可被外部稽核系統串接、每一步決策可記錄回放」做成第一級功能，而不是事後補的合規模組
- 如果你在做特定產業（法律、金融、行銷）的垂直 AI Agent：Cycls 的打法證明「窄而深＋在地主權雲端」路線在高度在地化、高度監管的市場比「通用多語言 Agent」更有效——台灣團隊若想切入東南亞或中東某個特定國家市場，應該優先鎖定單一垂直領域（例如當地稽核法規、當地證交所資料），而不是一次性做出一個號稱能處理所有語言、所有產業的通用產品
- 如果你在規劃「中東市場」的商業計畫：MAGNiTT 近九成募資集中在兩國的數據是一個明確警訊——用「中東」這個籠統地理概念寫 GTM 計畫會嚴重誤判資源分配，實務上應該先確定你要進的是 UAE、沙烏地,還是其他中東市場,這三種情境的買方結構、資金取得難度完全不同
- 如果你需要對自己的 AI Agent 做滲透測試或安全稽核：Zenity 這次對 AWS Bedrock AgentCore 的揭露顯示以色列資安公司在 Agent 安全研究領域持續產出具全球影響力的成果——台灣團隊物色第三方 Agent 安全測試夥伴時，以色列資安業者是一個值得認真考慮的選項,不必侷限於美國或歐洲供應商

## 今日收穫

之前以為中東的 AI 敘事主要就是「主權基金砸大錢買算力、買模型授權」,這週看完 UAE 的 Agent 控制塔和 Cycls 的四款本地化 Agent 之後才意識到,這個地區現在同時在做兩件更難的事——建自己的治理基礎設施、做自己的垂直產品，而不只是當資金方。但 MAGNiTT 的募資集中度數據也提醒我：這股「自建」能量目前還是高度仰賴兩個國家的國家層級資源在推動,還沒有看到真正由市場機制驅動、資金分散到更多中東國家的訊號。原來「主權 AI」在中東的下一階段,不是砸錢買模型,而是砸錢建治理系統和在地化產品——但這個「下一階段」目前仍然只有兩個買得起門票的國家。
