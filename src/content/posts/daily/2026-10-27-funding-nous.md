## 這家公司做什麼

Nous 是一家把「管理家庭開支與行政雜務」整個外包給 AI agent 的公司——英國倫敦，由曾創辦精品住宿平台 onefinestay（2016 年以 $200M 賣給 AccorHotels）的 Greg Marsh 於 2021 年創立。

核心產品是一個綁定使用者各項帳單、保險、合約的 AI agent，主動幫使用者找便宜方案並「真的執行」切換供應商（能源、寬頻、手機、車險），取消不需要的訂閱，標記即將到期、可能漫天漲價的合約，還能幫家庭管理行事曆、找附近的水電工並預約。公司把 LLM 和規則引擎疊在一起用——一般任務交給 LLM 判斷，但碰到金融或敏感動作就切到規則邏輯；更關鍵的是它已在英國金融行為監理局（FCA）登記，讓 agent 能真的代替使用者做出有監管意義的金融決策（換保險、換供應商），而不只是停在「給建議」的助理層級。

目前規模：將近 25 萬個英國家庭使用，每年經手管理約 £6.85 億的家庭支出（平均每戶約 £2,765），平均每戶省下 £734。

## 這筆融資的信號

### 對 Agent 生態的意義

英國 FCA 的 Mills Review 發現 20% 的英國成年人願意讓 AI 幫自己做金融決策，信任、控制權和可及性是關鍵因素。Nous 這輪的意義在於，它是少數已經拿到監理機構正式登記、把「agent 真的代替你簽約／換供應商」落地的消費端案例，而不是停在「幫你寫一封取消訂閱的信」的助理層級。資金將用於拓展到更多家庭支出類別（更廣的保險與金融服務）以及海外市場。

### 投資人在賭什麼

領投的 Heartcore Capital 合夥人 Max Niederhofer 跟 Marsh 已經認識 20 年，Heartcore 押注的邏輯類似他早年投資 onefinestay 的邏輯（onefinestay 至今仍在 Niederhofer 的個人投資清單上）。原 Seed 投資人 Mosaic Ventures 回頭加碼，是「老股東對估值有信心才會再加碼」的標準訊號。天使陣容也值得留意——GoCardless／Monzo 共同創辦人 Tom Blomfield、Faculty.ai 的 Marc Warner、Funding Circle 的 James Meekings 都下注，顯示這個領域吸引的是懂金融科技監理門道的人，不是單純看 agent 熱度進場的錢。

### 值得觀察的數字

- 使用者數從 0 衝到近 25 萬個英國家庭，平均每戶每年由 Nous 管理 £2,765 的支出
- 平均每戶省下 £734——這是一個可被驗證的直接 ROI 指標，比多數「AI agent 幫你省時間」的模糊說法更容易讓監管機構與消費者核實
- 累計融資僅 $26M（含本輪），相較同期其他 agent 領域動輒 $100M+ 的輪次，Nous 走的是精算型、受監管垂直領域的慢熬打法，而不是靠敘事衝估值

## Watchlist 狀態

Nous 尚未在 watchlist 中。建議併入 D6（金融服務／保險）相關追蹤，追蹤重點：受 FCA 監理的消費端家庭理財 agent，$17M 新一輪，Heartcore Capital 領投，Mosaic Ventures 回頭加碼。

## 今日收穫

多數消費端 AI agent 的敘事都卡在「使用者敢不敢授權 agent 代替自己做事」這道信任門檻，而 Nous 選的切入點不是技術突破，是監理合規——先去 FCA 登記、讓 agent 的每個金融動作都站在被監管的框架裡，反而讓消費者更敢把帳單、保險這類敏感決定真的交出去。這跟多數 agent 公司先衝產品再補合規的順序完全反過來，但看起來正是這類觸及金融敏感資料的消費端 agent，能規模化到 25 萬使用者的真正原因。
