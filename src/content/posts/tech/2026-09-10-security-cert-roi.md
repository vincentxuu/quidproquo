> 🌏 [English version](/en/posts/tech/2026-09-10-security-cert-roi-en)

考證照是投資，不是集郵。這篇用真實數據把三張經典資安證照的投入和回報攤開來算：考試費多少、準備要多久、維護成本怎麼算、薪資溢價有多少。

系列前兩篇已經畫好[全景地圖](/posts/tech/2026-09-10-security-cert-landscape)和 [AI 安全證照橫評](/posts/tech/2026-09-10-ai-security-cert-showdown)。這篇聚焦三張你最可能先考的：Security+、AWS Security Specialty、CISSP。

## 三張證照一覽

| | Security+ | AWS Security Specialty | CISSP |
|---|---|---|---|
| **發照方** | CompTIA | AWS | ISC2 |
| **定位** | 通用資安基礎 | AWS 雲端安全專家 | 資安管理全域 |
| **考試代碼** | SY0-701 | SCS-C03 | — |
| **題數 / 時間** | 90 題 / 90 分鐘 | 65 題 / 170 分鐘 | 100–150 題（CAT）/ 3 小時 |
| **及格線** | 750/900 | 750/1000 | 700/1000 |
| **經驗門檻** | 無（建議 2 年 IT） | 無（建議 5 年 IT + 2 年 AWS） | **5 年**跨 2 域（學位折 1 年） |

## 費用：不只是考試費

### 考試費

| 證照 | 考試費 (USD) | 備註 |
|---|---|---|
| Security+ | $404–$439（2026/06 起調價） | CompTIA 學生方案或授權夥伴常有折扣 |
| AWS Security | $300 | 持有任何 AWS 認證可享 **50% off = $150** |
| CISSP | $749 | 全球統一價，Pearson VUE 報名 |

**來源**：[CompTIA 官方](https://www.comptia.org/certifications/security)、[AWS 認證頁](https://aws.amazon.com/certification/certified-security-specialty/)、[ISC2 官方](https://www.isc2.org/certifications/cissp)

### 備考材料（估）

| 證照 | 免費路線 | 付費路線 | 估計花費 |
|---|---|---|---|
| Security+ | Professor Messer YouTube 全課程 + CompTIA 樣題 | Udemy Jason Dion / Professor Messer（$15–$30 特價） | $0–$50 |
| AWS Security | AWS Skill Builder 免費課 + 白皮書 | Udemy Stephane Maarek / Neal Davis（$28–$120）+ Tutorials Dojo 題庫 | $0–$150 |
| CISSP | ISC2 樣題 + Reddit r/cissp + Discord | Boson 模擬題（~$80）、Udemy Thor Pedersen（$15–$30）；台灣實體班：[恆逸 CISSP](https://www.uuu.com.tw/Course/Show/47/CISSP)、[全智網 CISSP](https://ainetwork-training.com/courses/cissp) | $0–$150（自學）/ NT$5–8 萬+（實體班） |

### 五年維護總成本

這才是大家容易忽略的——證照不是考完就沒事。

| 證照 | 效期 | 續期方式 | 年費 | 五年總維護 |
|---|---|---|---|---|
| Security+ | 3 年 | 50 CEU + 年費 | $50/年 | **$150**（三年一期） |
| AWS Security | 3 年 | 重考或取得更高認證 | **無** | **$0**（或 $150–$300 重考） |
| CISSP | 3 年 | 120 CPE + 年費 | $125/年 | **$625** |

**五年取得 + 維護總成本**：

| 證照 | 考試費 | 教材（估） | 五年維護 | **五年總計** |
|---|---|---|---|---|
| Security+ | $404 | ~$30 | $150 | **~$584** |
| AWS Security | $150–$300 | ~$50 | $0 | **~$200–$350** |
| CISSP | $749 | ~$100 | $625 | **~$1,474** |

AWS Security Specialty 的五年持有成本最低，特別是你已經有其他 AWS 認證可享半價的情況下。CISSP 最貴，但換到的是完全不同等級的市場地位。

## 準備時間

| 證照 | 典型準備時間 | 建議總學習時數 | 背景假設 |
|---|---|---|---|
| Security+ | 2–3 個月 | 80–120 小時 | 有 IT 基礎但非資安背景 |
| AWS Security | 2–3 個月 | 80–120 小時 | 有 AWS 使用經驗 |
| CISSP | 3–6 個月 | 150–300+ 小時 | 有 5 年跨域經驗但需要系統化複習 |

依 [CertStud 2026 分析](https://certstud.com/blog/do-it-certifications-increase-salary-data-studies)，Security+ 是「study-hours-per-dollar-return 最高效的資安投資」。CISSP 則是「absolute dollar return 最高的資安證照」。

**三張可以疊的策略**：先考 Security+（2–3 個月）→ 有 AWS 認證就接著考 AWS Security（再 2–3 個月，用 $150 折扣價）→ 累積經驗後考 CISSP。Security+ 可以折抵 CISSP 一年經驗要求。整條路線攤開約 8–12 個月完成前兩張。

## 通過率

三家認證機構都**不公開官方通過率**，以下是社群數據和培訓機構的估計。

### Security+

依 [SecuSpark 2026 統計分析](https://www.secuspark.com/blog/security-plus-pass-rate-statistics)：

| 情境 | 首次通過率（估） |
|---|---|
| 自學（100+ 小時） | 50–65% |
| 搭配培訓 | 85–93% |
| 模擬考穩定 85%+ 再報名 | 90%+ |
| 準備不足 | < 50% |

**關鍵指標**：模擬考分數是最強的預測因子。如果你在練習題上穩定拿 85%+，真實考試通過率超過 90%。

### AWS Security Specialty

依 [Pruvos 社群數據](https://www.pruvos.com/certifications/cloud-computing/aws-scs-c03)：

| 情境 | 首次通過率（估） |
|---|---|
| 一般考生 | 45–55% |
| 有 AWS 實務經驗 | 65–70% |
| 模擬考穩定 80%+ | 高通過率 |
| 模擬考 < 72% | 可能需要更多實作時間 |

這是 AWS 認證中較難的一張。及格線 750/1000 比 Associate 級高 30 分。

### CISSP

依 [Training Camp 2026 分析](https://trainingcamp.com/articles/cissp-pass-rate-what-the-numbers-actually-show-in-2026)：

> 「ISC2 將通過率數據保密，而且截至 2026 年 6 月仍然如此。獨立估計一般將首次通過率定在 50% 至 60% 之間。廣為流傳的 20% 數字沒有任何可驗證的來源。」

| 情境 | 首次通過率（估） |
|---|---|
| 有結構化學習 + 跨域經驗 | 50–60% |
| Reddit 上常見的自我報告 | 差異極大 |
| 「20% 通過率」 | **無可溯源**，不應作為決策依據 |

CISSP 的難不在單一題目，在於它的 CAT（電腦適性測驗）格式——答對就出更難的題、答錯出更簡單的，你永遠不知道自己表現如何。加上 8 個域的覆蓋面極廣，從密碼學到實體安全到軟體開發安全都考。

## 薪資溢價

數據主要來自美國市場，台灣的幅度會小一些（但趨勢一致）。

### 美國市場

依 [CyberSecJobs 2026 分析](https://cybersecjobs.com/best-cybersecurity-certifications)和 [CertStud 調查](https://certstud.com/blog/do-it-certifications-increase-salary-data-studies)：

| 證照 | 持證者平均薪資 (USD) | 相對未持證的溢價 | ROI 倍數 |
|---|---|---|---|
| Security+ | $71,697（入門級） | +$10K–$20K | **25–37x**（以 $404 考試費計） |
| AWS Security | 變化大（依角色） | +$12K–$20K（疊在既有雲端技能上） | **40–67x**（以 $300 計） |
| CISSP | $164,000（中位數） | +$25K–$35K | **33–47x**（以 $749 計） |

依 [Kore1 薪資指南](https://www.kore1.com/cybersecurity-salary-guide)，「CISSP 是讓人在會議中重新計算招聘預算的那個數字。$25K 到 $35K 的溢價不是統計雜訊。」

### 台灣市場

依 [CloudInsight 2026 薪資調查](https://cloudinsight.cc/zh/blog/security-engineer-guide)：

| 年資 | 月薪範圍 (NTD) | 年薪估算 |
|---|---|---|
| 0–2 年 | 40,000–55,000 | 52–72 萬 |
| 3–5 年 | 55,000–80,000 | 72–104 萬 |
| 5–8 年 | 80,000–120,000 | 104–156 萬 |
| 8 年以上 | 120,000–200,000+ | 156–260 萬+ |

持有 CISSP / OSCP 等高階證照，薪資可多 **10–20%**。金融業薪資最高，外商比本土高 20–50%。

台灣的薪資溢價幅度沒有美國那麼誇張（$25K–$35K 約等於 NT$80 萬–NT$112 萬，在台灣幾乎是一整個 junior 的年薪），但在升遷和跳槽的談判上，證照仍然是硬指標。特別是 CISSP——台灣僅約 500 人持有，稀缺性讓它在面對企業客戶時有很強的信任信號。

## ROI 排名

綜合考試費、準備時間、維護成本、薪資溢價和市場認可度：

| 排名 | 證照 | 理由 |
|---|---|---|
| 🥇 | **AWS Security Specialty** | 最低持有成本（$150–$300）、最高 ROI 倍數（40–67x）、直接對齊 AI 平台開發者的日常工作 |
| 🥈 | **Security+** | 最低進入門檻、最快取得（2–3 個月）、可折抵 CISSP 經驗、台灣金融業認可 |
| 🥉 | **CISSP** | 最高絕對薪資溢價（+$25K–$35K）、台灣最高認可度、但門檻和維護成本最高 |

**最佳組合策略**：Security+（打基礎、折 CISSP 1 年經驗）→ AWS Security（對齊工作、最低成本）→ CISSP（長期王牌）。三張全拿的五年總成本約 **$2,258–$2,408**，換到的是從入門到頂級的完整資安背書。

## 整體來說

如果你只考一張：考 **AWS Security Specialty**。它的持有成本最低、跟你的工作最對齊、ROI 倍數最高。如果你已經有其他 AWS 認證，考試費只要 $150。

如果你考兩張：先考 **Security+** 打基礎（$404、2–3 個月），再考 **AWS Security**。Security+ 除了本身有用之外，還為未來考 CISSP 折了一年經驗。

如果你考三張：上面兩張加上 **CISSP**。但不急——CISSP 需要 5 年經驗，可以先考試成為 Associate of ISC2，等經驗到了再升級。五年維護費 $125/年 是一筆持續支出，確認你的職涯方向確實需要這張牌再投入。
